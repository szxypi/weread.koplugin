# 墨水屏原生章节的划线和想法

在数字书号的墨水屏原生章节中，长按选中文字，选择「微信读书划线或想法」；核对引用后可保存云端划线或新建私密想法。页面使用 KOReader 原生控件，不加载网页界面。此入口保留本机划线，不自动删除或上传 KOReader 的本机记录。

后台先校验账号、已保存章节文件、目录和版本，再分别读取墨水屏与网页原文；只有两者字节一致，且两个端点和完整选区能够唯一对应原始 HTML 范围，才显示引用。确认发送前再次独立核对来源、章节和书籍版本。既有发送记录、一次领取和独立回读保护继续适用；结果不明确时不会自动重发，阅读位置或账号变化会取消旧界面。

私密想法可保存本机草稿。恢复原生章节草稿时须打开同一已保存章节并联网，从选区菜单进入「本机想法草稿」，以便重新核对两端原文；来源变化或不可用时保留草稿。现有云端笔记自动叠加到此类章节、书签及跨章选区尚未接入。

完整安装插件的 KOReader 模拟在 600×800 和 KO2 尺寸覆盖原生选区菜单、划线及私密想法创建、引用范围的独立解析、草稿保存／恢复；修改来源、翻页和提交前版本变化会停止，失败的想法保留草稿。合成服务还验证回执丢失后的独立回读，以及未产生预期记录时保留待核对状态、阻止重复提交。原生章节选区的真实账号写入和实体 Kindle 仍待验收。
