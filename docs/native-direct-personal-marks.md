# 原生章节中的个人云端标记

打开墨水屏原生章节后，插件会在正文中显示当前章节可精确匹配的个人云端划线、带引用的个人想法，并为可定位的云端书签显示角标。想法引用使用虚线，点击后打开想法内容；想法与划线或多个想法重叠时，可根据简短内容选择要打开的记录。同页多个书签也可以通过角标分别选择；原生章节可从菜单[保存云端书签](native-direct-bookmark.md)。它们不写入 KOReader 的本机划线或折角。隐藏批注、休眠、关闭章节、切换账号或切换到翻译视图时，图层及其选择菜单会随之隐藏或关闭。

首次联网显示时，插件在后台核对章节缓存、账号、书籍版本及墨水屏和网页的原文字节，再将已验证来源缓存在当前账号的本机数据库中。缓存最多保留 128 个章节、约 32 MiB 正文；有完整缓存时可以断网重开。没有来源缓存、缓存损坏或引用无法精确定位时，相应标记不会显示；重新联网后会尝试刷新。更换章节文件或账号不能复用不匹配的来源。

划线和想法引用的原文范围、两端锚点和完整文字均须匹配阅读器正文；想法内容本身不用于定位。若阅读器的逐字符定位与正文不一致，插件只将文字搜索作为候选：两个原文锚点、正文完整前缀和选中文字必须再次一致，无法唯一确认位置时不会显示。书签需有足够的预览文字才能在这种备用定位中恢复。无引用或无法精确定位的想法仍可从笔记列表查看；想法正文不直接插入书籍页面，跨章节选区尚未接入。

部分章节样式引用了未随章节包提供的图片。原生章节读取现在仅对已识别的缺失本地图片使用占位图，并提示图片缺失；未知类型、歧义引用和异常路径仍停止处理，原始正文与批注坐标不变。

两种模拟尺寸已覆盖实际 KOReader 正文划线、书签角标、联网缓存、离线重开、损坏来源拒绝和备用定位。真实账号一本书的一章中两条划线均在两种尺寸显示并逐条核对原文，断网重开后仍一致；真实账号书签角标、更多章节及实体 Kindle Oasis 2 仍待验收。见[脱敏记录](validation-assets/2026-11-23/native-direct-personal-marks.json)。

个人想法另经两尺寸的完整插件合成场景验证，包括与划线重叠时选择并打开想法、断网重开和缓存损坏拒绝；账号切换保护、选择菜单关闭及长文本摘要经组件测试。真实账号一本书的一章有两条带引用想法，两条均在两种尺寸显示并点击打开，弹窗内容、来源和原文范围分别经独立核对，离线重开一致；云端书架、笔记及两端阅读位置的可观察状态保持，临时配置及凭据检查通过。此前因授权自然过期，同账号续期一次并回读；本次实际点击验证没有账号写入或续期请求。更多章节及实体 Kindle 仍待验收，见[显示记录](validation-assets/2026-11-23/native-direct-personal-thoughts.json)和[点击记录](validation-assets/2026-11-23/native-direct-personal-thought-popup.json)。

## 从笔记列表返回原文

原生章节阅读菜单提供本书云端划线、书签和想法入口。从列表打开记录时，插件核对账号、章节文件、原文来源和定位结果后跳转到对应的原生章节；其他书籍仍沿用原有打开流程。同书跨章节定位会先核对目标来源与引用，切换后再核对阅读器中的位置。离线时需要目标章节和已验证的原文来源均已缓存；目录信息不完整的旧章节需要联网重开。来源损坏、引用不匹配或阅读状态发生变化时不会跳转到未核对的位置。

在 600×800 和 1264×1680 两种模拟尺寸下，实际 KOReader 合成场景验证了三类记录的菜单入口、从其他页面返回原文、离线重开及损坏来源拒绝；同账号真实数据各取一章，两条划线和两条想法均在两种尺寸完成在线及离线定位，原文经独立核对。本次没有账号数据写入或授权请求，云端可观察状态和网页阅读位置保持。真实书签定位、更多书籍及实体 Kindle Oasis 2 尚待验收，见[脱敏记录](validation-assets/2026-11-23/native-direct-personal-notes-navigation.json)。

同书跨章节定位已在两种模拟尺寸的完整 KOReader 插件中验证：目标缺章时联网获取，三类笔记各自打开目标原文，然后在新进程离线重开；断网且原文缓存损坏时保留原章节，且没有发出网络请求。账号切换、页面变化、无阅读权限和目录变化另经组件测试。真实账号的跨章节定位及实体设备仍待验收，见[验证记录](validation-assets/2026-11-23/native-direct-cross-notes.json)。
