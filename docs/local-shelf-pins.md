# 本机置顶

在书架长按一本书，选择「本机置顶」；再次长按可选择「取消本机置顶」。本机置顶仅影响本设备的书架，不会向微信读书发送修改，也不会同步到其他设备。云端置顶仍单独显示，未知状态不会被推断为未置顶；其协议已通过真实账号往返核对，原生入口与剩余验收见[云端置顶](cloud-pins.md)。

置顶书在当前书架及分组所选排序中稳定排在前面；搜索、筛选仍生效，同一优先级按用户选择的排序排列。封面和列表标识为「本机置顶」。首页最近阅读继续按阅读时间排列。该状态按当前账号保存在本机 SQLite，离线可用，切换账号不会继承其他账号的置顶。暂时从书架消失的书保留该本机记录；重新出现在同一账号的书架时继续生效。更改时比较已读状态并原子保存，其他进程先更新、账号切换或保存失败时不会覆盖新状态；重新打开书架后会读取最新状态，并在置顶发生变化时重新生成分页顺序。

## 验证

使用合成账号与书籍，在打包插件、KOReader 原生界面及真实 SQLite 中验证添加／取消、完整长按菜单、原有读完标记同时显示、其他排序及搜索、跨账号隔离、并发保存失败保护和离线新进程重开。封面标记在两种尺寸均经实际渲染核对，未发生账号网络请求。[600×800](validation-assets/2026-11-22/local-pins-600.json) 与 [KO2 尺寸](validation-assets/2026-11-22/local-pins-ko2.json)报告使用合成数据。另有模型、控制器及旧操作菜单的 Lua 检查；实体 Kindle 和其他设备仍需验收。
