# 未开始阅读与缺失章节索引

开发分支区分没有云端章节位置和有效的章节起点。首次从书架进入阅读、原生正文显示、翻页、本机位置保存与离线重开可以继续；没有章节位置的书籍，首次云端写入仍待独立协议验证，尚未启用。

## 云端没有章节位置

真实 Web 与墨水屏响应可返回 `chapterUid=0`、偏移 0、进度 0，同时省略章节索引和摘要。它不等于目录的第一章，也不等于一个可发送的完整原生位置。

正常同步入口现保留本机待同步点、撤销旧自动同步资格，并明确提示本书尚无可用云端章节位置。不显示两个都无法完成的冲突选项，不猜章号／序号，不触发定时或关书发送。反复点击同步仍保留本机意图；旧网关位置不会覆盖 Web 明确返回的无章节状态。

单独缺字段、非零进度却章号为零、非零偏移或非空摘要等矛盾数据，不归类为未开始阅读，而显示未能核对完整位置。普通响应解码器仍保留字段存在性，旧数值单位不变。

## 只有索引缺失

章号和偏移明确时，可按唯一章号使用目录实际提供的 `chapterIdx`，标记索引来源为目录。不使用数组序号、章号加减或默认零。目录重排不改变结果；重复章号、重复明确索引、索引别名矛盾、所选章节没有索引以及响应与目录索引不符，均停止比较和发送。

响应明确提供的索引零仍按零核对，不能当作缺失字段覆盖。其他章节缺索引时，仍可使用所选章节明确的索引。比较保持服务器百分比原单位。

目录补足索引不代替发送前的原生检查。原生通道仍必须独立取得完整位置、摘要、明确索引、版本、计数和书架，并与已比较的坐标一致；没有放宽 `NativePositionProtocol.point/snapshot` 或旧持久回执的校验。

## 本机普通翻页的精确重开

这次实际阅读器测试发现，先前仅为显式原文跳转保存视口证明，普通页面采集点重开后仍可能退回页首。现也为来源服务确认属于当前原生位置的普通采集点保存本机证明。

证明继续绑定账号、原文点哈希和八项完整原生视口字段。同一文件重开只在全部一致时恢复，仍须后台重新核对归档和渲染成员；未知、改变或旧视口保持 KOReader 原位置。证明不包含摘要，也不授予云端比较、上传或授权资格。

验收在全新离线进程打开后、任何诊断翻页／跳转之前，核对已识别的原文点与检查点并确认锚点可见。共用测试随后执行的诊断移动会返回这个已独立核对的初始点，不能用后续跳转掩盖打开时的位置偏移。

## 验收证据

[固定字段记录](validation-assets/2026-11-12/unstarted-reading.json)分别记录真实数据、实际阅读器与合成发送：

- 八本真实书籍的十六份 Web／原生响应，经 Python 和 Lua 独立投影比较；五本无章节、三本有位置。前后位置字段及存在性、摘要、计数、目录和稳定书架模型一致。
- 两个尺寸从真实书架进入未开始阅读的 TXT，正常同步两次均显示专用提示、不显示冲突选择、不授予自动发送资格，保留本机点。新进程离线重开初始点通过核对；原始云端无章节状态、三项计数和可见书架保持。
- 缺 Web 索引的独立模拟服务保留原生明确索引。两个尺寸完整执行手动、定时、未知回执及新进程零请求流程；每尺寸三个合成请求，由独立 Python 服务核对，零真实数据修改。
- 新发生的原生 HTTP 401 经本次实际阅读器及宿主分别复核后，仅续期一次；新授权保存钥匙串。原文位置请求在发送前阻断，数据修改为零，旧消费记录不重用。其后的只读验收不再申请授权。

最初的临时探针把会变化的外围响应字段也作为相等条件，记录为未通过并保留。正式探针明确比较位置字段、字段存在性和稳定书架模型；不把整个响应包相等当作协议要求。

本轮 256 组 Lua、125 个 Python 测试模块共 1604 项测试（零跳过）通过；714 项同步断言、70 项来源位置断言及 25 项新增 Python 测试通过。729 份 Lua 语法与 727 份静态检查无警告，1855 份文件凭据／私密摘要扫描和 299 条文档链接检查通过。

这轮没有验证“无云端章节→首次写入”的服务端语义，也没有制造一个零章号的恢复请求。后续仍需证明初始化写入、未知回执核对与已有阅读历史的处理，再接通原生首次同步。实体 KO2、实际磁盘写满／断电、多设备并发及更多格式仍待验收；整体性能专项继续排在功能验收之后。

后续[首次云端位置的独立 Python 协议验证](native-initial-position.md)已在一个新范围完成真实首次写入；当前目标保留，原始无章节状态不作伪造恢复。生产入口及其未知回执核对仍待接通。
