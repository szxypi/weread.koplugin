# 书架分组与弹窗生命周期

关闭书架后，旧分组回调曾能重新打开已经退出的页面；分组和选项弹窗也没有随所属书架关闭。
此外，封面或进度完成后的整页重绘会打断弹窗。关闭后的回调已用隔离组件测试复现。

现在分组、选项、排序、筛选和搜索共用所属书架的弹窗生命周期：

- 同一本书架只保留一个弹窗，替换、关闭或重开书架时关闭旧弹窗。晚到和重复回调不继续操作。
- 用户操作核对当前书架、账号／登录代次、阅读文档／会话、书架快照和读取通道；旧选择不修改新页面的设置。
- 封面和进度照常后台读取、保存；弹窗打开期间延后整页重绘。取消后显示新数据；完成选择后保留用户的新页面，旧重绘不能覆盖它。
- 正常分组不再因所有普通成员暂不可用而消失，仍可显示为空组。明确只有公众号容器的组继续由公众号入口承载。

本项是本机分组浏览与交互完善，不包含云端分组创建、改名、移动或删除。目录、正文、同步及书架写入权限没有扩展。

## 真实账号验证

Python 先独立读取 Web／墨水屏书架，核对分组与成员参考，再与 Lua 投影比较。
当次为 139 条书架、5 个原分组、6 个可选分组（含未分组）、137 个普通成员引用；两通道一致。
首次预检为原生 HTTP 401 后停止，既有维护工具只续期一次，核对同账号、书架与钥匙串回读，再继续读取。
这份维护记录不能代替产品自动续期的完整真实组合验收。

最终同一生产候选在 600×800 和 KO2 1264×1680／300 DPI 下，通过实际 PluginLoader／FileManager 加载。
每个尺寸分别启动独立联网和离线进程，使用原生 Menu 选择全部分组，核对组内全部页、成员、
展示字段、可见进度、封面文件及边界；离线反向翻页逐页与首次文件快照相同，全部离线阶段零请求。
同时核对关闭弹窗／书架后的旧回调不能重新打开页面。实际书架中没有空组；空组、长名称和不可用成员由独立合成场景覆盖。

真实账号配置只在 Linux tmpfs 中保存，凭据在匿名描述符／捕获管道中传递；结束后临时配置删除，
没有真实截图或人工目视验收，也没有账号数据写入。此前的独立插件实例绘制作为预验收保留，
不代替最终实际插件宿主的结果；具体范围和各次调用数量见[固定记录](validation-assets/2026-11-11/shelf-groups-and-popups.json)。
