# 原生章节云端书签

在墨水屏原生章节的微信读书菜单或快捷菜单中选择「保存云端书签」，插件会取当前视口中的文字位置，在后台分别核对账号、已保存章节、目录、书籍版本以及墨水屏与网页原文。只有两端来源一致且视口位置能够唯一对应原文时，才显示书签预览和确认入口；发送前再次核对来源与已有记录。未知回执保留待核对状态，不自动重发。

云端书签与 KOReader 本机折角分开保存。阅读页的云端角标显示当前页可定位的书签；同一页有多个书签时，点击角标可根据预览分别打开。翻页、关闭章节、切换账号、隐藏批注或休眠后，过期选择不会继续生效。已验证来源与笔记可在离线重开时显示，保存与删除需要联网。

两种屏幕尺寸的完整 KOReader 插件合成环境覆盖主菜单与快捷菜单、创建／删除、同页多书签分别打开、离线重开、原文变化阻止提交、结果不明确时禁止重发，以及账号和页面变化保护。合成服务之外，真实账号的一本书、一章先通过禁止发送预演，再在 KO2 分辨率的隔离原生阅读器中创建并删除一条新书签；两次操作各独立回读，原有记录、章节索引、书架及两端阅读位置的可观察状态保持。恰好两次账号数据请求，没有授权续期或自动重发，临时配置已清理。该早期真实往返使用隔离阅读器宿主，见[脱敏记录](validation-assets/2026-11-23/native-direct-bookmark-roundtrip.json)。

后续独立新建另一条测试书签，在两种模拟尺寸从另一章通过原生书签列表定位到相应原文，并在离线新进程重开；来源坐标、原有记录及两端位置均独立核对。该测试书签随后被删除并回读，恰好两次账号数据修改，原有可观察状态及章节索引保持，见[跨章验证记录](validation-assets/2026-11-23/native-direct-bookmark-cross-owner.json)。

该验证先只读核对两章和原始状态，创建后只允许定位新书签；若定位验证失败，会在独立确认该书签仍与测试记录一致后继续删除并回读。若记录或原有状态无法确认，则保留待核对状态并禁止自动重发。模拟服务已覆盖定位通过、定位失败后的清理和结果不明确时的停止保护。

随后另一条真实测试书签在两种模拟尺寸下显示角标并点击，确认打开的记录与书签一致；断网新进程重开后再次点击，本地 KOReader 批注保持不变。该书签创建和删除各一次并独立回读，原有可观察状态及章节索引保持，见[角标验证记录](validation-assets/2026-11-23/native-direct-bookmark-indicator-owner.json)。更多书籍及实体 Kindle 仍待验收。

书签批量索引优化后再次以真实账号进行核对：已有书签所在章节未通过当前可读权限筛选，因此选择可读章节中新建一条临时书签，两尺寸跨章定位、角标点击及离线重开通过；删除后独立回读，原有可观察状态和阅读位置保持。本轮恰好两次账号数据修改，未重发，详见[记录](validation-assets/2026-11-25/eink-bookmark-batch-owner.json)。现有书签的可读样本及实体 Kindle 仍待验证。

进一步合并正文扫描后，第一次试验遇到授权过期，临时书签已经核对并删除；该次跨章验证未完成，见[恢复记录](validation-assets/2026-11-25/eink-bookmark-scan-recovery.json)。另一次独立试验完成两尺寸的跨章定位、角标点击和离线重开，临时书签删除后独立回读，原有记录和阅读位置保持，见[验证记录](validation-assets/2026-11-25/eink-bookmark-scan-owner.json)。实体 Kindle 和其他真实书签仍待验收。
