# 原生章节云端书签

在墨水屏原生章节的微信读书菜单或快捷菜单中选择「保存云端书签」，插件会取当前视口中的文字位置，在后台分别核对账号、已保存章节、目录、书籍版本以及墨水屏与网页原文。只有两端来源一致且视口位置能够唯一对应原文时，才显示书签预览和确认入口；发送前再次核对来源与已有记录。未知回执保留待核对状态，不自动重发。

云端书签与 KOReader 本机折角分开保存。阅读页的云端角标显示当前页可定位的书签；同一页有多个书签时，点击角标可根据预览分别打开。翻页、关闭章节、切换账号、隐藏批注或休眠后，过期选择不会继续生效。已验证来源与笔记可在离线重开时显示，保存与删除需要联网。

两种屏幕尺寸的完整 KOReader 插件合成环境覆盖主菜单与快捷菜单、创建／删除、同页多书签分别打开、离线重开、原文变化阻止提交、结果不明确时禁止重发，以及账号和页面变化保护。合成服务之外，真实账号的一本书、一章先通过禁止发送预演，再在 KO2 分辨率的隔离原生阅读器中创建并删除一条新书签；两次操作各独立回读，原有记录、章节索引、书架及两端阅读位置的可观察状态保持。恰好两次账号数据请求，没有授权续期或自动重发，临时配置已清理。该真实往返使用隔离阅读器宿主，真实账号的角标点击、更多书籍及实体 Kindle 仍待验收。见[脱敏记录](validation-assets/2026-11-23/native-direct-bookmark-roundtrip.json)。
