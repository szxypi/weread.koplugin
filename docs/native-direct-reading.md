# 墨水屏来源的原生章节阅读准备

墨水屏章节可独立读取并整理为 KOReader 原生 EPUB，无需取得网页正文或网页位置。准备过程中核对账号、书籍、版本和阅读目录；账号或目录变化时停止，避免将旧章节交给新会话。缓存按账号和内容隔离，复用前核对记录、文件及正文和资源；无法核对或已损坏时保留旧文件并另存副本。

普通数字编号书籍的详情中可选择「阅读墨水屏章节（仅本机）」，联网读取墨水屏目录后选择有权限的章节，在后台准备并打开原生 EPUB。目录明确提示阅读进度和笔记不会同步到微信读书；无权限的章节不可选择。目录和下载遇到明确授权过期时复用已有的单次受保护续期，账号、页面或目录变化后停止旧操作。

书籍详情提供「阅读已保存墨水屏章节（仅本机）」；断网时选择原有墨水屏章节入口也会显示已保存列表。离线选择只需要仍登录保存章节的账号，不读取墨水屏授权或访问网络。列表按账号和书籍隔离，显示章节及版本；选中后在后台核对记录、整个文件和章节身份，损坏或变化时保留原文件。多个有效或损坏的副本分别显示，重新下载不会覆盖旧文件。

早于离线索引的章节不会自动出现在列表中；联网重新选择该章节时，如原文件核对通过会复用并补建索引。为限制损坏目录对设备的影响，每本书最多扫描 2000 个缓存条目；超过上限停止而不删除任何文件。

尚未接入跨章和本机续读位置入口；后续需补齐这些流程，并独立验证可用的云端位置及批注映射。此类缓存暂不作为网页书籍识别，也不发送手动阅读时长，避免混用不同来源的坐标；普通阅读路径不变。

章节内简单的排版样式可保留，复杂或无法安全识别的样式仍会拒绝。图片缺失默认停止；调用方明确允许时，用占位图替换并在正文显示提示。限流或账号变化仍会停止，不能当作缺图继续。

## 验证范围

合成服务在 600×800 和 1264×1680 尺寸下验证章节生成、缓存复用、损坏文件与记录保留、账号切换、目录变化和断网重开；图片缺失提示及严格模式也经过验证。真实账号的两个章节通过最终候选包的只读核对、独立正文比对和断网重开：一个章节在 KO2 模拟尺寸无缺图，另一个章节在两种尺寸均有两张图片不可用，已显示占位图及提示。整个章节验收没有修改账号数据，书架前后一致；正文和凭据未保存在验收文件，临时配置已清理。

验证开始时已保存的墨水屏授权过期，经独立核对后对同一账号续期一次；续期与上述只读章节验证分开。另一章节最初因内联样式被拒绝，增加受限样式支持后才继续；图片仍不可用，因此不能视为完整图片下载。这一轮仅验证后台，见[脱敏记录](validation-assets/2026-11-23/native-direct-reader.json)。

书籍详情按钮、原生章节列表和后台准备已通过两尺寸 KOReader 合成服务测试，生成的文件在断网新进程打开；真实账号两个章节也通过详情按钮、原生列表选章和离线重开，其中一个章节在两尺寸均有两张缺失图片。验证使用隔离详情宿主记录打开的文件，再由独立离线阅读器打开，并未覆盖完整插件实例内的阅读器交接；账号未写入、书架前后一致，见[脱敏记录](validation-assets/2026-11-23/native-direct-ui.json)。第一次合成界面测试因测试宿主未显示活动窗口而超时，增加窗口后通过。

插件内离线选章另在两尺寸通过合成 KOReader 测试：新进程禁网且不提供授权，覆盖普通入口自动切换、已保存入口、跨账号复制、账号切换、索引／记录／文件损坏、多副本以及旧缓存联网补索引。两个真实账号章节也在全新禁网进程通过书籍详情离线选章，其中一章的两张缺图仍保留提示；真实验收使用隔离详情宿主，打开路径再交由独立阅读器验证，未修改账号数据，见[记录](validation-assets/2026-11-23/native-direct-offline-ui.json)。实体 Kindle、完整插件实例内阅读器交接、离线跨章和云端同步仍待验收。
