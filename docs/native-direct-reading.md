# 墨水屏来源的原生章节阅读准备

墨水屏章节可独立读取并整理为 KOReader 原生 EPUB，无需取得网页正文或网页位置。准备过程中核对账号、书籍、版本和阅读目录；账号或目录变化时停止，避免将旧章节交给新会话。缓存按账号和内容隔离，复用前核对记录、文件及正文和资源；无法核对或已损坏时保留旧文件并另存副本。

普通数字编号书籍的详情中可选择「阅读墨水屏章节」，联网读取墨水屏目录后选择有权限的章节，在后台准备并打开原生 EPUB。阅读位置可同步，选中文字后可新建云端划线或私密想法；无权限的章节不可选择。目录和下载遇到明确授权过期时复用已有的单次受保护续期，账号、页面或目录变化后停止旧操作。

书籍详情提供「阅读已保存墨水屏章节（仅本机）」；断网时选择原有墨水屏章节入口也会显示已保存列表。离线选择只需要仍登录保存章节的账号，不读取墨水屏授权或访问网络。列表按账号和书籍隔离，显示章节及版本；选中后在后台核对记录、整个文件和章节身份，损坏或变化时保留原文件。多个有效或损坏的副本分别显示，重新下载不会覆盖旧文件。

早于离线索引的章节不会自动出现在列表中；联网重新选择该章节时，如原文件核对通过会复用并补建索引。为限制损坏目录对设备的影响，每本书最多扫描 2000 个缓存条目；超过上限停止而不删除任何文件。

原生章节的快捷菜单支持「搜索已下载章节」：后台搜索当前书籍同版本的已索引本机章节，可选择区分大小写，搜索词忽略空白；结果按批显示，并提示仅覆盖已索引下载。已知目录版本时只搜索同目录版本；同内容的缓存副本损坏时会尝试其他副本。选择结果后，插件重新核对账号、文件、正文锚点及当前页面，准确定位到同章或已保存的其他章节；无法核对时不猜测位置。搜索无需联网，也不会将本机锚点用于云端同步。两种尺寸的完整 KOReader 离线模拟覆盖同章、跨章和翻页中断，组件测试覆盖账号变化与损坏副本。一本真实书的两个相邻章节在两种尺寸以安装后的插件完成离线跨章搜索，打开页包含独立检索的原文；书架可观察状态及网页阅读位置前后相同，真实同章搜索及 Kindle 真机仍待验收，见[脱敏记录](validation-assets/2026-11-23/native-direct-search-owner.json)。

快捷菜单的「搜索整本书」也支持原生章节：联网搜索需要已验证的网页登录，定位时还需有效墨水屏授权。插件核对两端原文、账号、章节版本和搜索引用后才跳转；目标章节未保存时先询问，确认后只准备有阅读权限的章节，不自动购买。断网或缺少网页登录时转入已下载章节搜索；在线结果页也可带入搜索词切换本机搜索。两种尺寸的安装插件模拟覆盖同章、跨章、确认与取消下载、无权限、原文变化和离线回退；真实账号也通过同章、已缓存跨章，以及取消后确认下载可读目标的只读定位核对。Kindle 真机仍待验收，见[模拟测试](validation-assets/2026-11-23/native-direct-online-search-ui.json)、[真实账号记录](validation-assets/2026-11-23/native-direct-online-search-owner.json)和[缺章记录](validation-assets/2026-11-23/native-direct-online-missing-owner.json)。

阅读时可通过「微信读书·快捷菜单」或章末菜单打开目录、上一章和下一章。快捷菜单可从 KOReader 的微信读书工具菜单进入，也可绑定手势。离线切章只选择来自同一目录版本、确认为相邻的已保存章节；联网时若相邻章未保存，会重新核对目录和阅读权限后下载。不会跳过缺章，也不会自动购买。旧章节若缺少顺序记录，需联网重新打开该章节以补建记录。各章节沿用 KOReader 本机位置，切回已读章节可恢复本机页码。

阅读原生章节时，可在微信读书快捷菜单选择「核对本机阅读位置」。插件会后台重新核对账号、章节目录、缓存文件，并分别读取墨水屏和网页来源；只有章节原文逐字节一致，且当前页面位置能映射到原文时，才提示核对完成。页面、文件或账号变化时放弃旧结果；缺少授权、来源不一致或服务拒绝时不会猜测坐标。

快捷菜单还可选择「打开云端阅读位置」。插件读取并核对云端位置，同时校验原生章节与网页原文；云端位置在当前章且可精确定位时，可确认跳转。确认后会再次核对来源与云端位置，期间翻页、换账号或云端变化都会停止。云端位置位于其他章节时，可确认打开已保存章节，或在有阅读权限时下载后打开；切章后会再次核对账号、原文和云端位置，再跳转到原文。云端暂无位置、章节不可用或无法定位时保留当前页，或保留已打开章节的当前页。

快捷菜单还提供「同步本页到云端」：联网核对来源和云端状态后，确认将当前页面上传；确认后会再次核对，发生变化时停止。完成后需取得明确回执并独立回读；结果不明时保留待核对记录，不自动重发，再次选择同步可只读核对并归档。服务端原有全书百分比暂时保留，可能与新位置不一致。开启定时同步或关闭时上传，并在当前会话手动同步或核对后，翻页和关书可分别触发受云端基线保护的上传。完整插件手动、定时及关书写入已通过两尺寸模拟；真实账号在隔离原生阅读器中完成手动写入及原位恢复，定时与关书上传在测试宿主建立已核对基线后也各完成一次真实往返。实际 Kindle 和更多书籍仍待验收。见[同步验证](native-direct-upload-preview.md)和[选区说明](native-direct-selection.md)。

开启「本机记录离线时长及原生章节时长（含在线）」并启用 KOReader 阅读统计后，原生章节会在后台核对账号与章节文件，记录在线和离线阅读期间的有效时长；暂停、休眠、网络切换及切换账号时沿用本机账本的边界和去重保护。普通下载书籍仍仅在离线时使用此账本。记录以独立来源保存在当前账号账本中，可从「本机阅读时长」查看。历史记录可在「检查本机时段」中手动补传；当天原生章节记录可通过独立的「检查今日原生章节时长」入口手动补传。两者均仅处理北京时间、正版本的同一天时段，发送前核对账号、原生及网页来源、书籍版本和云端状态，并检查覆盖与重叠时段。本机缺少章节序号时，会从网页目录读取唯一序号，并在正文读取前后核对；目录缺少序号、重复或发生变化时停止。发送后需要成功回执与独立云端回读；结果不明时保留记录且不自动重发。无法找到唯一有效来源、缺少版本或无法核对章节序号的记录仍保存在本机。

两种尺寸的完整 KOReader 模拟使用真实统计插件验证了在线和离线阅读、网络切换、暂停恢复、切章、账号隔离，以及实际菜单查找并提交历史和当天时段给隔离的模拟传输服务；模拟服务与真实 SQLite 测试覆盖来源变化、回执丢失、跨午夜、只读复核和避免重复发送。原生章节的真实账号时长补传和实体 Kindle 尚未验收；此前普通下载书籍的真实时长验证不代表原生章节已验证。

可选开启「每 5 分钟自动同步原生章节时长」，默认关闭；开启时会同时启用本机记录，仍需启用 KOReader 阅读统计。阅读器处于当前页面且网络已连接时，插件检查当前账号、当前书籍当天的原生章节时段，并按批次核对与同步，不主动唤醒网络。历史日期仍需手动补传；若存在待核记录或回执不明确，自动同步停止，需在「本机阅读时长」中核对后恢复。两尺寸模拟以缩短的计时周期和隔离传输验证开关、后台执行与异常停止；真实账号自动发送、完整五分钟周期及实体 Kindle 尚待验收。

「本机阅读时长」显示自动同步的开启、等待和暂停状态。没有未完成补传时，可在此重试已暂停的自动同步；如果有未完成补传，页面先引导核对，重试也不会绕过发送记录。

缺少本机序号的处理另在两种模拟尺寸覆盖了本机查找与菜单入口，并用真实账号的一本书、一章验证了插件网页序号解析：测试故意不提供本机序号，目录前后稳定，版本和原生／网页正文摘要一致；该次只读验证未发送时长，见[脱敏记录](validation-assets/2026-11-23/native-time-index-owner.json)。

章节内简单的排版样式可保留，复杂或无法安全识别的样式仍会拒绝。图片缺失默认停止；调用方明确允许时，用占位图替换并在正文显示提示。限流或账号变化仍会停止，不能当作缺图继续。

章节正文或头部的简单内嵌样式表现可安全提取到原生 EPUB 样式中，并保留与已链接样式表的顺序；其中可识别的图片引用会按原章节路径定位并本地化。无法确认的样式属性、转义或复杂规则仍不会猜测处理。此修复针对真实书城结果中因内嵌样式而无法打开的章节；原始正文和其来源身份不变。
