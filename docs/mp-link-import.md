# 公众号文章链接导入

书架切换到「公众号」后，在右上角选项中选择「导入公众号文章链接」。输入微信文章链接后，插件在后台使用墨水屏授权查询文章编号，再以已登录的 Web 会话读取标题；标题暂不可用时保留占位名称。导入结果按当前账号保存在本机书库，可从同一菜单的「已导入的文章」打开。首次阅读复用现有公众号文章下载器；之后可离线打开缓存和保留的阅读记录。该操作不订阅公众号，也不修改云端书架。

支持 HTTPS 微信文章短链接和带必要身份参数的长链接，其他域名和不完整链接会被拒绝；仅将规范化链接发送到微信读书。子进程只回传校验过的文章身份与标题，账号、授权、页面或阅读会话变化、取消及休眠时不会提交旧结果。本地导入列表独立于公众号目录，重复导入不会覆盖已有条目或目录，最多保存 500 篇。真实正文不可用、账号无权阅读或微信验证限制时沿用现有文章下载器的错误提示与缓存保护。已导入文章所属公众号可从「管理公众号订阅」查看并选择订阅，见[订阅说明](mp-subscriptions.md)。

接口行为参考 [weread-omni 的公众号实现](https://github.com/teng-lin/weread-omni/blob/main/src/api/resources/public-accounts.ts)（MIT）；只使用接口行为与字段定义。一次已知公开样本的真实 Python 与 KOReader Lua HTTPS 查询返回相同文章身份及标题，独立回读确认书架、文章正文、授权和已有测试范围未变。该回执的两次查询均为只读解析，无账号数据修改或授权请求，见[脱敏记录](validation-assets/2026-11-17/mp-link-import.json)。其他文章、付费权限及公众号订阅尚需各自验证。

打包插件已在 600×800 和 1264×1680 模拟器中，以合成账号验证原生输入、后台请求、本地 SQLite、标题、文章下载、原生文档加载及全新进程离线重开；另验证重复记录、账号隔离、超时、取消和额度。实体 Kindle Oasis 2、更多真实文章，以及完整公众号目录和订阅仍待验证。
