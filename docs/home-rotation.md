# 首页快捷旋转与页面重排

首页「快捷设置 → 屏幕方向」提供竖屏、左右横屏和倒置竖屏，当前方向有选中标记。选择方向时调用 KOReader 的旋转事件，再按新的屏幕尺寸重新绘制首页；如果系统没有应用旋转，会提示失败。此入口不改变 KOReader 的默认屏幕方向或方向锁设置。

首页、书架和书城处于前台时，也会响应 KOReader 发出的屏幕方向变化。分页视图重排后优先回到按键选中的书，并恢复焦点。当前焦点不在书目上时，以原先页首的书为定位依据。连续书架按首条可见书目及其偏移恢复滚动位置，并恢复仍可见的书目焦点。旋转时仍然可以操作页面自己的菜单或搜索框，输入内容继续保留。关闭菜单或搜索框回到该页面时再重排，即使旋转时显示着屏幕键盘。其他窗口位于前台时，插件不会主动关闭它们或替换其后台页面。

书籍详情也会在屏幕尺寸变化后原地重排。详情保留当前滚动偏移与按键焦点，偏移超出新内容范围时停在末端。打开确认窗口时，详情仍可在它下方重排。关闭详情后，首页或书城优先回到原来聚焦的书，未聚焦书籍时保留之前首个可见的书目位置。

转屏后提交搜索，如果离线且找不到已保存的结果，当前页面会等提示关闭后按新尺寸重排并恢复焦点。如果打开了已保存的搜索结果，新列表会直接按当前方向显示。两种模拟尺寸用真实 KOReader 控件和独立的本机缓存验证了这两条流程。

使用打包插件及真实 KOReader 文件管理器，在 600×800 和 1264×1680 模拟屏幕、合成账号及离线书目上验证了四向选择、首页／分页书架／连续书架／书城重排及书目焦点恢复、关闭菜单或搜索键盘后重排、快速连续旋转和关闭页面后不再重开。测试环境已清理。实体 Kindle Oasis 2 的重力感应、按键和显示效果仍待验收。[方向菜单](validation-assets/2026-11-24/home-rotation-menu-ko2.png) · [普通尺寸横屏](validation-assets/2026-11-24/home-rotation-landscape-600.png) · [KO2 模拟尺寸横屏](validation-assets/2026-11-24/home-rotation-landscape-ko2.png)
