# 离线时长补传协议与原生签名层

当前已验证一次当前来源的时长请求与独立入账核对，并完成原生 Lua 的纯载荷模块。
这一步尚未接入历史账本、后台发送协调或插件补传入口，不能据此宣布离线补传功能完成。
原有本机采集与只读账本预览继续保留，见[前置说明](eink-readtime-prototype.md)。

## 两次受限实际测试

基于继续执行授权，使用人为控制的两秒测试窗口，没有领取或上传真实历史账本行。
参考 MiuRead 的只含时长载荷，经[接口目录](https://github.com/teng-lin/weread-omni/blob/88bd2e095d7d7ee423eaadf8f40653e72c5be6d4/docs/endpoints.md)确认端点；
原生 `/book/info` 版本、Web 目录版本与读取原文时的来源版本独立匹配后，才准备发送。
请求省略全部章节／偏移坐标，使用 `isResendReadingInfo=1`，发送前保留独立钥匙串意图并原子领取一次。
没有授权续期、通道回退或自动重发。

首轮只有一次 POST，收到明确成功，但统计核对出现预期外差异，立即停止。
该工具没有把月度／逐日统计基线摘要写入意图，所以不能事后补判完整通过。
只读诊断通过原先保留的逐书计数摘要重建原值，再独立读取两次，确认逐书 `readingTime` 增加两秒，
`recordReadingTime` 与 `ttsTime` 不变；原文、目录、全体原标记、本人想法、书架标记及 Web／原生精确位置一致。
旧试验保持 `UNVERIFIED`；通过再次只读审核后，将原记录封存为已消费状态，不能重新领取或提交，也未标记为验证通过。

新版使用独立协议和钥匙串条目，把统计基线摘要和捕获时区同时绑定。
[官方统计说明](https://github.com/Tencent/WeChatReading/blob/main/skills/readdata.md)规定时长按秒处理；
`readDays` 保留服务端口径，不再由正时长桶推导。单日测试只接受其不变或增加一天，实际增量另行记录。
统计日期仅在服务端日期与捕获时区日期两个明确候选中核对；其他日期、其他桶、额外秒数或计数减少均停止。
跨月候选在发送前阻止，等待对应的跨月读取协调，不能为了通过而只核对总数。

第二轮先对同一计划完成零提交预演，再仅发送一次新的两秒测试窗口，明确成功回执及独立回读均通过：

| 受检项目 | 实际结果 |
| --- | --- |
| 逐书 `readingTime` | 增加 2 秒 |
| 逐书 `recordReadingTime`／`ttsTime` | 不变 |
| 月度 `totalReadTime` | 增加 2 秒 |
| 单日时间桶 | 增加 2 秒，其他桶不变 |
| `readDays` | 不变，保留返回值 |
| 原标记／想法／书架标记 | 一致 |
| Web／原生精确位置 | 一致 |
| 新版待处理意图 | 已清除 |

本次捕获时区为 `+08:00`，两个日期候选相同，不据此宣称已验证不同时区的服务端归属。
两轮合计两次数据 POST、四秒测试时长；测试时长没有回滚，也不保证操作历史、排序或未返回字段完整恢复。
旧版已消费记录继续保存在钥匙串；其余活动试验意图为空，开发登录按要求继续保留到整体目标完成。

## 原生纯载荷模块

`weread/lib/readtime_protocol.lua` 提供严格区间验证、按小时分桶、捕获时区保留、客户端签名和外层签名。
每批最多 100 行／600 秒，同版本、无重叠、非未来时间；未知版本、无效时区、稀疏数组及额外字段拒绝。
载荷模块不代表有权发送，也不能代替账本归属、文件身份、覆盖日志和持久领取核对。
`guest_token` 的客户端默认值只是公开协议常量，始终仍须有效的本人墨水屏授权。

字节替换、排序和两次旋转／SHA-256 由独立参考向量核对，包含 UTF-8、多时区、跨小时和空签名分量。
随后使用真实来源配置和版本，完成 11 次 Python／官方 KOReader v2026.07.1 Linux ARM64 Lua 载荷比较；
包括实际来源及明确标为假设的小时／发送时区与分段组合，逐字段一致，零数据 POST。
这些是假设协议输入，不能描述为已上传的历史账本或其他书籍样本。
最初独立运行器未初始化 KOReader 的 JSON 路径，零提交停止；补齐 `setupkoenv` 后通过，原失败保留。

签名参考 [AnkioTomas/moon 的实现](https://github.com/AnkioTomas/moon/blob/43b2181da6eb5285b62114da85e1413d2f8464e4/book.koplugin/source/wechat/app.lua)，
MiuRead 原作者声明及 GPL 许可全文随候选包保留于 `integrations/licenses/`；本仓库原许可证与 NOTICE 未修改。
