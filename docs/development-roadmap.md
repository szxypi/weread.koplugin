# 开发与验收清单

目标：按优先级完善已有功能、迁移缺失功能，并完成自动化、真实运行环境和适用真机验证。
所有功能开发与测试通过后，再集中进行 Kindle 等墨水屏设备的性能优化。
本清单中的“实现”与“验收”分开记录，不以单元测试替代真实功能验收。
界面统一使用 KOReader 原生 Lua 控件，正文使用原生 EPUB 引擎；Web 仅作数据来源，
书籍资料在后台解析并缓存，不加载网页界面或执行网页 JavaScript。

## 验证层次

1. 单元与组件：数据整理、分页、取消、失败恢复、账号隔离、同步状态机。
2. 合成 HTTP：真实传输、错误响应、延迟、断线、空数据；不访问真实账号。
3. 真实 KOReader：打包后的插件、原生控件、字体、SQLite、EPUB 引擎、截图与交互。
4. 在线服务：真实授权、数据读取、写入后的回读确认、权限与限频行为。
5. 真机：实际屏幕、按键／触摸、休眠唤醒、网络恢复、性能和残影。
