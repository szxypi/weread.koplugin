# 云端书架加入与移除

入口：书籍详情 → 书架状态 → 加入／移出云端书架。
需要有效的墨水屏登录授权；读取方式的偏好不改变写入通道。读完、置顶和私密状态修改尚未接入。

打开操作时在后台读取完整的实时书架，按所选书籍编号确定加入或移除，并显示书名和原生确认窗口。
确认前不发送修改。预览固定账号、登录代次、授权修订、书籍编号、完整成员集合和所在窗口，最长有效两分钟。
关闭状态窗口、关闭微信读书页面、关书、休眠或换账号会撤销旧任务和按钮；迟到结果不能覆盖新窗口。

确认后先持久保存一个有界的每账号待确认记录，再创建发送工作进程。
记录只含账号摘要、登录代次、单本编号、操作、修订和随机尝试编号，不含凭据、书名或整份书架。
文件排他创建、同步、原子重命名、目录同步及主文件回读通过后才允许发送。
预检再读取完整书架：目标已经达到时只读完成；其他成员变化时停止并要求重新预览，不静默改变所选操作。
本次只提交单本 `bookIds`，没有批量修改、自动反向操作或重试 POST。

成功要求已实测的 `succ=true/1` 回执及独立完整书架 GET，核对目标成员和预期全体成员一致。
回读最多三次。回执缺失、HTTP 拒绝、超时、发送中取消或进程中断均保留待确认状态，重建服务不会重发。
可通过「核对待确认的书架修改」只读取得当前状态，再明确接受该状态，结束上一次核对；这一步不写云端。
同账号的新登录仍须核对旧待确认修改，旧登录或旧尝试的回调不能清除新记录。

本机快照由父进程保存到原有 SQLite 事务，并更新书架展示；云端成功但本机保存失败会提示刷新，不重复修改。
下载文件、阅读检查点、原生位置和进度／时长上报权限不由此操作改变。
读取授权过期时提示在设置授权或续期后重新预览，已可能发送的修改不会通过续期再发。
本机制不提供服务端原子条件写入，也不宣称协调任意其他进程或多设备的并发操作。
