# 真实新选区的原生零写入预演

已用实际账号的一本普通 XHTML 书籍、当前续读章节，完成 600×800／167 DPI 和 1264×1680／300 DPI 的原生选区预演。
本次选择与该章已有云端标记范围不重叠的唯一正文片段，不复用已保存划线。
生产编辑器生成的完整私密想法请求与独立 Python 模型一致，但在传输前被测试门槛拦截，**没有实际创建、编辑或删除账号数据**。
不能据此判断新选区是否被服务端接受、是否产生关联划线，或删除想法后是否保留其他服务端记录。

## 已核对的流程

1. 独立读取 Web 原文、目录及位置，以及原生书架标记、本人想法、划线、精确位置和书籍版本。
   按原始 HTML 字符范围排除已有标记，选择唯一正文窗口；原始范围与筛选后 UTF-16 位置分别计算。
   重叠出现的相同文字也按非唯一处理，不使用只统计不重叠子串的次数。
2. 从真实书架打开详情「阅读」，由插件下载章节并交给实际 KOReader 原生引擎。
   在原生正文中定位两个选区端点，经实际选区菜单进入「写私密想法」，核对完整原生引用。
3. 保存并恢复本机草稿，显示引用和正文确认；生产后台服务在预览和提交时分别核对最新原文、目录与原生书籍版本。
   请求中的章节编号、原始范围、引用、私密标记、版本和测试文字逐字段与独立模型一致；不猜测原生 `chapterIdx`。
4. 生产操作记录已进入 `pending` 后，测试专用 SQLite 门槛核对完整请求并禁止网络派发。
   每种尺寸只拦截这一次新建；后续重复提交在生产服务内被阻止，不新增 HTTP。
5. 关闭后启动全新原生进程，离线恢复同一选区草稿和 `pending`，零 HTTP、零自动重发。
   阅读器原有本机附注与精确来源目标保留；最后由宿主独立核对原有云端想法、划线、书架状态和精确位置未变。

两种尺寸各经过联网／离线两个原生进程，后台工作进程、SQLite、真实 HTTPS 和原生 EPUB 引擎均实际执行。
这不是手势硬件或人工目视验收：没有真实截图，没有公开书籍标识、原文、引用、位置或凭据。

## 一次续期与请求范围

首次预检在原生书架 GET 收到 HTTP 401 后停止，没有启动原生预演或创建测试意图。
沿用既有维护授权，仅续期一次，并核对同账号书架及钥匙串保存回读；随后两种尺寸均通过。
包含初次失败、该次维护、两份独立预检、正常原生流程和最终回读，本批共 **117 GET、45 个既有内容读取 POST、1 个授权 POST、0 个账号数据 POST**。
每个联网原生进程另有七次只读笔记／资料 GET；新建请求只被本机门槛捕获，没有转发。
45 个读取 POST 是目录和章节内容的既有接口，不是修改笔记或进度。

凭据和真实文字通过捕获管道及内存传递；下载文件、草稿、缓存与测试门槛仅在私有 tmpfs。
有效授权未进入配置文件，工作进程回收、临时配置删除及安装字节核对均通过。
项目 Web 与墨水屏登录继续保存在钥匙串，未因单次预演删除。

## 工具与验证

`scripts/verify_owner_selection_preview.py` 默认离线，只有配对的 `--saved-session --native-ui-command …` 可运行本流程。
没有 `--apply`、续期模式或跳过门槛的开关；JSON 本身不能开启原生附加流程。
原生运行器需显式 `--selection-thought-preview`，也拒绝与其他附加流程组合。
模拟运行入口为 `scripts/test_owner_selection_preview_runtime.py`，需提供 KOReader、尺寸和新的运行目录。
仅接受固定合成账号／登录的独立本机模拟端口，不接受真实账号经该模式转发。

- 两尺寸合成原生预演／离线重开通过，模拟服务独立确认没有收到任何账号修改或授权 POST。
- 12 项新边界测试覆盖无登录默认、无执行／续期开关、不重叠及重叠重复文字、账号／来源／载荷隔离、原生序号猜测拒绝、严格结果结构、安装与清理、未知结果和私密诊断不泄露。
- 旧阅读、来源候选、批注、进度预览及限定进度执行器的离线契约另经回归；原有生产文件未改。
- 完整检查为 77 份 Python／941 项零跳过、211 组 Lua、584 个静态文件零警告／错误、586 个 Lua 语法、226 个 Python 编译、四时区、命名空间和 TLS。
- 两份候选的 236 个生产文件与基线 `ce3213a`、当前源码、实际模拟及真实安装内容逐字节一致。
  真实结果、请求计数、候选和工具摘要见[固定证据](validation-assets/2026-11-11/owner-selection-preview.json)。

早期合成用例的相对 URL、书架范围和文字坐标断言错误已修正；旧失败未计入成功。
模拟门槛最初只登记一本书，错误拦截了正常后台书架进度读取，现按完整合成书架登记明确编号，仍不允许任何数据修改。
