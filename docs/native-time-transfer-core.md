# 原生历史时长任务与持久回执

原生发送底层已实现。后续[原生账本与后台服务](native-time-transfer-ui.md)已接通分批提交及待核恢复；下文保留底层阶段的独立验收范围。
本阶段只使用合成数据与模拟 HTTP；没有访问真实账号、重发旧请求或替换原两秒采集。
[上一阶段零桶规则](readtime-zero-buckets.md)的实际只读证据继续保留。

## 来源、发送与核对

`readtime_transfer_task` 要求调用方提供当前账号、被冻结的账本选择、缓存来源引用和持续有效的取消条件。
它从原始行及选区重新构造协议区间，逐项核对，拒绝把同样秒数挪到另一个小时、文件或版本。
当前范围为数值书号、同一下载文件、正版本、同一北京时间历史日；当天记录、跨日混批和其他时区不发送，原记录保留。
发送任务一次仍接收最多 128 个来源引用。原生界面在章节较多时先通过后台任务按每批最多 32 项查找，核对缓存文件身份、原文及渲染摘要后，只把匹配的引用交给发送任务；该任务会再次独立核对本地和线上来源。目录最多支持 10,000 章；停止或找不到来源不会领取或发送时长。CB_ 等边界仍需继续完善，不能修改原时间或静默丢弃剩余记录。

`readtime_source` 独立打开 EPUB，核对嵌入身份、原始和渲染字节摘要，再核对线上原文及前后目录版本。
整个任务不访问父进程的原生文档句柄，不解压正文到磁盘，也不执行网页代码。
线上来源核对新增可选目录观察回调，原有调用的返回结构和默认行为保持。

发送前读取完整原生／Web 位置摘要、逐书三项计数、书架状态及历史／当前月份的四字段时长投影。
新鲜签名载荷由已验证的原生协议模块生成；账本片段、覆盖区间和来源分组须一致，持久领取先于唯一 POST。
不续期、不更换通道、不重发。未领取的准备可取消，可能已发送的记录继续隔离。

明确回执先写入 `acknowledged`，不能据此结算。最多四轮只读等待，须有两轮稳定目标观察；
原日期及逐书时长只增加本批秒数，所核对月份其他日桶／计数保持，仅允许已出现的零桶消失并记录数量。
随后再次核对来源和完整目标快照，才保存核对证据并确认；成功回执、核对证据与本机账本结算分开保存。
日期变更、来源／位置／计数变化、回执丢失、保存失败或取消均停止，不能把未知结果改成成功。

## SQLite 迁移与恢复

覆盖数据库在同一写锁下为旧表添加证据列，并升级包含 `acknowledged` 的唯一活动记录索引。
迁移保留原计划、编号、行和请求摘要。确认要求两次回读证据；旧 `confirmed` 行若缺少证据，不会自动结算。
`acknowledged` 重开后也不会自动结算、取消领取或重发。

已核对但结算中断的记录仍为 `confirmed`，重开只做幂等本机结算。
成功后保留 `settled` 请求及证据，永久排除区间继续合并保存；不会删除回执审计。
无法核实的确认回执可保留为 `retired_acknowledged`，账本记为未知并保留排除区间，不恢复发送次数。

## 已验证范围

合成测试覆盖正常、延迟、当天误入账、位置／其他计数／来源变化、回执丢失、途中取消、错误账号、
小时区间挪动、文件／版本变更、回执保存失败和结算失败。使用实际 SQLite，旧请求不能再次领取。
单次任务为 580 个检查；账本状态／迁移为 132 个检查；纯归属为 11 个检查，来源单元为 40 个检查。

官方 KOReader 运行环境还分别使用原生 JSON／SQLite 执行任务、数据库迁移及故障测试，
并在真实子进程中重复任务。独立 libarchive 实际写入／重开合成 EPUB，来源检查及五次重复读取通过，文件描述符数量保持。
两个竞争进程恰好一个领取成功；跨进程在线覆盖排除、取消拒绝和幂等结算回归通过。
这些均为合成来源和模拟请求，不能代替真实账号发送或正常菜单流程验收。

最初原生运行在测试触发器创建时停止：运行时的多语句执行器不能拆开触发器内部的分号；
改用完整语句准备后通过，没有放宽生产数据库或发送条件。
一次竞争测试因新加元数据字段引用了错误变量而停止，修正测试引用后通过，失败记录均保留。

完整检查：135 个 Python 模块／1715 项，262 组 Lua，748 份 Lua 语法，746 份静态检查，零跳过／警告。
固定记录见[原生任务底层证据](validation-assets/2026-11-17/native-time-transfer-core.json)。

后台服务、按日分批提交、同插件上报互斥、只读恢复及两尺寸原生界面现已另行实现并以合成数据验收，见[后续界面阶段](native-time-transfer-ui.md)。
真实写入只能使用新的实际窗口，不能重新使用已消费的旧两秒；实体 KO2 与设备故障验证仍待完成。
