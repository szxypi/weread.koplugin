# 从本人云端划线查看原文

「我的云端划线」的文字弹窗新增「查看划线原文」。只有具备有效章节、范围和文字的划线显示此按钮；书签、未知类型、缺失范围及「我的云端想法」不显示。
从书籍详情或阅读菜单均可进入，原生按钮打开 KOReader 的原生 EPUB 阅读器，不加载网页界面。

优先核对当前文件、对应单章缓存、整书缓存和其他明确关联的缓存。
已下载原文可以离线定位；未找到匹配章节时，联网提示下载，由用户确认后只下载对应章节，重新核对来源后再打开。
新下载不附带公共批注请求，也不在下载完成前先打开默认章节。
云端想法的创建／编辑／删除仍见[独立实验准备](private-thought-experiment.md)，本功能不消费那份待授权计划。

## 范围转换与来源核对

微信读书划线的 range 在本批样本中是去除开头 BOM 后的原始 HTML Unicode 字符范围，包含标签。
现有阅读位置使用过滤后的 XHTML UTF-16 坐标；两者不能直接互用。
先由独立 Python 逐条验证，再接入 Lua：

1. 核对书号、章节、有效范围及服务端保存的完整划线文字。
2. 从原始范围提取正文，排除 head、注释、脚本与样式，不接受截断的实体。首轮 51／52 条精确匹配；剩下一条独立核对确认仅首尾空白不同，允许仅裁除两侧空白后 52／52 通过，中间空白与文字仍必须一致。
3. 以完整原文验证文字身份，用最多 1,024 个非空白字符和两侧有界上下文识别第一处被选中的可见字符。短引用、重复文字必须由唯一上下文消歧；重叠坐标、实体内部、歧义与正文变化均拒绝，不选择最近结果。
4. 输出原文字节摘要与本机坐标。独立后台重新打开 EPUB，核对书籍／文件身份、章节元数据、原始正文和实际渲染成员，再复用既有来源导航器。
5. UI 进程只读取小份元数据并遍历原生 DOM，确认目标实际可见后保留精确来源位置。解析、正文散列、归档读取及缺章目录请求均在后台，正文不通过窗口回调传回 UI。

原始引用保留不变，没有用模糊文字替换完整范围核对。
引用很长时仍核对全部文字，实际定位上下文受现有 8 KiB 锚点限制。
`upload_verified=false` 始终保留，查看划线不授予云端坐标上传权限。
本批也修复了原始引用扫描将 HTML 注释中 `>` 后的文字误当正文、将字面 `<3` 当标签的问题；默认原有批注扫描仍可使用，新增正文限定选项供划线定位使用。

## 页面与阅读会话

每次查找绑定其划线页面、缓存快照、账号、授权范围、文档、阅读会话及当前视口。
关闭、取消、休眠、切书、账号变化或刷新替换快照后，旧结果不能打开文件；旧取消操作不能取消新请求。
下载确认属于当前查找，关闭划线页会取消所属下载；下载完成后等待任务释放，再核对新文件。
跨文件交接只使用一次，并复核新阅读器、路径、来源元数据与阅读代次；过期交接不能重复导航。
未知回执、云端待确认进度等既有同步状态仍由原有同步服务控制。

入口本身不发送云端笔记或阅读数据修改；正常阅读的既有同步／时长设置继续生效。
真实验证配置关闭所有上报，并在原生进程拒绝全部插件 HTTP 调用；验证前后另行读取云端位置。
本机选中位置通过既有阅读记录保存流程处理，取消或定位失败不删除原文件的已存记录。
如果跨文件打开后才发现来源或 DOM 无法匹配，可能停留在新文件的默认位置；不会把这个位置当作成功定位。

## 验证与限制

独立协议读取选择一本含 52 条划线的书，逐章读取两次，共 5 个章节；完整划线与精确云端位置在前后保持一致。
Lua 在 KOReader 运行环境中的 52 个结果与 Python 独立模型完全相同。
原生验收使用同次读取的私人正文和划线，在 tmpfs 中通过生产打包器创建五个单章及一个合并缓存；
再经实际 PluginLoader／FileManager 的详情入口、原生弹窗按钮、ReaderUI 和来源导航器核对。
首进程使用单章间交接，新进程从离线合并缓存反向逐条定位。账号范围经匿名描述符提供，无登录凭据或真实截图。
这是实际数据的离线缓存定位验收，缺章的真实联网下载路径没有在本批对真实账号执行；下载与取消另由组件检查及原有下载组合覆盖。

合成原生场景覆盖中文、实体、表情、短引用、跨文件与合并缓存，另验证真实子进程取消／回收和旧忙碌框操作失效。
合成截图可以目视检查，模拟字体缺少部分表情字形的限制仍保留，原始文字未改变。
定位验收候选、两尺寸结果、请求台账及检查范围见[固定记录](validation-assets/2026-11-11/my-mark-navigation.json)。
后续私密实验还修正了想法模型的章节编号类型，最终候选仅该模块与定位候选不同；该模块已单独重做真实三条想法的两尺寸浏览与混合数字／字符串编号合成回归。
定位、首页及普通阅读的历史结果仍绑定各自候选，不把未重新运行的场景描述为最终候选的逐字节安装验收。

本批限定普通数字书号、带可靠原始来源记录的 XHTML 缓存；旧缓存缺少来源记录时需要重新下载。
TXT 范围语义、想法引用跳转、更多书号类型、真实缺章下载组合及实体 KO2 尚待验证。
本机未检测到 Kindle USB 或 KOReader 挂载目录，真机按键／休眠／断电及整体功能清单仍未完成，集中性能专项尚未开始。
