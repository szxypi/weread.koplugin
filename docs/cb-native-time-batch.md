# 导入书原生阅读时长请求验证

2026-11-18 使用自造 EPUB 和本人账号验证了导入书（`CB_`）的原生阅读时长请求。整个过程只写入新建测试书，不修改既有书籍；两本测试书均已删除，原书架成员、分组和标记已独立回读核对。每次正时长请求最多发送一次，不重发。

第一本测试书发送不带摘要的两秒请求后，服务端计入了阅读时长，章节、位置和百分比未变，但原有摘要在原生及网页接口中均消失。原自动核验因此保持未验证状态；后续独立只读审计确认上述结果，并单独清理测试书。此结果表明导入书请求不能使用空摘要。

第二本测试书发送包含完整原摘要的两秒请求。服务端成功回执；原生与网页位置及摘要保持一致，书籍计数、当天和当月时长均增加两秒，其他阅读计数不变。测试书清理及原书架恢复经独立回读确认。六本已有导入书的版本另经只读核对：原生元数据与网页目录版本一致。

实验补传通道现已接入来源校验、快照、一次性发送记录及独立回读，摘要只参与内存中的构造，不写入发送记录。发送前要求原生与网页位置、完整摘要和时长计数一致；回读时两端计数和日月统计均达到目标才确认，允许一端短暂延迟。来源核对绑定本地文件和章节内容，并要求两次目录读取中所有存在的版本字段一致。缺失或冲突时停止；回执不明不会自动重发。

实验通道必须显式启用内部测试开关，普通队列和界面仍不选择导入书。当前测试使用合成历史记录，真实账号的两秒试验仅覆盖实时段；尚须验证真实跨日离线记录的日期归属、计数与异常恢复，也未在 Kindle KO2 真机上验证。

2026-11-18 已在隔离的 KOReader 环境中使用已有导入书实际采集 6 秒离线阅读。采集前后分别只读核对原生和网页的来源、版本、阅读位置、计数及书架状态，没有上传阅读时长。记录及其 EPUB、账本和覆盖范围证据保存在独立的本机钥匙串中；之后用独立 KOReader 进程核对了原始记录、文件及覆盖范围，确认当日不会选中补传。此记录最早可在北京时间 2026-11-19 00:00:01 参与跨日验证，尚未发送。
