# 书籍公开书评

书籍详情中的「书评」提供推荐和最新两个分类。首次显示一页；服务端表明还有更多时，可在列表末尾选择「加载更多结果」。每个分类单独保存当前会话中已加载的结果，切换分类不会重复请求；加载失败时已显示的内容保留，可再次尝试。评分按微信读书的五星量表显示。公开书评仍使用微信读书 Skill 授权；微信读书登录本身不代表已启用 Skill。

分页遵循 [微信读书官方书评接口说明](https://github.com/Tencent/WeChatReading/blob/main/skills/review.md)：使用上一页最后一条的 `idx` 和返回的 `synckey` 请求下一页。同一书评编号只显示一次；如果服务端声明还有更多，却没有有效游标或返回已使用过的游标，则停止本次加载并保留原结果，避免重复请求导致死循环。关闭页面后，已经排队的请求结果不会重新打开页面。

## 验证及限制

模型和界面组件测试覆盖五星换算、多页合并、重复记录和游标、错误响应、分类缓存、请求失败与关闭页面；由于当前没有 Skill 授权，本次分页没有用真实 Skill 接口或实体 Kindle 验收。现有网络任务仍由界面调度，慢网络下的后台化及大量书评的渲染优化尚未完成。

为探索不依赖 Skill 的墨水屏接口，对已保存会话进行了只读请求：一种列表类型返回了其他书籍记录，不能用于本书书评；另一种类型在两本书的样本中返回的记录均属于目标书籍且类型为点评，但改变参数后返回条数与请求条数、返回的更多标记并不一致。此观察不能证明其推荐／最新语义或分页完整性，因此暂未将该通道接入书评页，后续需继续核实。请求没有修改账号数据，未保存书评文字或凭据。
