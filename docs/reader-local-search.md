# 阅读器中的本机搜索

阅读器快捷菜单现在区分「搜索当前文件」与「搜索书城」。前者打开 KOReader 原生全文搜索，输入后可使用 KOReader 提供的搜索方向和结果操作，无需联网；后者仍进入微信读书书城搜索。

搜索范围是当前打开的文件。如果打开的是整书 EPUB，搜索覆盖这个 EPUB；如果打开的是下载的单章，只搜索该章，尚未下载的其他章节不会自动加入本机搜索。同一菜单另有需要联网的[整本书搜索](cloud-book-search.md)。当前阅读器没有提供原生搜索模块时，本机搜索按钮显示为不可用。打开菜单后若已切书或关闭阅读器，延迟的搜索动作不会在另一本书中执行。

快捷菜单还提供「搜索已下载章节」，可跨文件检索当前书已缓存且附有原文索引的章节，支持普通书籍和导入的 `CB_` 书籍，退出登录后也能使用。搜索区分大小写、忽略空白，在后台逐章进行，可以中止后继续；结果列表显示未能搜索的章节数量，达到 1000 条时提示结果可能不完整。点击结果前会再次核对缓存文件身份、正文和渲染内容；无法安全定位的匹配会被省略。搜索和跳转不会请求网络，也不会授予云端进度上传权限。目录缺失时只能检索已关联的单章缓存，结果不能跳转，需先联网更新目录；未下载、旧格式或缺少原文索引的章节不在搜索范围内。

合成书籍在实际 KOReader 环境的 600×800 和 1264×1680 屏幕下验证了取消、继续、离线跨章定位、退出登录及目录缺失提示，未产生网络请求；另一段真实账号正文通过只读的原文坐标和缓存重核验。实体 KO2 仍待验收。

用合成正文在实际 KOReader 运行环境完成 600×800 与 1264×1680 两种尺寸的交叉测试：整书和单章各从快捷菜单进入原生搜索，定位到文件靠后的目标；随后关闭模拟服务，以全新进程重开同一文件再次搜索。四组均未产生模拟服务请求。另核对书城搜索仍执行原有动作，以及切书／关书后的延迟动作失效。截图只含合成内容：[600×800](validation-assets/2026-11-18/reader-search-600.png) · [KO2 尺寸](validation-assets/2026-11-18/reader-search-ko2.png)。真实微信读书账号与实体 KO2 的该入口尚未验收。
