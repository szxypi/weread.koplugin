# 阅读器中的本机搜索

阅读器快捷菜单现在区分「搜索当前文件」与「搜索书城」。前者打开 KOReader 原生全文搜索，输入后可使用 KOReader 提供的搜索方向和结果操作，无需联网；后者仍进入微信读书书城搜索。

搜索范围是当前打开的文件。如果打开的是整书 EPUB，搜索覆盖这个 EPUB；如果打开的是下载的单章，只搜索该章，尚未下载的其他章节不会自动加入本机搜索。同一菜单另有需要联网的[整本书搜索](cloud-book-search.md)。当前阅读器没有提供原生搜索模块时，本机搜索按钮显示为不可用。打开菜单后若已切书或关闭阅读器，延迟的搜索动作不会在另一本书中执行。

快捷菜单还提供「搜索已下载章节」，可跨文件检索当前书已缓存且附有原文索引的章节，支持普通书籍和导入的 `CB_` 书籍，退出登录后也能使用。搜索可选择区分大小写，或忽略大小写；后者在 KOReader Unicode 组件可用时支持多种文字，例如 `STRASSE` 可找到 `Straße`，希腊文及带重音字母也可匹配。两种方式均忽略空白，结果摘要保留原文中的词间空格。若 Unicode 组件不可用，界面会明确回退为仅忽略英文大小写。当 KOReader 的 Unicode 规范化功能可用时，常见预组字符与分解字符、组合重音的不同顺序及韩文组合形式也可匹配；缺少该功能时仍保留已有的大小写搜索。搜索在后台逐章进行，可以中止后继续；结果列表显示未能搜索的章节数量，达到 1000 条时提示结果可能不完整。点击结果前会再次核对缓存文件身份、正文和渲染内容；无法安全定位的匹配会被省略。搜索和跳转不会请求网络，也不会授予云端进度上传权限。

当有未覆盖章节、目录或索引不完整、结果达到上限，或部分匹配无法安全定位时，提示位于结果前；需要补全时，下载全书和获取目录的入口也位于结果前。达到结果上限后仍可主动选择补全；取消下载保留已有结果。两种模拟尺寸的原生界面通过上限提示、下载确认取消和零请求核对，上限在该测试中调低为两条；缺目录恢复、跨章跳转和全书下载另经回归，实体 KO2 尚未验收。见[记录](validation-assets/2026-11-19/cached-search-coverage-actions.json)。 另在两种尺寸以普通书和导入书确认：退出登录且缺目录时搜索、定位及新进程离线续读可用，原待同步记录保留。早期尝试因夹具先注入模拟账号、重开时又推进登录代次而失败；修正夹具后重新核对退出状态通过。

搜索完成后，如果已有完整目录且部分章节未覆盖，可以选择下载全书并使用同一搜索词和大小写选项重新搜索。关闭搜索会取消属于该搜索的下载，正在阅读的文件不会被作为下载目标；无法索引的章节仍会计入未覆盖数量。该流程已在两种屏幕尺寸的 KOReader 合成环境验证，并在 1264×1680 隔离环境使用一本真实账号导入书完成 57 章下载和搜索；实体设备仍待验证，详见[导入书搜索](cb-book-search.md)。

补充的两尺寸原生验证在完成首章后关闭搜索并重启 KOReader：下载停止，待同步位置保留，重新下载时复用已完成的首章且不重复请求；完成后仍可搜索并定位。一次早期测试在下载器尚未推进索引时过早断言，调整等待条件后通过；该次不代表产品恢复失败。

忽略英文大小写选项以合成中英文正文核对了原文坐标、显示内容及分页续查；在 600×800 和 KO2 尺寸的实际 KOReader 环境中，对导入书籍合成整书验证了取消、继续、离线跨章定位和新进程续读，原待同步记录保持不变。该轮仅覆盖英文大小写；更多语言的后续验证见文末，实体 KO2 仍待验收。

目录缺失时，插件会读取已关联的单章以及整书缓存中的原文索引，临时发现可搜索章节；无法核对的章节会提示索引不完整，这不会重建或替代云端目录。联网后可在搜索结果中选择获取章节目录：后台保存成功后用原搜索词重新搜索，并显示未下载章节数量及下载入口；取消或获取失败保留原有结果。两种屏幕尺寸的原生模拟和一本真实账号导入书的隔离验证均通过，真实验证覆盖 57 章目录、取消、重搜、合成待同步位置保留，以及书架、目录和云端位置独立回读；实体设备仍待验证，见[脱敏记录](validation-assets/2026-11-18/owner-cached-catalog-restore.json)。定位后的阅读位置保存在 KOReader 的章节或整书文件中，书架续读会在核对缓存后优先打开该文件，原待同步记录保持不变，且该阅读会话不自动同步。缓存发生变化时会询问是否尝试打开已有缓存；目录恢复后，仍按原待同步位置进行正常核对。未下载、旧格式或缺少原文索引的章节不在搜索范围内，可使用 KOReader 的「搜索当前文件」查找当前文件中的正文。

合成书籍在实际 KOReader 环境的 600×800 和 1264×1680 屏幕下验证了取消、继续和离线跨章定位。早期退出登录测试被模拟环境自动注入登录，不能证明退出状态；修正测试后，两种尺寸的普通书和导入书均在确认退出状态后通过本机搜索与跨章定位，见[更正记录](validation-assets/2026-11-19/signed-out-book-search-fallback.json)。目录缺失时，两尺寸的单章及整书索引搜索、定位、新进程通过插件续读以及原有待同步记录保留通过；缓存校验失败后取消和确认回退也通过，未产生网络请求。另一段真实账号正文分别与合成章节组成隔离测试文件，在两尺寸通过离线原生定位、新进程插件续读与只读坐标核验；这不代表真实整书全部章节均已验收。实体 KO2 仍待验收。

随后选取一本真实 `CB_` 书，逐章只读核对全部 57 章的来源及目录。使用这些正文构造隔离整书缓存并移除目录后，两种模拟尺寸均完成 57 章搜索、一个唯一结果的原文定位，以及全新进程从插件续读；原有待同步位置使用合成数据验证保留。测试进程阻止 IPv4／IPv6 连接，原书云端进度和书架在界面测试后独立回读未变，目录及版本在读取前后相同。书名和章节标题为合成文字，原图与原始样式未纳入，不代表这些资源或其他书籍已验收。范围见[脱敏记录](validation-assets/2026-11-18/real-full-offline-search.json)。

用合成正文在实际 KOReader 运行环境完成 600×800 与 1264×1680 两种尺寸的交叉测试：整书和单章各从快捷菜单进入原生搜索，定位到文件靠后的目标；随后关闭模拟服务，以全新进程重开同一文件再次搜索。四组均未产生模拟服务请求。另核对书城搜索仍执行原有动作，以及切书／关书后的延迟动作失效。截图只含合成内容：[600×800](validation-assets/2026-11-18/reader-search-600.png) · [KO2 尺寸](validation-assets/2026-11-18/reader-search-ko2.png)。真实微信读书账号与实体 KO2 的该入口尚未验收。


2026-11-18 修复个人导入书的 TXT 来源在离线搜索后不能定位的问题：本机搜索结果现在独立核对归档、原文和章节身份后定位，仍不授权云端位置上传。两种屏幕尺寸的实际 KOReader 使用合成 TXT 与 XHTML 验证 Unicode 大小写匹配、德语展开、重音和希腊文字母；包括个人书单章、缺目录整书、跨章跳转与新进程断网重开。源文件变化、半个展开字符、结果续查和缺少 Unicode 组件另有边界测试。早期个人 TXT 测试因误用了云端来源限制而失败，修复后重跑通过；没有真实账号写入。截图仅含合成文字：[普通尺寸](validation-assets/2026-11-18/cached-unicode-search-600.png)、[KO2 尺寸](validation-assets/2026-11-18/cached-unicode-search-ko2.png)。该轮未验证真实账号 Unicode 搜索；后续真实章节验收见下文，实体 KO2 尚未验收。见[固定结果](validation-assets/2026-11-18/cached-unicode-search.json)。


组合字符匹配随后在两种模拟尺寸的实际原生阅读器中完成：使用预组查询搜索分解形式、使用分解查询搜索预组形式，均核对到原文位置；还验证重音顺序调整、TXT／XHTML、跨章跳转和全新断网重开。匹配不会把一个带重音字符的部分内容当成完整结果，搜索坐标仍绑定原文。规范化组件不可用时沿用原有大小写功能，实际设备与更多文字仍待验收。截图仅含合成内容：[普通尺寸](validation-assets/2026-11-18/cached-canonical-search-600.png)、[KO2 尺寸](validation-assets/2026-11-18/cached-canonical-search-ko2.png)，见[脱敏记录](validation-assets/2026-11-18/cached-canonical-search.json)。


真实账号只读验收进一步从六本个人导入书中选择一章，使用独立计算的全角字母搜索词匹配真实正文，并在两种尺寸分别验证单章缓存与双章整书缓存的搜索、原文定位和新进程离线续读。真实章节以外的章节与待同步位置均为合成数据，真实正文和凭据仅经过内存、管道及临时内存文件系统；没有真实截图、账号数据写入或授权请求。测试后独立回读的所观察进度字段、书架及分组、目录和版本均与事前一致。此项验证全角字母的 Unicode 匹配，不代表真实账号的组合重音或完整书籍均已验收；后续另验证一个可分解字符的真实章节，实体 KO2 仍待验证。见[脱敏记录](validation-assets/2026-11-18/owner-unicode-cached-search.json)。


真实账号随后另选一章含可分解字符的个人导入正文，使用该原文片段的分解形式搜索，在两种尺寸分别完成单章与双章整书缓存的原生定位及全新离线续读。两次测试的其他章节、书名和待同步位置均为合成数据；测试后独立回读的所观察进度、书架与分组、目录和版本保持一致，未发送账号数据或授权请求。一次早期尝试在只读来源准备阶段停止，原因未保留，不能视为通过；扩大有界样本检查后独立重试才完成。该结果不代表全部语言、真实整书或实体设备已验收，见[脱敏记录](validation-assets/2026-11-18/owner-canonical-cached-search.json)。

## 较大章节编号

已下载章节搜索现在保留章节编号的完整十进制字符串，支持超过 32 位以及超过 JavaScript／Lua 数值精确范围的编号。搜索结果仍需核对正文、归档和来源身份后才能定位；缺少目录时的离线续读也保留精确编号。兼容旧版数值键缓存，但只在数值可以精确表示时使用该回退，避免相邻编号误指向同一章节。这不改变云端搜索或云端进度写入支持范围。

使用相邻的大编号构造的章节已通过来源绑定和防误配测试；600×800 与 1264×1680 两种 KOReader 模拟尺寸分别验证单章缓存搜索／定位，以及退出登录、缺少目录时的整书搜索、定位和独立进程离线重开，均无网络请求。首次整书重开未通过，原因是旧的无目录续读校验仍限制章节编号；修复后两尺寸重测通过。

真实账号只读抽查了五本导入书的 307 个目录条目，没有发现超过 32 位的章节编号；该样本没有真实大编号，不能证明真实服务数据或实体 Kindle 已验收。检查没有修改账号数据或续期授权。详见[脱敏结果](validation-assets/2026-11-19/cached-search-large-chapter-ids.json)。
