# 云端分组管理：协议验证

书架已有[本机多选分组](shelf-groups-and-popups.md#同时查看多个分组)。云端新建、移动和删除分组尚未接入插件：它们会修改微信读书账号，不能仅凭其他项目的接口说明推断本插件的授权方式和实际效果。

参考项目 [weread-shelf-organizer 的接口记录](https://github.com/tanyaqiongcode/weread-shelf-organizer/blob/main/references/api.md)描述了客户端分组请求及其 `vid`／`skey` 认证。本仓库没有运行该项目的脚本，也没有从客户端日志读取凭据。

## 空分组验证

先使用已保存的账号登录，只读核对原生和网页两种书架。原生完整书架查询包含有声书列表和分组中的有声书关联；两次读取中，书籍成员、可观察标记、分组和有声书投影稳定，两种通道的书籍和分组成员一致。

随后使用墨水屏授权恰好发送一次新建临时空分组请求，收到 HTTP 200 和 `succ=1`。紧随其后的三次双通道读取没有发现该分组。稍后两轮独立只读检查以及关闭试验前的两次读取，仍未发现目标，已核对的书架成员、标记、分组及可观察有声书投影与基线一致；**没有发送删除请求，也没有重发新建请求**。

这不能证明请求永远不会延迟生效，也不能证明非空分组请求或其他认证方式不可用。试验记录保存在本机钥匙串，状态为 `closed_unverified`，原范围永久保留并禁止重发。该状态表示按当时的只读结果结束等待，不表示创建成功或云端永远不会出现延迟变化。已提供不发送修改的只读检查，可继续核对目标是否延迟出现及其他可观察状态；该检查已在真实账号运行。没有保存真实组名、账号标识或凭据到仓库。

另用已保存网页会话的密钥，对同一客户端完整书架接口进行一次**只读 GET**，服务器返回 HTTP 401。这只说明该次网页会话密钥未通过此读取检查；不能推断其他客户端凭据或写操作的结果。

后续只读复查时墨水屏授权自然过期；Python 和原生 Lua 分别确认 HTTP 401 后，使用同设备刷新令牌续期一次，并核对账号、书架及钥匙串回读。为保留试验的可复查性，续期前在钥匙串绑定已封存记录与原设备身份摘要；续期后同设备只读复查通过，原记录未改写。该绑定不保存令牌或设备编号，也不允许重新发送分组请求。

离线测试覆盖了临时组名与删除参数限制、双通道基线、其他状态变化、回执丢失、延迟读取、持久领取、只读封存和禁止重发。验收范围见[记录](validation-assets/2026-11-17/cloud-group-empty-trial.json)。下一步需使用不同且明确隔离的测试范围验证带书的建组、移书及安全移除，并在真实独立回读确认协议后再接入原生界面。

## 带书分组的离线准备

新增独立的测试书范围和分组记录，将测试书身份同时绑定上传记录与通知回执。模拟流程只允许创建包含这一本自造书的新分组，核对已有书籍、标记、分组和可观察有声书状态，再以保留书籍的方式移除已确认的新组。每次请求在发送前持久标记，程序退出或回执丢失后不能重发；结果不明确时也不会清理测试书。验证入口默认离线，真实账号只读预演已通过，未上传或修改数据；完整往返目前只经过合成服务测试。中断后提供只读核对，不会自动恢复或重新发送。尚不能据此宣称带书分组协议或原生界面已完成。

随后使用独立范围上传了一本自造测试书，并恰好发送一次包含该书的新建分组请求；随后多次双通道回读均未发现新分组，测试书在两端均可见。这次执行报告没有保留创建回执，不能据此判断服务端是否接受请求，也不能排除延迟生效。流程未发送删除分组或清理测试书请求；测试书暂留在书架。排除该测试书后，两端的书籍成员、可观察标记、原有分组及可观察有声书状态与上传前一致，旧空分组仍未出现。已保留一次性记录和只读核对入口，不会自动重发。[脱敏记录](validation-assets/2026-11-17/cloud-group-nonempty-trial.json)不包含账号或书籍标识。

为让该未确认记录在同设备续期后仍可复查，已在本机钥匙串建立只读绑定并核对；绑定不保存令牌或设备编号，也不允许修改或重新发送请求。后续授权自然过期，经 Python 与原生 Lua 分别确认 HTTP 401 后同设备续期一次；续期后独立只读复查确认两端测试书仍在、目标分组仍未出现，排除测试书后的原有可观察状态不变，旧空分组仍未出现。未发送分组或书架修改请求，未清理测试书或重发原创建请求。此结果不能证明此前创建请求的最终效果，原记录继续保持未确认，见[脱敏记录](validation-assets/2026-11-18/cloud-group-nonempty-renewed-inspection.json)。

续期后另在隔离内存工作区离线恢复原生计时采集包，原 EPUB、账本及覆盖数据核对一致；记录仍须等自然跨日后验证，相关保存范围未变。

另一份 [weread-omni 接口清单](https://github.com/teng-lin/weread-omni/blob/main/docs/endpoints.md)将建组参数中的有声内容字段列为 `lectureBookIds`，与此前参考项目记录的 `albumIds` 不同；该清单同时将建组接口标为尚未接入。这个差异仅供后续协议研究，不能解释或证明本次结果，也不构成新的写入验证。

此后墨水屏授权再次自然过期，经两个独立读取确认后同设备续期。续期后双通道只读检查显示，两个目标分组仍未出现，带书试验的测试书仍在；不过当前书架投影与上述两次试验保存的基线均不再一致，原因未确定。检查没有重发、删除、清理或其他账号数据写入；原记录及测试书继续保留，不能将较早的「原有状态不变」观察延伸到本次。导入书历史计时的保存采集另经独立只读核对，来源、位置和采集记录均保持。见[脱敏复查记录](validation-assets/2026-11-18/native-import-search-renewed.json)。
