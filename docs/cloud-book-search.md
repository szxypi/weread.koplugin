# 跨章节正文搜索

微信读书 Web Reader 的只读搜索接口可返回跨章节候选。`book_search` 模块检查目录、页序、游标、账号和返回结构，限制响应大小并去除重复结果。网络读取在后台工作进程执行；每页读取前核对 Web 账号，并绑定同一登录会话。网络诊断不会输出查询词或正文。支持数字书号和符合既有格式的 `CB_` 书号；结果范围默认标记为未核对，不能直接用作阅读器位置。

原生墨水屏章节现可从快捷菜单在线搜索全书。后台位置核验先比对两端章节原文、账号和已保存文件，再把搜索候选转换为仅供本机使用的锚点；目标章节未保存时，只有确认后才准备下载，并检查阅读权限。断网或缺少网页登录时可进入已下载章节搜索，在线结果也可带词切换本机搜索。两种尺寸的安装插件模拟覆盖同章、已保存与下载章节、取消、无权限、原文不一致及离线回退，见[测试记录](validation-assets/2026-11-23/native-direct-online-search-ui.json)。真实账号每次使用一本书的两章和一个搜索词，也在两种尺寸的安装插件中通过同章及已缓存跨章定位；原文由阅读器独立核对，书架及两端阅读进度观察结果前后相同。验证前曾续期一次，真实缺章下载及实体 Kindle 尚未验收，见[脱敏记录](validation-assets/2026-11-23/native-direct-online-search-owner.json)。

本次真实账号只读测试先从一章原文选择查询词，再读取四页、五章的搜索候选；Python 与 Lua 独立比较了 113 个去重结果，原生 Lua HTTPS 的首批结果与独立读取一致。分页仍有后续，不能声称获取了全书全部匹配。请求的每页数量是 5，服务端一次返回多达 51 条，因此不能把请求数量当成返回数量上限。目录和原阅读位置在前后读取中保持一致，未发送账号数据或授权修改请求。

该章 64 个候选中，一处结束范围包含正文标记，简单的文字边界比较不一致。现有原文核对与位置转换逻辑对 64 个候选均成功验证，包括这一处；新适配器只在原文、章节、书籍和引用吻合时产生本地定位候选，不授予云端上传资格。观察仅覆盖一本书的一章原文和有限页数，不能推断所有图书、跨标记、表情或其他格式均有相同坐标语义。[脱敏验证记录](validation-assets/2026-11-18/cloud-book-search-preflight.json)不包含查询词、书籍标识或正文。

阅读器快捷菜单的「搜索整本书」已接入原生输入框与结果列表，搜索和后续分页在后台执行。点击结果时先核对书籍、章节、原文和引用，再交给 KOReader 定位；目标章节未缓存时先询问是否下载。取消搜索或下载确认、切书、关书及账号变化会停止相应操作，旧响应不能继续打开阅读位置。在线查询需要已验证的 Web 登录；正文或坐标不能独立核对时会提示失败，不猜测位置。最多读取 128 页，达到上限会提示结果可能不完整。

取消在线搜索、目录读取或搜索期间的登录续期后，结果页也会提供「搜索已下载章节」，并带入原搜索词；取消续期不会自动重发账号数据。两种模拟尺寸以普通书和缺少目录的导入书验证了取消、本机搜索、恢复在线搜索与跨章定位，本机搜索阶段没有网络请求；续期取消及迟到回调另经组件测试。一次组合测试因夹具错误地把缺失目录传成已有目录而在定位阶段超时，修正夹具后重新通过；实体设备仍待验收。

离线时，或联网但未登录、缺少 Web 登录凭据时，从「搜索整本书」可直接进入已下载章节搜索，可以选择大小写方式；只搜索本机有来源记录的章节，不把未下载章节当作已覆盖。在线搜索进行中断网、请求失败、受限、登录续期失败或目录准备失败时，已取得的在线结果保留，结果页提供「搜索已下载章节」并带入原搜索词；目录失败时也保留重试入口。切换账号、关闭阅读器或取消仍按各自流程停止旧任务。 无论普通书还是导入书，在线结果成功返回后也可从结果列表前部进入已下载章节搜索；在线空结果同样提供该入口，并带入原搜索词。

普通书和导入书在 600×800 与 1264×1680 两种尺寸的实际 KOReader 模拟中，均验证了从阅读菜单离线进入、断网后保留已显示的在线结果、带词转入本机搜索及本机搜索零网络请求；正常在线分页、登录续期和目录重建另做回归。测试使用合成书籍及模拟服务，实体设备和真实网络故障尚未验证，见[记录](validation-assets/2026-11-19/offline-book-search-fallback.json)。 退出登录后的入口和跨章跳转随后在两种尺寸、两类合成书籍中重新验证，见[更正与记录](validation-assets/2026-11-19/signed-out-book-search-fallback.json)。

两种尺寸的 KOReader 原生模拟中，普通书和导入书的在线结果均可切换到本机搜索并保留搜索词；另以普通书模拟在线返回空结果、本机两章有匹配，核对本机搜索不产生网络请求。已回归分页、结果定位、续期、离线和未登录入口；真实服务的空结果及实体设备尚未验收，见[记录](validation-assets/2026-11-19/online-results-local-search.json)。

如果目录尚未缓存，搜索会先读取并保存目录，再进入搜索和定位；保存失败时可重试，不会继续使用无法可靠恢复的目录。普通数字书号和 `CB_` 书号各有一个真实账号样本，在两种屏幕尺寸下通过目录重建后的原生搜索与定位。普通书早期一次验证因隔离范围未按实际可读章节筛选而拦截了查询；修正验证范围后通过，两次均没有账号数据或授权修改。

`CB_` 书籍的有限样本中，部分从正文提取的查询未返回匹配；列表和空结果均会提示可能不完整。首章起点查询结束后，若能确认不同的当前章，会在总页数上限内自动补查该章，并合并去重；首轮还有后续页时也可主动补查当前章，再继续原搜索。匹配项只能在核对本机原文后用于本机跳转，不解除该类书籍的云端位置同步限制。实际样本、原生缺章下载与已知限制见[CB 搜索说明](cb-book-search.md)。

导入书还可从目录选择其他章节补查；已显示的候选、原搜索游标和共同页数上限均保留，未完成的章节可在本次搜索中继续。合成界面与真实账号只读验收的范围见[章节补查说明](cb-book-search.md)。

搜索请求明确返回 HTTP 401 时，会使用已有的登录续期流程恢复一次，再从当前页重新读取；之前已显示的结果保留。续期期间可以取消，切书、关书或账号变化会停止旧操作；同一页持续返回 401 时，即使手动再次加载也不会反复自动续期。429 和未经确认的业务错误不会触发续期；登录不可用与请求受限分别显示对应提示。两种尺寸的实际 KOReader 进程配合模拟服务验证了登录续期、首批和后续结果、持续 401、手动重试与 429；其中 KO2 尺寸还覆盖缺目录和目标章节的下载。真实账号在有效登录下通过两尺寸已缓存及缺章路径回归；真实账号的自然过期尚未在此入口重现，详见[脱敏记录](validation-assets/2026-11-18/cloud-book-search-renewal.json)。

两种屏幕尺寸的实际 KOReader 进程使用合成书籍及模拟服务验证了输入、两页结果、取消后台任务、已缓存章节定位，以及缺少目录和章节时的下载确认、取消与下载后定位；确认前取消没有发起下载请求。旧的本机搜索和划线缺章定位流程也已回归。另以真实账号从目录首章发起只读搜索，原生 Lua 首批结果与 Python 独立读取一致，目录和原位置保持，见[补充记录](validation-assets/2026-11-18/cloud-book-search-first-chapter.json)。

真实账号还在 600×800 和 1264×1680 隔离的 KOReader 进程中，从原生快捷菜单搜索并点击一本书当前章节中的一个匹配结果；结果范围与原文独立核对后，阅读器定位到对应页面。验证使用内存中的授权和临时章节，限制网络请求为只读，完成后再次读取确认云端进度、目录和章节原文不变；没有截图或修改账号数据。[脱敏验证记录](validation-assets/2026-11-18/cloud-book-search-owner-ui.json)按上述屏幕顺序记录两次结果。

同一真实账号另在两种尺寸验证了目标章节未缓存时的流程：阅读器从隔离的合成章节进入搜索，取消下载确认时没有发起下载请求；再次选择并确认后，插件从真实服务读取目录、目标章节与样式，独立核对下载原文后打开对应位置。每次下载产生 3 个 GET、1 个目录只读 POST 和 4 个正文／样式只读 POST；请求限定账号、书籍和章节，账号数据与授权修改均为零。凭据只在内存中使用，临时文件核查和清理通过，云端进度、目录及原文的前后读取一致，见[脱敏记录](validation-assets/2026-11-18/cloud-book-search-owner-missing.json)。真实账号验证仅覆盖一本书的一个搜索结果；更多书籍格式、异常网络和实体 KO2 仍待验收。合成界面：[600×800](validation-assets/2026-11-18/cloud-book-search-ui-600.png) · [KO2 尺寸](validation-assets/2026-11-18/cloud-book-search-ui-ko2.png)。

## 较大章节编号

在线搜索结果的本机定位现支持服务端以十进制字符串返回的较大章节编号。定位前仍会核对书籍、精确章节编号、原文引用和下载文件，定位结果不会授予云端同步或划线写入权限。超过数值精度范围的数字型编号会拒绝处理；若服务端将长编号序列化为不精确的数字，仍需使用已下载章节搜索或等待可核对的返回格式。

两种 KOReader 模拟尺寸使用合成导入书和模拟服务验证了两页搜索、切换本机搜索、精确原文定位及零进度写入；相邻大编号的源码绑定与误配拒绝另经单元测试。真实账号抽查没有发现大编号章节，这些结果尚未在真实大编号响应或实体 Kindle 上验证，见[脱敏记录](validation-assets/2026-11-19/online-search-large-chapter-ids.json)。
