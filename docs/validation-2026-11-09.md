# 2026-11-08—09 原生详情与书城验证

本轮跨夜工作延续[开发清单](development-roadmap.md)；界面采用原生 KOReader 控件，
先完成功能与验证，再进行 Kindle 等墨水屏设备的集中性能优化。
本轮没有合并或发布，仍在现有草稿 PR。

## 已完成的行为

无 Skill 密钥也可从已登录会话取得书籍资料并显示在原生详情页；有密钥时优先官方查询。
读取、解析在独立后台进程完成，资料在账号 SQLite 中缓存；简介转换成原生文字。
刷新详情不再读取云端进度，更不会用旧网络结果覆盖阅读期间更新的本机位置或文件版本。
重读最新本机记录后只合并展示字段；取消、账号／凭据变化、旧页面回调和保存失败均有处理。

## 原生授权书城

在用户确认方便扫码后，完成墨水屏授权、同账号书架核验及系统钥匙串保存／回读；
与已保存的 Web 会话使用独立条目，按用户要求保留至整体目标验收收尾。

- 真实 Python 原型先于 Lua 实现，核对搜索、个性化推荐、相似书籍的固定 GET 合同。
  搜索 20＋2 本、相似 20＋3 本，游标前进、无重复、会话保持一致；真实个性化推荐为空。
- Python／Lua 对相同真实响应的展示投影一致；KOReader 原生 HTTPS 独立完成 5 个 GET 的搜索／相似分页，
  结果数量一致，无账号数据写入。[去敏报告](validation-assets/2026-11-09/native-discovery-owner-readonly.json)
  仅含时间、字段名、数量和断言，不含私有查询结果、书名、ID 或凭据。
- 搜索／推荐／相似列表采用原生控件，后台进程解析数据；相似推荐保留会话，后续页绑定原通道及凭据修订。
  首批故障可按规则回退 Skill；429 不回退，失败保留当前页。刷新清除旧游标。
- 600×800 与 KO2 1264×1680／300 DPI 的完整合成链路通过：原生搜索框 20＋6、
  相似 20＋5／会话／前后批、推荐 20＋6、异步心跳、退出／关闭种子详情取消、首批回退／后续绑定、429 缓存保护。
  同时回归授权／续期、下载、EPUB、原文导航与离线时长。截图全部使用合成账号：
  [600 相似书籍](validation-assets/2026-11-09/native-store-similar-600.png)、
  [KO2 搜索](validation-assets/2026-11-09/native-store-search-ko2.png)。
- 106 组 Lua、145 组 Python、259 个 Lua 文件静态分析通过（0 警告／错误）。
- 原有打包发现界面的 600×800 回归通过，覆盖 Skill 相似书籍、公开分类／榜单、首页与书架、
  可见进度、阅读统计、长列表和离线缓存。

分类层级选择器仍沿用原有公开请求调度；分类书单已在后台读取。
真实非空个性化推荐、书城自动续期、真实过期／限流及实体 KO2 仍待验收；
实体残影、按键、休眠／网络、耗电及集中性能优化不以桌面分辨率模拟结果替代。
