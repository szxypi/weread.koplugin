# 本机笔记导出

阅读任意书籍时，打开「工具 → 微信读书 → 导出本机笔记」，选择 Markdown 或 JSON。
导出当前书籍在 KOReader 中保存的文字划线及其附注，不需要联网或微信读书登录。
成功后显示文件路径；文件位于插件数据目录的 `exports/notes/` 下，可自行复制到电脑。

## 内容与边界

- 每条记录包含划线文字、附注、章节，以及 KOReader 已记录的页码或页码标签。
  页码沿用记录值，字号重排后可能不同；不把原生 XPointer 当成页码。
- Markdown 对多行文字加引用前缀，并转义 HTML、链接、图片及其他 Markdown 标记。
  附注中的格式源码按文字保留；JSON 按原字符串保留文字与换行。
- JSON schema 1 仅含来源、书名、作者、导出时间和有界笔记字段。
  不输出原生定位对象、书籍路径、账号、凭据或其他附加字段。
- 只导出当前书籍的本机文字划线／附注。普通页书签、无文字无附注的图片划线不导出；
  微信读书云端划线／公开想法的本机覆盖层不属于此次来源。
  不修改笔记、阅读位置或云端数据；导出按钮不授予同步权限。
- 单条文字与附注分别最多 64 KiB，最多 100,000 条，单文件最多 32 MiB。
  超限、无有效条目、编码或写入失败会停止并移除本次文件，不截断文字后冒充成功。

## 后台与文件保护

原生格式弹窗确认后，后台子进程读取启动时的 Lua 笔记快照并写出文件。
子进程不调用继承的原生文档、DOM 或 ZIP 对象；父进程继续处理输入。
导出开始后编辑原笔记不改变本次快照，编辑本身保持。
后台仅经管道返回条数、字节数和固定错误码，正文不回传至日志。

每次排他创建新文件，初始权限为 POSIX `0600`（实际权限仍取决于目标文件系统）。
文件名只含清理后的有限书名、时间及冲突序号，不打开或截断已有文件。
成功前同步并核对文件身份及字节数，才展示完成提示。
点击等待窗、按键取消、关闭插件界面、切换账号、关书或休眠会停止自有任务并移除本次文件。
阅读会话、文档或路径变更和超时同样拒绝迟到结果；旧回调不能关闭新任务。
取消只删除仍属于本次创建身份的文件，原路径被替换时保留替换文件。
成功文件保留供用户复制；此实现不保证进程崩溃或断电后的半成品自动清理。

自定义缓存目录包含插件数据目录时，导出路径仍被排除在微信读书缓存识别之外，
避免用户打开导出文件后触发书籍位置同步。

## 验证

```sh
luajit spec/notes_export_spec.lua
luajit spec/notes_export_ui_spec.lua
```

模型 27 项、操作协调 31 项检查覆盖字段保留与过滤、转义、UTF-8／容量、写入／同步／接收错误、
取消、旧回调、会话／文档／账号变化、超时、无笔记和格式弹窗生命周期。
`spec/koreader/notes_export_smoke.lua` 作为完整核心流程的一部分，在官方 KOReader v2026.07.1 Linux ARM64 中运行：

```sh
WEREAD_TEST_OFFLINE_TIME=1 xvfb-run -a python3 scripts/mock_weread.py \
  --smoke --port 0 --koreader /path/to/koreader --run-dir /path/to/new-directory \
  --width 1264 --height 1680 --dpi 300
```

实际 ReaderUI、原生弹窗、后台进程／管道和磁盘文件共同验证 Markdown／JSON 回读、
事件循环心跳、启动快照、已有文件保护、取消清理、替换文件身份、自定义缓存根目录与存储失败。
600×800 与 KO2 1264×1680／300 DPI 的完整核心流程均通过，145 个安装文件分别与工作树一致，零重绘警告。
同时回归 KO2 尺寸的云端原文精确导航／跨文件续接，第三个候选包也通过同样检查。

不读取真实笔记或新增账号请求。
桌面 KO2 分辨率运行不能替代实体 KO2 的按键、文件系统、休眠与断电验收。
