# 真实位置写入验收的准备工具

`scripts/verify_position_roundtrip.py` 已完成真实账号的只读准备与离线测试。
位置写入实验的具体授权已请求，尚未执行真实写入；本项不作为上传协议或精确同步通过的证据。

## 准备和允许的实验范围

默认不读取凭据、不联网。明确使用已保存授权后，工具选择一本已有位置的普通书籍，
核对云端／Reader 内嵌位置、同书章节、原文与唯一目标，以及已有进入阅读／上报请求的签名结构。
只读预览确认了一个同章、连续、唯一的相邻原文目标，偏移增加一个 UTF-16 单位。
空白、合并字符、控制字符、标签／实体内部和两个单位的标量不会作为一字探测目标。
没有合适目标时不改选偏移、不扩大范围。

工具提供两种需要单独授权的实验：

| 模式 | 最多进度 POST | 核对 |
| --- | --- | --- |
| `same` | 2 | 进入阅读、相同位置且零时长的上报，再读取位置。没有明确回执时仍为未确认，位置不变本身不证明写入成功 |
| `probe` | 4 | 上述两步之后，在同一章前进一个单位，独立读回，再有条件恢复原位置并核对 |

每次实际执行都重新准备上下文和签名，固定已预览的账号与书籍；
`--apply` 必须同时提供 `--mode`、`--book-id`、`--expected-owner`，不在写入模式下自动选书。
同位置／探测／恢复上报都固定 `rt=0`，进入阅读请求按现有协议不含时长字段。
身份、阶段顺序、请求目标、精确字段集、签名、位置、时长与发送上限在传输前再次核对。

独立读取最多四次以观察异步结果，不重发 POST、不续期、不换账号、不追加其他坐标试探。
HTTP／回执不确定的发送仍消耗名额。探测请求已被尝试时，即使异常或中断也先检查当前位置；
只有当前书籍／章 UID／偏移仍等于本次探测点，才发一次恢复。若已经回到原位则不重复写入。
读取到其他坐标时保留新位置并停止，不能覆盖其他阅读器的新进度。

服务器可能自行归一百分比等元数据：探测按书／章／偏移独立核对，恢复仍须核对原来的章节序号和百分比。
仅坐标已恢复而元数据不同，报告明确保持未确认，不为制造通过结果而再次发送。
这些检查不是服务端原子比较交换，不能识别另一个设备恰好写入同一坐标；
进程被强制结束、断电或恢复读取失败时，也不能保证自动恢复。

最近阅读时间、位置摘要或同步记录可能更新。当前真实预览的摘要不能按既有二十字载荷原样往返，
工具明确标记这一点，并使用已核对原文目标的二十字摘要；不承诺恢复服务端历史记录或原摘要。
探测的目标是验证章节／偏移的写入与恢复，不累计阅读时长，也不修改书架／批注。

## 使用和证据

```sh
python3 scripts/verify_position_roundtrip.py
python3 scripts/verify_position_roundtrip.py --saved-session
python3 scripts/test_position_roundtrip.py
```

以下入口仅用于已经批准的具体实验，两个变量来自本机私有预览，不是凭据：

```sh
python3 scripts/verify_position_roundtrip.py --saved-session \
  --book-id "$ROUNDTRIP_BOOK_ID" --expected-owner "$ROUNDTRIP_OWNER_VID" \
  --mode probe --apply
```

本人授权只保留在原有项目钥匙串条目。选书及账号绑定只在任务内存中保留，不新增授权条目。
正文、完整位置、Reader 会话、签名、账号和书籍编号均不进入报告或普通文件；
读取响应后核对账号，并保存／回读合法的 Cookie 轮换。恢复不确定时明确保留未确认状态。

20 项离线检查覆盖默认零请求、显式授权参数、同书及零时长载荷、重新签名后的篡改拒绝、
账号变化、回执缺失、不确定发送、中断恢复、并发位置、服务器元数据归一、无效目标及隐私边界。
测试不能代替真实写入：当前仅有[只读准备报告](validation-assets/2026-11-10/position-roundtrip-preview.json)，
状态为 `READONLY_ROUNDTRIP_PREVIEW_READY`、进度写入尝试为零。
新的精确上传路径仍待本人批准实验并验证结果后再接入 Lua。
