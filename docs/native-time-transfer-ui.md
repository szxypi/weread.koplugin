# 原生离线时长补传与待核对恢复

离线账本已接通原生补传按钮和后台服务。正常入口为微信读书设置中的“离线阅读时长”→“检查本机时段”→“补传此批时长”。
提交前显示书名、原始日期、时区和本批秒数；每次只处理这一批，不自动循环发送。

界面使用 KOReader 原生菜单和对话框；来源核对、网络请求及结算在后台子进程执行。
本阶段在实际 KOReader ReaderUI、子进程和 SQLite 中使用合成数据验证，**没有新增真实账号请求**。
旧两秒窗口、原已消费请求与未通过的试验均未重用。

## 分批与互斥

每批最多 600 秒、100 个片段，保持同书、同文件身份、同版本与同一北京时间历史日。
当天和其他时区的记录会跳过，后续合格历史记录仍能被选中；跨午夜的片段按边界拆选，原采集行不改写。
原时长、小时分布、版本与来源摘要仍由[发送底层](native-time-transfer-core.md)重新核对。

章节较多时，插件先在后台分批查找与本机时长记录匹配的缓存来源；查找可以取消，不会提交时长。找到后仍要通过原有的本地和线上来源复核。未完成记录的只读恢复使用原记录的来源身份，不会发送补传请求。

补传开始前，若本插件有正在发送或准备的在线时长／位置同步，先拒绝启动，避免取消一个可能已发出的请求。
同书未处理完的位置同步凭据也会阻止补传，保留其原核对依据。
操作期间暂停本插件的上报定时器与位置自动同步，并阻止新手动上报；完成或在原会话中取消后恢复原先运行的定时器。
账号、授权、文档、会话或网络失效时取消，不恢复旧阅读会话。
这不锁定其他设备；其他设备造成的变化会使本次核对停止，结果保持待核。

父进程每次检查当前界面与授权，子进程只读取匿名共享取消位，不访问继承的原生文档句柄。
取消先失效发送条件，再终止并回收子进程；70 秒父进程期限与有界后台任务共同限制等待。

## 未完成记录

“查看未完成的补传”按保存状态提供操作：

| 保存状态 | 可执行操作 | 是否再次发送原请求 |
| --- | --- | --- |
| 尚未领取发送 | 取消已知未发送的准备，恢复待处理时段 | 否 |
| 已领取，但没有可靠回执 | 保留为待核记录，继续处理其他时段 | 否 |
| 明确回执已保存，入账未核实 | 只读核对云端结果；或保留为待核记录 | 否 |
| 云端已核实，本机结算中断 | 只完成幂等本机记账 | 否 |
| 旧确认缺少独立核对证据 | 保留为待核记录，不当作成功 | 否 |

只读恢复重新核对当前账号、同一原生设备、缓存原文／版本、两端完整位置摘要、书架与保存的月份投影，
必须两轮稳定目标及最后一次来源／快照核对一致。可以使用同账号同设备的新授权，不改写旧计划或回执。
这个路径不获取签名令牌、不调用补传接口，也不将迟到的回执或单次观察当作结算依据。
缺少设备绑定的旧记录仍保持待核，不推断设备身份。

保留待核记录会保存原编号、请求、回执事实与永久排除区间；不增加“已核实补传”，也不释放原时间再次发送。
本机恢复绑定具体请求，旧页面的操作不能取消另一条新准备记录。
成功结算仍保留原请求和独立核对审计。

## 验证与边界

两尺寸实际原生流程覆盖：正常补传、回执后只读恢复、回执丢失后的待核保留、本机结算失败后的恢复，以及回执保存后关闭窗口并回收子进程。
其中模拟请求由一次领取约束及独立 SQLite 计数核对，每条范围恰好一次发送，恢复没有新增发送。
600×800 和 1264×1680／300 DPI 均验收了实际菜单、中文按钮和排版。
来源归档核对另由实际 libarchive／原生 SQLite 测试覆盖；此 UI 测试的原文／HTTP 来源使用合成固定值，不能代替真实账号验收。

新增的大目录场景在两种尺寸分别使用 160 章合成目录，将匹配的实际 EPUB 放在第 155 章：扫描时取消不会领取或发送；重新操作后完成一次模拟发送，再从已保存回执只读恢复，恢复没有新增发送。来源字节使用真实归档库核对，线上响应使用合成数据；10,000 章上限的最后一章另经单元测试核对。该场景未使用真实账号，也未在实体 Kindle 上测试，详见[记录](validation-assets/2026-11-17/readtime-many-sources.json)。

完整检查与固定结果见[验收记录](validation-assets/2026-11-17/native-time-transfer-ui.json)。

尚待完成：使用**新的真实采集窗口**完成原生按钮的真实入账验收、真实历史账本与跨月、过期／移动缓存、大量来源引用的真实设备验收、其他时区与 CB_、多设备并发、实际写满／断电和实体 KO2。
不修改日期来制造历史窗口，不把模拟器尺寸验收当作实体设备验收；性能专项仍安排在功能验收之后。
