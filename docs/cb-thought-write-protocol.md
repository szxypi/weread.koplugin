# 导入书私密想法写入验证

2026-11-19 使用新上传的自造 EPUB 测试导入书私密想法。测试先新增一条普通划线，
以该划线为引用新建私密想法，再编辑、删除想法，最后删除测试划线。五次笔记修改逐次独立回读，
并核对书架、位置和其他笔记；测试完成后移除自造书。原有书籍未修改。

测试程序对每次写入先保存意图；异常或中断时停止，禁止重发或继续清理。该次执行最终确认所有测试记录
及测试书已移除，原有记录保持一致。脱敏结果见[验证记录](validation-assets/2026-11-19/cb-thought-owner.json)。

随后使用另一份新上传的自造 EPUB，在 KO2 分辨率的 KOReader 原生书籍详情中验证想法创建、编辑和删除。
测试划线由受控接口创建，原生界面先阻断预演，再执行三次想法写入；每一步由宿主独立回读后才继续，
最后移除测试划线及测试书。验证记录只含脱敏结果，见[原生验证记录](validation-assets/2026-11-19/cb-native-thought-owner.json)。

验证覆盖已有划线上的私密想法，未验证直接从新选区创建想法、公开想法的编辑、其他导入格式、
实体 Kindle 或真实服务中从阅读菜单进入该界面。插件对未经验证的写入范围保持关闭。
