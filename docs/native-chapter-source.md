# 原生章节来源组件

新增只读原生章节来源组件：请求前核对当前账号、授权版本及调用方状态，重新读取书籍信息和原生目录，只允许目录明确标记为免费或已购的数字书号 EPUB 章节；每次请求包含关闭自动购买参数。组件不处理购买、授权续期或账号写入，单次调用不自动重试。章节包大小受限，凭据和正文不记录到日志；返回前再次核对账号状态。

HTTP 401、429，以及章节包接口明确返回的登录过期／限频业务码分别报告；其他明确的业务拒绝保留为拒绝，不能当作普通错误立即换通道重试。章节包解密与图片识别沿用[原生章节包验证](native-chapter-package-research.md)：无法识别的图片有单独计数，图片签名可识别也不代表引用和解码完整。该组件返回 E-Ink 来源标记，不授予网页坐标或上传权限。

2026-11-22 在真实账号上对三本书各一章，通过实际 KOReader 网络层分别读取书籍信息、目录和章节包，与同一章的独立 Python 原生读取逐项比较正文、样式和可识别图片，均一致；每本 Lua 路径各三次请求，未发送账号数据修改或授权请求。第一本仍有一个无法识别的图片条目；三次真实结果分别见[一](validation-assets/2026-11-22/native-chapter-source-1.json)、[二](validation-assets/2026-11-22/native-chapter-source-2.json)、[三](validation-assets/2026-11-22/native-chapter-source-3.json)。首次原生进程因未设置模拟显示环境而退出，后续补齐环境后重测；该失败未作为通过结果。

合成服务下的实际 KOReader HTTP 测试覆盖正常读取、付费未确认、HTTP 和业务码限频、登录过期、其他业务拒绝、缺少密钥与损坏包；检查请求数量及模拟服务收到的凭据隔离。单元测试另覆盖账号变化、超限及重复响应头。真实正文和授权只在内存中处理，报告不含账号、书籍、章节、原文或凭据。

组件现已以默认关闭的试验接入单章、下一章预取及整书下载，范围和验证情况见下文；实体设备及其他格式仍需验证。

## 单章下载试验

插件“下载设置”中可启用“实验性墨水屏章节资源（仅单章）”。它还要求开启图书图片下载并有当前账号的墨水屏授权；否则继续使用原有下载方式。手动单章和自动预取下一章先从原有来源取得原始正文和进度依据，再读取墨水屏章节：仅在原始字节完全一致、资源可安全整理且账号保持一致时才采用墨水屏内容和图片。正文不一致、格式或资源不受支持时使用原有下载方式；限频、授权过期、明确业务拒绝或账号变化时停止本次尝试，不自动重试墨水屏请求。两种来源不能互相替代进度依据：文件中保留的是独立取得的原有来源记录。

该试验需要额外网络请求，并不解决原有来源不可用时的阅读。实际 KOReader 模拟环境中，合成服务覆盖了手动下载及下一章预取的单章获取、图片保存、EPUB 打包、原始进度依据及离线渲染，在 600×800 与 KO2 尺寸均通过；合成正文中还验证了原文位置到阅读器位置的往返，另核对了正文不一致时的回退、下载后账号切换时停止保存，以及等待原生章节请求期间取消并清理暂存。预取的模拟取消发生在书籍信息请求期间，确认返回后没有继续读取目录及章节。

另以真实账号选取一本书的一章，在 KO2 模拟尺寸下独立读取原有来源并与原生章节逐字节核对，再通过实际下载器的后台子进程生成单章 EPUB；正文、原文依据和图片经禁网的 KOReader 读取，账号数据没有写入。测试文件仅在隔离内存文件系统中产生并于结束时清理，凭据未写入文件；[验证结果](validation-assets/2026-11-22/native-candidate-owner-ko2.json)不含账号、书名、正文或图片。该测试以独立读取结果模拟下载器的原有来源获取，未覆盖完整界面、真实账号下载中取消或全新进程重开。真实云端进度和批注交互、更多书籍及实体 Kindle 仍待验证。

同一真实样本也通过 KO2 模拟尺寸的正式后台预取调度和子进程，生成章节并离线读取正文、图片和原有来源依据；[预取验证结果](validation-assets/2026-11-22/native-prefetch-owner-ko2.json)不含账号、书名、正文或图片。原有来源由独立只读结果注入，未覆盖完整阅读器页面、真实下载中取消或全新进程重开。

## 整书下载试验

下载设置中另有默认关闭的“实验性墨水屏章节资源（整书）”，独立于单章开关，并同样需要启用图书图片下载和当前账号的墨水屏授权。此选项用于“下载全书”生成的合并文件；多选章节的其他下载方式仍使用原有来源。每章先独立取得原有来源和位置依据，只有正文逐字节一致且资源可核对时才使用墨水屏章节；其他章节回退原有来源，因此一本书可以混合两种来源。原有来源不可用时不会仅凭墨水屏章节推断云端位置。

整书按章节保留各自样式及其图片，重复图片按内容复用；原生断点绑定账号及原文、样式和图片的摘要，同一账号重新登录后可继续，其他账号不会复用。恢复与打包前重新核对，资源损坏只会使受影响章节失效；重新下载时仅在原章节、版本及资源记录能证明归属时原子修复损坏文件。限频、授权过期或账号切换会停止任务并保留已完成章节；旧整书只有在完整打包并通过账号校验后才替换。每章需要额外请求，试验并不代表下载更快。

整书续传使用的网页共用样式也保存摘要并在重开时核对。样式或摘要损坏、缺失，或使用没有摘要的旧断点时，不加载未经核对的样式；已有未完成章节时由其重新尝试获取，章节全部完成时重新获取第一章以恢复样式，其他有效章节保留。样式写入或摘要发布失败不会把不匹配的内容视为有效断点。600×800 与 KO2 模拟尺寸通过合成混合来源的样式损坏、恢复和离线阅读；旧格式、摘要发布失败及章节保留另经文件级测试。真实 Kindle 存储故障和断电仍待验证。

中断后残留但不再被当前章节引用的墨水屏图片可从新书中排除；当前章节记录的样式图片，以及正文或公共样式中引用的同名网页图片会保留。需要排除残留文件时，先构建独立的打包目录：支持时使用硬链接，不支持时分块复制；准备失败保留旧整书。两种模拟尺寸的实际 KOReader 归档验证检查了文件清单及归档内容，续传和离线阅读仍通过；复制失败和目录冲突另经文件级测试。网页图片的历史记录和保守处理见[下载说明](batch-source-pacing.md#章节图片写入失败)，真实设备文件系统仍待验收。

600×800 与 KO2 模拟尺寸的合成服务覆盖不同章节样式、共享图片、混合来源及离线读取；KO2 尺寸另覆盖限频续传、图片与样式同时损坏后的修复和不完整临时文件清理；授权过期及打包时账号切换均核对已完成章节和旧整书保留。真实账号选取同一本书的两章，使用整书下载路径和后台进程完成只读打包、来源核对及离线正文／图片读取，见[去敏结果](validation-assets/2026-11-22/native-full-owner-two-chapters.json)。该真实验证只覆盖两章，原有来源由独立只读结果注入，并非完整书籍或完整界面验收；真实断线、云端进度与批注、更多书籍和实体 Kindle 仍待验证。验证前确认原生授权过期，并完成一次同账号续期；没有账号数据修改。

后续以同一范围在 KO2 模拟尺寸进行了[实际网页下载与全新离线进程验证](validation-assets/2026-11-22/native-full-owner-live-web.json)：插件自行读取网页阅读页、章节与样式，并独立读取墨水屏章节，两章原文与独立只读结果逐字节一致后打包；第二进程通过系统网络限制断网，重新打开 EPUB、核对原文依据、搜索正文并解码图片。下载阶段限制请求范围，只允许选定书籍的只读接口和无凭据图片请求；临时文件和已读取归档内容检查未发现已用凭据。验证范围仍是预选的两章，不是完整真实整书或从首页操作的界面验收，也未验证真实云端进度和批注。期间发现授权自然过期，独立复核后完成[一次同账号续期](validation-assets/2026-11-22/native-full-owner-renewal.json)；续期是单独的一次授权请求，未发送账号数据修改。

## 包内资源准备与原生渲染

章节解析现在保留各段正文及样式的包内来源；资源准备按各自所在路径解析相对引用，核对样式链接，并为可识别图片生成基于内容的 EPUB 内部名称。重复目标冲突、缺失图片、无法核对的样式和不支持的标记返回失败，不猜测使用同名图片。资源准备本身只统计网络引用；后续[网络图片组件](native-chapter-remote.md)可下载受支持的图片并再次核对。图片签名可识别不等于完整解码验证。

多个样式表在每个正文片段均完整引用、顺序一致、规则边界完整且不含样式表级 `@` 规则时，按正文声明顺序合并，并分别以原路径解析图片。顺序或内容无法核对时回退原下载方式；内联样式和其他复杂样式仍未接入。墨水屏样式也应用与原有来源相同的根元素零字号保护，保留其他选择器的零字号设置。手动单章与预取在 KO2 模拟尺寸均通过合成多样式表顺序、字号保护、图片及离线阅读检查；不代表实际屏幕目视或所有样式均已覆盖。

真实账号的三个只读样本各有一个样式表，本次未找到多样式表真实样本；[去敏计数](validation-assets/2026-11-22/native-styles-owner-sample.json)。另以真实账号的一章在 KO2 模拟尺寸完成当前实现的后台预取及离线正文／图片回归，账号数据写入为零；[去敏结果](validation-assets/2026-11-22/native-style-prefetch-owner-ko2.json)。真实多样式表和实体 Kindle 仍待验证。

三份真实章节经过 KOReader 原生请求及资源准备：第一份核对一个包内引用，另有一个网络引用；第二份核对两个包内引用且无网络引用；第三份缺少一个资源，正确停止准备。没有将真实正文、资源、路径或凭据保存到报告。见[样本一](validation-assets/2026-11-22/native-resources-1.json)、[样本二](validation-assets/2026-11-22/native-resources-2.json)、[样本三](validation-assets/2026-11-22/native-resources-3.json)。
