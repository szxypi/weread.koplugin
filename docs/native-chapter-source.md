# 原生章节来源组件

新增只读原生章节来源组件：请求前核对当前账号、授权版本及调用方状态，重新读取书籍信息和原生目录，只允许目录明确标记为免费或已购的数字书号 EPUB 章节；每次请求包含关闭自动购买参数。组件不处理购买、授权续期或账号写入，单次调用不自动重试。章节包大小受限，凭据和正文不记录到日志；返回前再次核对账号状态。

HTTP 401、429，以及章节包接口明确返回的登录过期／限频业务码分别报告；其他明确的业务拒绝保留为拒绝，不能当作普通错误立即换通道重试。章节包解密与图片识别沿用[原生章节包验证](native-chapter-package-research.md)：无法识别的图片有单独计数，图片签名可识别也不代表引用和解码完整。该组件返回 E-Ink 来源标记，不授予网页坐标或上传权限。

2026-11-22 在真实账号上对三本书各一章，通过实际 KOReader 网络层分别读取书籍信息、目录和章节包，与同一章的独立 Python 原生读取逐项比较正文、样式和可识别图片，均一致；每本 Lua 路径各三次请求，未发送账号数据修改或授权请求。第一本仍有一个无法识别的图片条目；三次真实结果分别见[一](validation-assets/2026-11-22/native-chapter-source-1.json)、[二](validation-assets/2026-11-22/native-chapter-source-2.json)、[三](validation-assets/2026-11-22/native-chapter-source-3.json)。首次原生进程因未设置模拟显示环境而退出，后续补齐环境后重测；该失败未作为通过结果。

合成服务下的实际 KOReader HTTP 测试覆盖正常读取、付费未确认、HTTP 和业务码限频、登录过期、其他业务拒绝、缺少密钥与损坏包；检查请求数量及模拟服务收到的凭据隔离。单元测试另覆盖账号变化、超限及重复响应头。真实正文和授权只在内存中处理，报告不含账号、书籍、章节、原文或凭据。

组件尚未连接书架或阅读器下载入口；图片引用与样式处理、整书下载和恢复、来源坐标隔离、后台取消、真实设备及其他格式仍需验证。现有阅读器继续使用原有下载路径。

## 包内资源准备与原生渲染

章节解析现在保留各段正文及样式的包内来源；资源准备按各自所在路径解析相对引用，核对样式链接，并为可识别图片生成基于内容的 EPUB 内部名称。重复目标冲突、缺失图片、无法核对的样式和不支持的标记返回失败，不猜测使用同名图片。资源准备本身只统计网络引用；后续[网络图片组件](native-chapter-remote.md)可下载受支持的图片并再次核对。图片签名可识别不等于完整解码验证。多个样式表、内联样式等尚未接入的格式保持未完成状态。

三份真实章节经过 KOReader 原生请求及资源准备：第一份核对一个包内引用，另有一个网络引用；第二份核对两个包内引用且无网络引用；第三份缺少一个资源，正确停止准备。没有将真实正文、资源、路径或凭据保存到报告。见[样本一](validation-assets/2026-11-22/native-resources-1.json)、[样本二](validation-assets/2026-11-22/native-resources-2.json)、[样本三](validation-assets/2026-11-22/native-resources-3.json)。

另以合成包在实际 KOReader 网络层完成请求、解包、资源准备、EPUB 生成及 CRE 原生正文／图片内容核对；两种模拟尺寸另以新进程离线重开，并确认生成文件没有网页原文坐标元数据。后续一章真实正文及图片也已完成两尺寸原生解码与离线重开，范围见[网络图片验证](native-chapter-remote.md)；尚不能证明屏幕像素或所有进度写入路径均已隔离。仍需接通来源切换、下载器和阅读器，再验证进度、批注、整书恢复及实体 Kindle。
