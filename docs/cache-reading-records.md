# 清理下载缓存时保留阅读记录

旧清理入口递归删除整本书的目录和书籍索引。下载文件与
`reading_state.json`、原生 `.sdr` 记录共用目录，因此本机位置、待同步位置及
阻止未知发送重放的记录也会丢失。修复前已在独立临时目录复现，未对真实账号或实际书籍缓存执行删除。

现在单本、全部书籍及全部公众号清理共用同一流程：

- 先核对书籍编号、目录名称、元数据、文件身份和范围，显示将删除的文件数量及大小，再确认。
- 删除下载正文、资源、目录和文章列表，完成后清理云端划线／想法在本机的缓存。取消或失败明确显示停止，不宣称全部完成。
- 保留书籍索引与实际目录。阅读记录文件逐字节保留，不反序列化再保存；只更新已经失效的下载文件指针，避免覆盖关书任务的新位置。
- 保留原生 `.sdr`、Lua／JSON 记录及备份、文章恢复隔离目录。无法确认归属、符号链接、未完成下载或持锁冲突均停止，不整目录删除。
- 确认后重新检查账号／登录代次、菜单、阅读会话、下载队列、目录和文件快照。正在打开的书籍，包括文件管理器背后的 ReaderUI，不允许清理。
- 每本书使用同一内核排他锁。普通下载和预下载持有至任务结束，公众号下载先取得该锁再创建暂存；清理还取得各文章的锁。无法可靠加锁时拒绝清理。
- 删除按最多 32 个条目一批交还界面，可用轻触或按键停止。停止后保留阅读记录，核对实际剩余文件并修正下载指针；批量操作出现错误会报告停止。

整书缓存状态另改为明确显示「整书已缓存」。即使同时保存两份单章文件，或目录暂不可用，也不会误显示为只缓存两章；部分缓存只统计目录中有对应文件的有效章节。

## 验证范围

新增的组件检查覆盖记录保留、错误归属、越界路径、目录／文件替换、元数据变化、并发写入、暂存与隔离文件、部分删除失败、旧确认回调和界面取消。
原生运行库的独立进程测试使用真实 Settings／BookStore、文件系统和内核锁：五本合成书籍含普通、CB_、公众号及不透明记录，核对单独公众号清理、全部清理、新进程回读和重新下载；书籍索引及原始阅读记录不变。

打包插件的原生界面验证、候选文件核对与自动检查结果见[固定记录](validation-assets/2026-11-11/cache-reading-records.json)及[当日验证记录](validation-2026-11-11.md)。
初次界面验收误要求相同归档产生跨文件锚点而失败，保留原未通过记录；修正核对方式后重新执行。
截图只使用合成书名与正文。相同归档身份重新下载时，验证原生页码、保留文字点可见性及独立原文偏移；不同归档仍走既有经过校验的本机位置交接，不要求同一文件额外生成跨文件锚点。

本项未访问真实账号，未发送真实授权或账号数据修改请求；同步回归的写入只发送到合成服务。开发凭据没有清理。
模拟 KO2 尺寸不等于实体 KO2 验收。真实设备的文件系统、按键、休眠及断电仍待验证；完整功能清单与集中性能专项继续保留为未完成。
