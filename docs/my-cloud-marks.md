# 我的云端划线：原生只读浏览

书籍详情的「我的云端划线」与普通微信读书书籍的阅读菜单，现可打开本人划线与书签。
使用 KOReader 原生 Menu 分页和 TextViewer 原文弹窗，提供全部／仅划线／仅书签筛选。
首次无缓存时后台读取；已有缓存时立即显示，手动刷新。关闭详情、关书、切换阅读上下文、休眠或退出插件会取消所属任务及弹窗。

这批没有创建、修改、删除笔记，也不根据划线 range 跳转或上传阅读位置。
现有章节公共划线／想法仍是独立功能。本人的想法读取和云端笔记写入继续待实现，不能以公共想法替代。
当前仅开放已核对的普通数字书号；公众号和 CB_ 书号未扩展。

## 先验证协议，再接入 Lua

参考 [MiuRead 的墨水屏客户端](https://github.com/miumiupy98-art/miuread-koreader/blob/c1893562aa25a870b8dd076d7be062a3348f823e/miuread.koplugin/miuread/eink_client.lua) 的 endpoint 约定，
独立 Python 模型及只读工具 `scripts/my_cloud_marks_model.py`、`scripts/verify_my_cloud_marks.py` 先于 Lua 实现运行。
实际路径为：读取书架、笔记本列表选择有标记且仍在书架的普通书、读前位置、完整标记、读后位置。
139 本书架、15 个笔记本中所选书返回 52 条带文字的标记和 5 个章节标题，声明计数匹配，前后位置对象一致。
初次墨水屏书架 HTTP 401 后停止；仅执行一次已有授权维护，回读同账号书架后再继续。没有账号数据 POST。

读取使用 `GET https://i.weread.qq.com/book/bookmarklist?bookId=…&synckey=0`，只发送墨水屏授权头，
不混入 Web Cookie 或 Skill 密钥，不保存响应 Cookie。接收上限 4 MiB。
显式 HTTP 401 最多交给既有父进程续期服务恢复一次并重新读取；其他失败保留旧缓存。
待确认续期不会自动重发。

模型检查根及条目显式书号、可选账号标识、服务端错误／未完成标记、重复编号、数组结构、数字和有效 UTF-8。
只投影 bookmarkId、引用、摘要、原始展示 range、章节编号、类型／样式／颜色／时间及章节标题。
原始 range 没有转换为阅读或上传坐标；未知类型保留为「云端标记」，不臆断为书签或划线。

另按参考参数测试 `/review/list`：返回中出现其他书籍及其他作者的记录，bookId／bookid 与 listMode 的尝试未建立可靠筛选。
Web `/web/review/list/mine` 与墨水屏 `/review/list/mine` 返回 404。相关结果被拒绝，未进入 Lua、缓存或「我的想法」界面。
这些失败保留为限定协议诊断，不能宣称本人想法已接通。

## 缓存与页面归属

标记单独存于按账号隔离的 library SQLite 的 `my_cloud_marks` 表，不进入通用设置或匿名书城缓存。
单本最多 5,000 条标记、5,000 个章节，单份 JSON 最多 4 MiB；最多保留最近写入的 64 本书和 32 MiB JSON 总量。
该总量不包含 SQLite 页、WAL 等额外开销。超额淘汰在同一事务完成，失败回滚保留旧副本。
刷新成功且完整保存后才替换界面；保存失败不会把仅在内存的新结果当作离线缓存。
标记快照独立于下载正文缓存；清理下载正文不会清除此表。

后台工作进程仅返回有界投影；父进程核对账号、登录代次、文档、阅读会话、详情页和授权版本后才能保存。
原文弹窗显示期间，刷新重绘等弹窗关闭后再执行。旧菜单、旧取消按钮及旧详情操作不能启动新页面或关闭新任务。
空筛选保留明确空状态，不把失败回包保存为空标记。

## 原生验证及边界

实际 KOReader v2026.07.1 Linux ARM64 的 PluginLoader／FileManager 加载候选，
两尺寸分别读取 52 条标记，分页并逐条打开原文弹窗，与各自独立 Python 模型及文件 SQLite 对照。
每尺寸再启动全新离线进程，读取相同快照，离线零请求。
真实凭据仅经捕获管道和匿名描述符传递，账号内容只在隔离 tmpfs 配置中使用，审计后删除；没有真实截图或人工目视验收。
FileManager 在这里是 KOReader 实际插件宿主；测试从插件书籍详情打开标记，不是让用户从文件管理器阅读网页。

两尺寸合成场景覆盖正例书签、长引用、中文、有效 UTF-8 表情、未知类型、筛选及独立进程重开。
原生额外核对服务错误、错误书籍回包、保存失败、取消中断、关闭详情和旧详情操作；错误结果均未覆盖旧副本。
合成截图目视检查了菜单边界、分页与可滚动原文。模拟环境字体没有对应表情字形时显示缺字符号，原始文字未删改；不据此宣称全部字形可显示。
验证工具最初把合成表情写成 JSON 代理对转义，运行时解码器产生非法 UTF-8，模型按预期拒绝。
改为直接 UTF-8 传递合成输入后通过；线上若出现无法正确解码的文本仍会保留旧缓存并报告失败。

自动检查与固定候选范围见[本批证据](validation-assets/2026-11-11/my-cloud-marks.json)。
实体 KO2 的按键、休眠、联网及字体仍待连接设备后验收；本批只读浏览不代表整个迁移目标、笔记写入或集中性能优化完成。
