# 公众号订阅

在书架的「公众号」页打开右上角选项，选择「管理公众号订阅」。列表包括书架中已有的公众号及已导入文章所属的公众号；选择其中一项，可查看已保存的书架状态，并通过「更改云端书架状态」预览订阅或取消订阅。实际操作前会重新读取完整书架并显示确认。取消订阅保留已下载文章和本机阅读记录。

变更沿用账号隔离的待核对记录：发送前保存意图，只派发一次；明确成功回执及独立读回一致后才结束。读回还核对其他条目的成员、可见标记和分组。取消、账号或授权变化、网络错误、未知回执和中断不会自动重发；有待确认结果时须先通过状态页的只读入口检查并明确接受当前状态。账号切换与休眠均取消未完成的界面任务。

参考 [weread-omni 的订阅接口](https://github.com/teng-lin/weread-omni/blob/main/src/api/resources/public-accounts.ts)（MIT），公众号使用墨水屏书架接口，附带空的专辑和分组数组。一个此前未订阅的公开样本已完成真实 Python「订阅→独立核对→取消订阅→独立核对」：恰好两次账号数据请求，无授权请求；原有成员、可见标记和分组恢复，授权及其他测试范围未变，见[脱敏记录](validation-assets/2026-11-17/mp-subscription.json)。这不证明服务端历史或排序完全恢复。

两尺寸打包 KOReader 的原生菜单、后台请求、本机待核对记录、订阅／取消和离线文章重开已用合成账号验证；其中还验证了订阅回执不明确时停止、保留待核对记录且不派发取消或重发。

随后在 1264×1680 模拟屏幕使用真实账号，从公众号书架选项进入生产界面，对同一计划先完成零写入预演，再订阅和取消各一次。每次操作后由宿主独立读取书架；确认订阅且其他成员、可见标记和分组一致后才允许取消，最终原书架和隔离测试配置中的导入文章记录均保持，测试期间无授权请求，临时配置已清理。见[脱敏记录](validation-assets/2026-11-17/mp-subscription.json)。更多公众号、整机断电和实体 Kindle Oasis 2 仍待验收；公众号历史文章目录的验证限制也仍存在。
