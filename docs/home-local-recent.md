# 首页本机最近阅读

从书城等入口打开一本书后，即使它没有加入云端书架，只要当前账号在本机留下了阅读记录，首页的最近阅读也会显示它。列表结合云端书架的最近阅读时间与本机时间排序，保留既有的 6、12、24 本显示上限。相同书籍只显示一次；此功能不向云端书架添加或删除书籍。

本机书籍必须有有效的普通书籍编号、正数阅读时间，以及与当前账号一致的阅读记录。若资料带有账号标记，也必须属于当前账号；退出登录或账号不一致时不展示这些本机专属记录。界面只使用书名、作者、封面等显示信息，不传递待同步位置等内部状态。已缓存书籍从首页进入时继续使用现有的原生阅读与位置恢复流程。

## 验证范围

使用隔离的合成账号和合成 EPUB，在 KOReader 原生宿主以 600×800 / 167 DPI 和 1264×1680 / 300 DPI 分别验证：

- 未读的书架外书籍不会提前出现；经插件书籍详情进入阅读后出现在首页。
- 首页直接打开缓存书籍并恢复页面；关闭模拟服务、新建进程后仍能离线从首页续读。
- 其他账号的阅读记录或资料不显示；本地书架快照在操作前后保持不变。
- 模拟服务零请求，阅读流程未执行云端书架或进度写入。

组件测试另覆盖编号不一致、重复书籍、异常时间和无效标题。

随后使用真实账号和真实正文，分别在上述两种尺寸的 KOReader 中只读验证了书架外续读：预先从公开书目选择不在 Web 和墨水屏书架中的一本书，核对当前章节明确可读，再由测试入口提供书籍资料并打开插件详情。进入阅读、翻页、关闭后从首页续读到同一页面，以及全新进程断网从首页再次续读均通过。每轮前后独立核对 Web／墨水屏书架的可观察成员与标记、分组及 Web 阅读位置；所观察状态一致。两轮阅读验收均没有账号数据或授权写入，失效的墨水屏授权在此前单独续期一次。凭据和真实正文只通过内存管道及临时内存文件系统处理，未保存真实截图。

这项验收使用预先选定的书籍资料进入详情，不覆盖书城搜索选书，也不证明其他书籍、完整多账号或实体 Kindle Oasis 2 的行为。前后比较只覆盖本轮观察的状态，不改变此前分组试验中基线差异的记录。见[脱敏结果](validation-assets/2026-11-18/owner-home-off-shelf.json)。

随后另在两种尺寸完成真实账号的[书城搜索到首页续读](validation-assets/2026-11-18/owner-store-home.json)：在插件书城输入公开搜索词，从实际墨水屏搜索结果选择一册不在书架的书，经原生书籍资料、阅读、翻页、首页续读和新进程断网续读。前后独立核对书架与所观察的阅读位置一致，无账号数据或授权写入。该隔离验收关闭封面预取及云端批注显示，书架通道使用 Web；封面与批注各有独立测试。本项覆盖一个有限的真实样本，实体 KO2 和其他书籍仍待验收。

进一步在两种尺寸同时启用所选书封面和云端划线显示，重复完整搜索、阅读与离线续读：真实封面在书城及首页绘制并由离线进程复用，个人标记快照在线读取及离线回读一致。所选真实书的个人标记为空；另有两尺寸合成非空划线组合验证，以及[真实非空个人划线的独立验收](personal-highlight-display.md#验证)。测试只为所选书预取封面，书架使用 Web 通道；前后所观察书架、标记与位置保持，零账号数据／授权写入。实体 KO2 仍待验收，见[组合记录](validation-assets/2026-11-18/owner-store-home-cover-marks.json)。

## 最近阅读与位置归属

旧版的 `recent_read_account` 同时用于首页时间和旧版续读／待同步位置的归属。现在首页使用独立的阅读事件，保存新事件不会改写旧字段；旧记录仍按原字段读取。新位置另行记录其所属账号，避免旧首页事件替新位置指定账号；退出登录时的事件和位置也不会继承此前账号。首页事件只补丁更新该书的阅读状态，不再重存全部书籍。

两种尺寸的原生宿主使用隔离合成数据核对了旧待同步位置、旧本机位置、账号切换、退出登录及新进程回读；新进程的模拟配置会重置账号，因此测试中重新选择第二个合成账号后回读。另已回归常规原生阅读、离线移动和重连。测试不使用真实账号，也未执行云端请求。

## 多账号阅读状态

同一本缓存书现在为各账号分别保存插件的阅读状态，包括本机位置、待同步位置和未确认的上传回执；退出登录使用独立位置。旧版共用记录保留原文件，能确认归属的字段在对应账号首次保存时复制到该账号的记录。原书籍资料被其他账号更新之前，会先保存确定旧记录归属所需的资料，避免切回旧账号时丢失；无法确认归属的旧位置不会自动分配给任何已登录账号，原文件仍保留。

两种尺寸的原生宿主使用合成账号验证了旧记录、第二个账号从书籍详情实际进入阅读和翻页、资料更新、新进程切回原账号，以及待同步位置和上传回执分别回读。普通离线阅读、重连及进程中断测试另行回归。以上均未使用真实账号。

KOReader 原生页面位置也新增了按账号记录：对插件已登记、且文件身份可核对的缓存书，阅读器打开时先等待文件加载完成，再恢复当前账号的页面；没有本机位置的新账号从开头开始。页面记录附在该文件原有的 KOReader 设置中，书签和批注沿用原有数据，并不会因此按账号拆分。两种尺寸的合成测试验证了两个账号各自翻页、字号变化后重新分页、全新进程回读和本机批注保留。

旧版页面如果能由当前账号的本机位置和文件身份共同确认，会保留并建立账号记录。无法确认归属时保留 KOReader 原有行为，不会自动认领。登录后，在符合条件的缓存书阅读器中可打开微信读书快捷菜单，选择「为当前账号保存本机位置」；该操作保存选择时的本机位置，不修改云端进度或原有待同步记录。滚动模式以当前可见文字作为锚点，纯图片视图无法使用此操作。即使保存后程序未正常关闭，下一次也会在核对账号与文件后恢复到该位置附近；原有 KOReader 页面和本机批注保留。两种尺寸的合成原生流程分别验证了自动迁移、不自动认领、翻页／滚动模式菜单操作及新进程恢复。

无法确认归属且尚未主动保存的旧页面仍可能在账号间共用；文件变化、身份无法核对或其他插件阻断设置事件时也会回退原有行为。已经被其他位置替代的旧页面找回、完整账号切换流程、真实多账号、其他文件格式和实体 Kindle Oasis 2 仍需继续完善和验收。
