# 首页本机最近阅读

从书城等入口打开一本书后，即使它没有加入云端书架，只要当前账号在本机留下了阅读记录，首页的最近阅读也会显示它。列表结合云端书架的最近阅读时间与本机时间排序，保留既有的 6、12、24 本显示上限。相同书籍只显示一次；此功能不向云端书架添加或删除书籍。

本机书籍必须有有效的普通书籍编号、正数阅读时间，以及与当前账号一致的阅读记录。若资料带有账号标记，也必须属于当前账号；退出登录或账号不一致时不展示这些本机专属记录。界面只使用书名、作者、封面等显示信息，不传递待同步位置等内部状态。已缓存书籍从首页进入时继续使用现有的原生阅读与位置恢复流程。

## 验证范围

使用隔离的合成账号和合成 EPUB，在 KOReader 原生宿主以 600×800 / 167 DPI 和 1264×1680 / 300 DPI 分别验证：

- 未读的书架外书籍不会提前出现；经插件书籍详情进入阅读后出现在首页。
- 首页直接打开缓存书籍并恢复页面；关闭模拟服务、新建进程后仍能离线从首页续读。
- 其他账号的阅读记录或资料不显示；本地书架快照在操作前后保持不变。
- 模拟服务零请求，阅读流程未执行云端书架或进度写入。

组件测试另覆盖编号不一致、重复书籍、异常时间和无效标题。以上为合成数据验证；真实账号下的书架外阅读和实体 Kindle Oasis 2 仍需验收。
