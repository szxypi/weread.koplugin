# 导入书的个人云端笔记

个人导入书（`CB_`）现在可从书籍详情和原生阅读菜单查看「我的云端划线」「我的云端书签」和「我的云端想法」。
使用墨水屏登录读取，筛选、分页及原文弹窗沿用普通书的原生界面；数据按账号存入独立缓存，断网后可重开。
接口错误、账号切换或保存失败时保留原有缓存。划线及想法的引用具备完整来源和唯一匹配时，
可以打开对应的原生阅读位置。导入书书签需要不少于 12 个非空白字符的预览，且预览与原文点吻合并在本章唯一，
才允许定位；没有足够预览的书签仍可查看。原文选区支持保存普通划线，已有普通划线可删除；
书签、样式和想法编辑尚未接通。

该功能只扩展读取所接受的书号，不放宽账户、章节或写入所用的数字编号校验。
导入书的想法创建、编辑和删除仍未接通；不能将读取成功视为这些操作的协议验收。
定位依赖原始章节、当前阅读文件和引用内容的精确核验；不匹配时会停止，而不会猜测位置。
公众号书号仍不使用此入口。

## 保存和删除普通划线

原生阅读器中选中文字后可选择「保存划线」；个人划线列表也可删除指定划线。
保存前会核对缓存和远端原文、账号、章节及完整笔记；与已有笔记重叠或无法确认来源时停止。
删除前核对完整标记与想法，关联想法的划线不能删除。导入书暂时只使用已验证的默认划线样式和颜色。
写入前持久记录意图，提交后独立回读；无法确认时提示检查，重新打开不会自动重发。

两种尺寸的原生界面已对封闭合成服务完成选区保存、正文显示、删除和离线重开；来源变化拒绝提交、
不确定结果不重发及只读恢复通过。真实自造 XHTML 书的新增／删除协议已单独通过，见
[协议验证](cb-highlight-write-protocol.md)；本次原生界面尚未对真实账号写入，实体 KO2 和其他格式仍待验收。
两尺寸合成界面的运行记录见[原生验证结果](validation-assets/2026-11-19/cb-native-highlight-edit.json)。

可复现合成原生测试：

```sh
  --koreader /path/to/runtime --run-dir /path/to/new-marks-profile

  --koreader /path/to/runtime --run-dir /path/to/new-thoughts-profile
```

`scripts/verify_cb_personal_notes.py` 默认离线；显式选择已保存登录时只允许所选书架中的导入书读取。
