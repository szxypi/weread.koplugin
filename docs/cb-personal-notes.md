# 导入书的个人云端笔记

个人导入书（`CB_`）现在可从书籍详情和原生阅读菜单查看「我的云端划线」「我的云端书签」和「我的云端想法」。
使用墨水屏登录读取，筛选、分页及原文弹窗沿用普通书的原生界面；数据按账号存入独立缓存，断网后可重开。
接口错误、账号切换或保存失败时保留原有缓存。列表明确提示导入书暂不支持编辑或跳转原文位置。

该功能只扩展读取所接受的书号，不放宽账户、章节或写入所用的数字编号校验。
导入书的笔记创建、编辑、删除、正文图层和引用定位仍未接通；不能将读取成功视为这些操作的协议验收。
公众号书号仍不使用此入口。

## 验证

2026-11-19 只读检查本人书架中的六本导入书，六次划线读取共返回一条划线；
所选书的想法列表为空。所选书在两种屏幕尺寸均从实际插件详情打开、核对内容，
再以全新离线进程从账号缓存读取相同结果。实际原生 HTTPS 与独立 Python 投影一致；
读取前后导入书书架身份一致。共 13 次只读 GET，零账号数据 POST 和授权 POST；
真实书名、编号、笔记正文和凭据没有进入公开记录，临时配置和缓存已移除。
真实空想法结果不代表非空导入书想法已在真实账号验证。

两尺寸的合成数据各覆盖 45 条划线与 45 条想法、分页、错误与取消、账号隔离、离线重开，
并确认没有暴露尚未核对的编辑或定位操作。两尺寸另从原生阅读器的菜单打开三种笔记，
并在全新离线进程中复验缓存；其中人工检查了[小屏提示](validation-assets/2026-11-19/cb-notes-600.png)和
[KO2 尺寸提示](validation-assets/2026-11-19/cb-thoughts-ko2.png)。模拟器使用的字库未覆盖示例表情，
列表中的表情显示为缺字框，文字本身仍保留。真实非空想法、更多导入书格式、实体 KO2 及后续编辑／定位仍待完成。

可复现合成原生测试：

```sh
xvfb-run -a python3 scripts/test_my_cloud_marks_runtime.py --imported \
  --koreader /path/to/runtime --run-dir /path/to/new-marks-profile
xvfb-run -a python3 scripts/test_my_cloud_marks_runtime.py --imported --variant thoughts \
  --koreader /path/to/runtime --run-dir /path/to/new-thoughts-profile
```

`scripts/verify_cb_personal_notes.py` 默认离线；显式选择已保存登录时只允许所选书架中的导入书读取。
可选的原生流程通过私有管道交接登录和笔记，在临时内存文件系统中完成验证并清理。
