# 导入书的个人云端笔记

个人导入书（`CB_`）现在可从书籍详情和原生阅读菜单查看「我的云端划线」「我的云端书签」和「我的云端想法」。
使用墨水屏登录读取，筛选、分页及原文弹窗沿用普通书的原生界面；数据按账号存入独立缓存，断网后可重开。
接口错误、账号切换或保存失败时保留原有缓存。划线及想法的引用具备完整来源和唯一匹配时，
可以打开对应的原生阅读位置。导入书书签需要不少于 12 个非空白字符的预览，且预览与原文点吻合并在本章唯一，
才允许定位；没有足够预览的书签仍可查看。原文选区支持保存普通划线，已有普通划线可删除；
已有划线还可创建私密想法；已有私密想法可编辑和删除。书签及样式编辑尚未接通。

写入前会重新核对账号、章节、原划线和完整想法状态，提交后独立回读；结果不明确时保留本地草稿，
可通过「检查上次想法变更」核对，不会自动重发。导入书直接从新选区创建想法以及公开想法编辑仍未接通。
定位依赖原始章节、当前阅读文件和引用内容的精确核验；不匹配时会停止，而不会猜测位置。
公众号书号仍不使用此入口。

## 保存和删除普通划线

原生阅读器中选中文字后可选择「保存划线」；个人划线列表也可删除指定划线。
保存前会核对缓存和远端原文、账号、章节及完整笔记；与已有笔记重叠或无法确认来源时停止。
删除前核对完整标记与想法，关联想法的划线不能删除。导入书暂时只使用已验证的默认划线样式和颜色。
写入前持久记录意图，提交后独立回读；无法确认时提示检查，重新打开不会自动重发。

两种尺寸的原生界面已对封闭合成服务完成选区保存、正文显示、删除和离线重开；来源变化拒绝提交、
不确定结果不重发及只读恢复通过。真实自造 XHTML 书的新增／删除协议已单独通过，见
[协议验证](cb-highlight-write-protocol.md)。随后使用另一份自造书，在 1264×1680 原生界面先阻断预演，再各保存和删除一次；
每步由独立宿主回读，新进程离线重开通过，测试书已移除，原有书籍未修改。
本次真实原生验证见[脱敏记录](validation-assets/2026-11-19/cb-native-highlight-owner.json)；实体 KO2、其他格式和既有非空笔记仍待验收。

## 划线上的私密想法

在个人划线列表选择已有划线，可写私密想法；在个人想法列表选择私密想法，可编辑或删除。
草稿保存在当前设备并按账号隔离。提交前后都核对完整列表与目标内容；冲突或回执不明确时停止，
保留草稿供检查，避免重复创建。

对新上传的自造 EPUB，真实服务已完成添加测试划线、新建私密想法、修改、删除、移除测试划线，
每一步独立回读，随后移除测试书；原有书籍未修改。具体范围和限制见[协议验证](cb-thought-write-protocol.md)。
两种屏幕尺寸的 KOReader 原生界面已在封闭模拟服务完成划线上的私密想法新增、编辑、删除，
以及划线恢复和离线重开，见[合成运行结果](validation-assets/2026-11-19/cb-native-thought-edit.json)。
真实服务验证使用协议测试程序；实体 KO2 和真实服务中的原生界面仍待验收。
