# 原生选中文字写私密想法

普通数字书号的 EPUB，在原文模式中长按选中文字，点击「写私密想法」，核对引用后进入原生多行编辑器。
已保存的本机划线也可从「…」菜单进入；不修改、删除或自动上传这条本机划线。
未完成的原生选区模式和译文／双语模式不显示入口，公众号、CB_ 编号、TXT 及没有可核验原文的旧文件尚不支持。

引用限制为 4096 个 UTF-8 字节；想法正文沿用现有编辑器限制。可离线保存草稿，之后从选区窗口、
「我的云端划线」或「我的云端想法」的「本机想法草稿」恢复。恢复要求仍能从已知缓存文件中核对同一章、
同一原文摘要和引用范围；文件迁移后若原文相同也可恢复。来源丢失或变化时保留草稿，不自动改用相似文字。

当前已完成原生界面和合成读写验收，**新选区的真实云端写后回读仍待验证**。
此前[真实私密三步](native-thought-trial.md)只复用了已有服务端划线，其许可已使用，不扩大为新选区写入许可。
新增选区是否产生关联划线等服务端行为，也不能由现有结果推断。

## 范围与原文核对

原生位置、网页进度的筛选后 UTF-16 坐标及云端引用的原始 HTML Unicode 字符范围分开转换。
不能把阅读位置直接拼成引用范围。原始 HTML 仅在工作进程读取、解析和校验；UI 协作式采集两个端点附近的有限文字。
两个端点、完整选中文字和原文共同决定唯一范围，拒绝跨章、模糊匹配及实体内部边界。
脚注搬移可能改变端点附近文字，必须联合整个选区核对，不能只凭某一侧上下文选择范围。
请求中的引用采用原始范围的实际文字，确认界面同时显示引用和将要保存的想法正文。

新建前和确认后发送前，后台独立读取本人完整想法、当前原生书籍版本及 Web 原文章节。
目录前后版本、章节编号和序号、原始内容字节数及 SHA-256 必须与本机来源一致；账号、授权、阅读会话、
文档或位置变化使旧操作失效。原文读取只有既有 GET 和章节内容读取 POST，没有在此流程自动续期授权。
本次 52 条真实划线样本未提供原生 `chapterIdx`；新建载荷沿用已实测的无该字段形状，
Web 目录序号仅用于原文校验，不猜测为原生序号。

复用现有草稿、SQLite FULL 发送意图、原子领取、一次 POST 和独立完整读回。
原文预检耗时较长时，工作进程在可能发送前仍核对时间窗口，防止超过 120 秒或时钟倒退后领取修改。
取消尚未派发的预检可清除准备；已可能派发的记录保留待核对，不重发。
回执丢失可由独立读取确认；结果未知则保留草稿及记录，下一次提交不能绕过它。
各账号仍使用既有 16 条／2 MiB 草稿配额，没有往主设置添加新集合或保存整章引用。

## 已验证

Python 独立模型先对真实 52 条划线／5 章进行范围往返，随后 Lua 同输入逐字段一致。
最终当前工具再读原文两次并比较全部 52 条，原划线和精确阅读位置独立回读一致。
这些只证明引用转换，不证明新选区创建已被真实服务端接受。
首次预检遇到 HTTP 401 后停止；既有维护工具仅续期一次、核对账号和书架并回读钥匙串，随后完成验证。
包括准备及最终比较，本轮实际请求为 170 GET、200 个既有内容读取 POST、1 个授权 POST，零账号数据修改。
真实标识、正文、位置和凭据未写入持久报告，没有真实截图。

实际 KOReader v2026.07.1 Linux ARM64 的 600×800／167 DPI 和 1264×1680／300 DPI 均通过：

- 原生选区菜单、实体／表情／跨标签和跨段落引用、多行输入与完整确认；解析、校验和 HTTP 在后台进程。
- 离线保存与恢复，缺少原文授权时保留草稿；HTTP 401 不自动续期或发送修改。
- 来源变化阻止发送，取消检查及持久准备后的原文预检会回收任务、保留草稿并阻止旧任务派发。
- 新建、编辑、删除仅操作新记录，原有合成想法、本机附注和阅读位置保留；每份六次修改均仅作用于本机模拟服务。
- 创建／删除的空回执独立核对；无效果读回保留待确认，重试不重发；新进程离线恢复同一草稿及 pending，零 HTTP。
- 用户会话、账号、页面、原生选区和延迟按钮的失效保护；已保存划线菜单退出后的临时选区被清理，后续定位及关书同步继续工作。

最初两次为测试调用原生按钮字段和绘制时机错误；之后发现已保存划线的残留选区会阻塞进度定位，已修复。
复杂脚注邻居的单端点歧义改为联合完整选区判断；重开时只能从划线列表恢复的缺口也已修复，现可从想法列表恢复。
这些早期失败没有计为最终成功，两尺寸完整组合均从新配置重跑。
首页／书架／书城／统计／授权、原有想法编辑与中断恢复，以及进度、来源／授权恢复、成员和读完标记另行回归。
初版合成截图中的原生文字控件曾把部分表情显示为缺字框；后续已补齐[想法文字的局部字体回退](thought-text-fonts.md)，
两尺寸字形／位图、排版、确认和全新进程草稿恢复通过。本文初版截图与检查记录保留，后续显示修复另附固定证据。
