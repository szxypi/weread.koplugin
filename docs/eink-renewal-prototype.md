## 真实验证范围

- 登录、两次 `/login` 续期和两次续期后的 `/shelf/sync` 均 HTTP 200；书架均为 139 本。
- 两次均保持同一账号和设备标识。服务端未返回 `refreshToken`，沿用原刷新凭据再次续期和回读成功。

- 仅在字段缺失时保留旧刷新凭据；显式空值或无效格式仍拒绝。账号不匹配立即停止。

  不推断它等于 Web `bookVersion`。

这次验证的是有效会话的续期与读取。真实凭据过期后服务端的状态码／业务错误码、

## 复验工具

默认不联网、不生成二维码、不读取旧凭据；结果为 `PENDING_OWNER_SCAN`：

```sh

```

本人方便扫码时，使用已有的外层 `.validation/eink-auth-tools/` 环境或安装了 `qrcode` 的独立环境：

```sh
/path/to/python scripts/verify_eink_renewal.py --interactive --rounds 2 \
  --output /path/to/new-renewal-report.json
```

## 插件行为

- “微信读书 → 墨水屏授权 → 续期墨水屏授权”提供手动入口。
- 书架后台刷新遇到原生 HTTP 401 时最多续期一次，成功后重新读取原生书架；
  自动模式续期失败后尝试常规书架，强制墨水屏模式保留缓存并提示失败。
  HTTP 200 中的业务错误码尚未作为自动续期触发条件。
- 原生书城搜索／推荐／相似书籍、书籍资料、“我的”及详细统计遇到 HTTP 401 时同样最多恢复一次。
  成功后检查本次续期的修订号、账号和普通读取凭据，再重发一次原请求；
  原生分页保留原游标与推荐会话，仅本次拥有的续期可更新分页绑定修订。服务返回不同会话时仍拒绝混入。
  再次 401 不继续续期；首批读取可按既有策略回退，已经绑定原生的后续批次保留缓存。
  429 不触发续期或其他通道请求。
- 续期发送前，先将待确认标记写入同一授权主文件，并明确检查文件及目录同步结果和主文件回读。
  未确认写盘成功不发送。请求只在后台运行，凭据通过最多 64 KiB 内存管道返回。
- 新结果仅由父进程提交，绑定账号、登录代次和授权修订号。保存失败可只重试本地保存；
  仅书架验证失败时最多补一次读取，不再次发送续期。
- 取消、账号切换、休眠和关书终止任务。已可能发出而回执未知时保留待确认标记，
  新实例或重启不自动重放，需重新扫码授权；只有证明未发送时才释放标记。
- 书城和资料请求只取消自己拥有的续期任务；旧回调不会关闭新请求的等待窗。
  改变账号、普通读取凭据或外部替换授权时，旧结果不能提交。重新授权、清除授权、手动续期、
  关书与休眠都会先清理相关读取请求，避免等待锁遗留。保存失败时保留已有的本地重试入口。

94 组 Lua 回归与两个尺寸的真实 KOReader／合成 HTTP 运行通过，覆盖手动菜单、
HTTP 401 恢复、磁盘保存、取消后新实例拒绝重放及原阅读／下载流程。
以上插件运行使用合成账号；真实账号凭据未写入插件。KO2 文件系统同步和完整扫码仍待真机验证。
