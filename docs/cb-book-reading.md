# CB_ 书籍的目录、原生阅读与本机位置

CB_ 书籍现在可以从插件详情点击「阅读」，后台准备目录并下载正常续读章节，随后进入 KOReader 原生 EPUB 阅读器。
沿用按账号的目录／正文缓存及本机阅读记录；Web 只提供数据，不加载网页界面。
本项先验证目录与正文协议，再放开原先仅接受数字编号的未缓存阅读入口。
账号、章节编号、云端位置和其他写入接口的原校验保留。

## 协议验证

`scripts/verify_cb_reading.py` 默认离线。显式复用保存会话后，先核对账号，读取完整 CB_ 书架集合（最多八本），
逐本读取正常续读章节；未开始时选择目录中第一章可读正文，不更换成更容易验证的章节。
固定目录及内容 POST 都是只读查询；不会购买、开启试读、续期或修改阅读位置。
每个阶段／书籍有独立次数限制，失败停止，不跳过失败书籍继续宣称全部通过。

五本实际样本的五份目录合计 307 章，每本读取一个正常续读章节，均为 XHTML 来源。
Reader 会话、当前章、分片校验、样式查询、前后目录／版本和云端位置通过；随后五份 Python／Lua 本机模型一致。
307 是目录条目数，不代表下载并阅读了全部章节。没有真实 CB_ TXT 样本。
书名、编号、正文、位置、会话和凭据只留在内存／捕获管道；公开报告只有数量、布尔值和固定状态。
已核对的 Cookie 轮换按原有方式保存到本机钥匙串，授权继续保留至整体目标完成。

## 连续 XHTML 与本机定位

一份实际章节包含 37 段连续 XHTML，约 1.6 MiB。下载器本来就会合并这些正文，
但本机位置模型此前拒绝多个 body。现已增加明确的本机模式：最多 256 段、沿用 2 MiB 原始来源上限，
拒绝嵌套、未闭合、多余结束标签、控制字符和超限文档。跨包装仍使用原始 UTF-16 坐标，不重写来源。
原云端模型默认仍只接受单段 body；不能据本机支持推断云端坐标语义已经验证。

实际长章节另暴露从章末逐字回走导致的跳转超时。现先二分查找原生页边界候选，
只有完整章节前缀同时匹配固定的原生文字和字节前缀时，才用它缩短后续精确逐字核对。
不按页数比例推测位置，不搜索整本书，不保存不断增长的页码表，仍检查当前文档、来源和取消状态。

另一份正文的跨段原文引用未出现在原生文字中。同段引用现在优先用于本机反向跳转；
采集先尝试完整双侧上下文，必要时再核对单侧唯一片段，并确认反向引用仍落在同一原生位置。
多个精确结果冲突时拒绝定位。合成用例包含相邻段落被改写的情况；真实邻接文字没有导出或保存。
上传摘要仍使用原有默认引用，不从本机改进推导云端写入许可。

## 真实原生验收与回归

同一生产候选在官方 KOReader v2026.07.1 Linux ARM64／Xvfb 中，分别使用
600×800／167 DPI 和 1264×1680／300 DPI。每种尺寸按当次完整书架的排序，逐本选择五个 CB_ 条目，
各运行独立联网及全新离线进程，共十例、二十个原生进程。

每例均通过插件书架选择、详情「阅读」、正常章节下载、原始来源回执、可见正文、翻页、
实际原文位置采集、原生反向跳转、关书保存及新进程恢复同文件／页码／XPointer；
原目录字数单位与本机原文单位分开保存。每例独立回读云端原位置，全部未变，离线零 HTTP。
书架序号在每次运行内绑定实际编号；公开证据不保留跨运行的书籍编号集合封印。
真实页面没有截图或人工目视验收；配置和下载文件仅位于 tmpfs，结束后清理，凭据没有写入配置文件。

早期超时及原文定位失败均保留未通过记录，工具停止后独立核对云端位置；修复后才重跑最终十例。
含协议、诊断及所有界面尝试，本轮共 687 个 GET、300 个只读目录／内容查询 POST，
零账号数据或授权 POST，没有复用其他真实写入许可。

两尺寸普通书的正常选书／下载、原生阅读、离线重开、双向重连、正常／周期／定时／关书同步、
授权恢复、保存重试和成员操作，以及首页／书架／书城组合均通过合成 HTTP 回归。
[普通书阅读回归 600×800](validation-assets/2026-11-11/reading-regression-600.png)与
[KO2 分辨率](validation-assets/2026-11-11/reading-regression-ko2.png)使用自写合成正文，已目视检查。

187 组 Lua、61 份 Python 的 768 项检查通过，零跳过；498 个静态文件零警告／错误，
500 个 Lua 语法、165 个 Python 编译及命名空间通过。
五份候选各 208 个安装文件与源码一致，四份合成安装目录逐字节一致，ZIP CRC 和重绘检查通过。
范围、失败尝试、计数、源码与包哈希见[固定证据](validation-assets/2026-11-11/cb-book-reading.json)。
