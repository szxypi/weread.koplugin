# 我的云端想法：原生只读浏览

普通数字书号的书籍详情和阅读菜单新增「我的云端想法」。
原生 Menu 分页，按全部／有引用原文／其他想法筛选；原生 TextViewer 展示引用与本人文字，明确标示返回的私密状态。
无正文文字的条目显示提示，引用为空时仍可查看独立想法。这里只浏览已返回的文字，没有创建、修改、删除或分享操作，暂不渲染想法中的图片等附件。

## 协议与完整性

此前按 MiuRead `c1893562aa25a870b8dd076d7be062a3348f823e` 的 `listType=1` 查询时，返回了其他书籍／作者的记录。
本批依据 [weread_to_notion 的原始实现](https://github.com/toyoungtosimple/weread_to_notion/blob/aa828ac9f2b6ffc6e62872340bef11fed796b873/weread.py) 与
[Obsidian 插件的读取实现](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/0cb9d05174f203714731e96a7f181334306d5e7d/src/api.ts)，
先用独立 Python 验证 `listType=11`，再接入 Lua：

`GET https://i.weread.qq.com/review/list?bookId=…&listType=11&listMode=0&mine=1&synckey=0&count=20`

实际 3 条想法逐条具有正确的书号与作者标识，和笔记本声明计数一致。
每条都要求显式同书、本人归属，并核对包装层与正文的 reviewId；不以 mine=1 或请求书号代替回包验证。
只投影本人文字、引用、可用章节名称／编号、类型、私密／读完字段、时间和原始展示 range；不保存作者资料、令牌或远端游标。
个人返回条目全部保留，筛选以是否返回引用文字为准，不猜测未知 type 的含义。
后续限定私密想法实验发现，新建记录的 chapterUid 会以规范十进制字符串返回，旧记录则为数字。
Python 实际四条回读确认后，Lua 对该字段单独规范化为有界整数，缓存形状保持不变；其他数值字段仍严格校验。
拒绝前导零、指数、空白、布尔值和越界形式。真实三步往返及首次停止／接续见[实验说明](private-thought-experiment.md)。
网关的个人想法与笔记统计口径另见 [Tencent 的原始说明](https://github.com/Tencent/WeChatReading/blob/main/skills/notes.md)；本批实测使用墨水屏通道，没有套用网关的路径或认证。

实际请求 count=1 和 count=2 分别只返回 1／2 条，总数仍为 3，但 hasMore 均为 0。
因此同时核对总数，不能看到 hasMore=0 就保存为完整列表。
后台从 count=20 开始倍增，最多到 5,000；每次重新从 synckey=0 读取同一列表前缀，核对总数、前缀条目和实际条数确实增长。
数量或前缀内容变化、停止增长、回包不完整及达到上限仍未收齐时停止，保留原缓存。
读取到全部声明条目且结束标志一致后才保存，不持久化部分结果。单次响应仍受 4 MiB 接收上限约束。
真实 1／2 条前缀已独立验证；正常 20→40→80 的完整读取由两尺寸 45 条合成原生场景覆盖，不宣称真实账号具有 45 条样本。

## 位置核对与响应时钟

两次预检因完整位置回包不同而停止。随后记录限定字段的相等标志，确认唯一变化是根 timestamp；
章 UID、序号、偏移、百分比、摘要、阅读时长、书籍更新时间和其余字段均一致。
额外跨秒读取证明根 timestamp 对应本次请求时间，且阅读状态仍未变。
只读验证工具现仅排除这个已核对的响应时钟，检查其类型、存在性及请求时间窗口；所有其他字段，包括嵌套时间，仍必须相同。
原划线验证工具复用同一规则。生产阅读同步、上传坐标和报告逻辑没有改动。

## 页面、缓存与验收

与划线共用窗口归属和可取消后台读取机制，切换二者会关闭前一个窗口与弹窗。
账号／登录代次／文档／阅读会话／详情页／授权修订变化使旧结果失效；旧取消按钮不能取消新任务。
显式 401 最多通过既有父进程授权服务恢复一次，再从首批重新核对；其他失败保持原副本。

想法写入同账号 library SQLite 的独立 `my_cloud_thoughts` 表，划线仍在 `my_cloud_marks` 表。
两表各自保留最多 64 本、单份 4 MiB、JSON 总量 32 MiB，SQLite／WAL 开销另计；仅使用固定表名。
事务保存和配额淘汰成功后才替换页面，失败回滚。想法／划线不能互写快照，淘汰想法不删除划线；下载内容清理不删除这些快照。

两尺寸实际 PluginLoader／FileManager 详情入口、3 个真实想法原文弹窗、账号文件 SQLite 和全新离线进程回读均与独立 Python 模型一致。
另有真实空列表及原 52 条划线的回归。真实数据只在捕获管道、匿名描述符和隔离 tmpfs 中使用，审计后删除，没有真实截图或人工目视验收。
合成覆盖 45 条想法、长引用、无引用、无正文提示、20→40→80、私密标示、错误／取消／旧操作，以及原划线页面和主阅读流程。
合成截图可供目视检查；模拟字体的表情缺字不影响原始文字保留。实体 KO2、其他书号类型、附件、坐标跳转和笔记写入仍待完成。
