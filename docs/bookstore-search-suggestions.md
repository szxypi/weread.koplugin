# 书城搜索建议

首页或书城打开「搜索微信读书」，输入搜索词后选择「搜索建议」。插件在后台通过已登录账号的墨水屏授权获取建议，选择一项后使用该词进入原生书城搜索；查询前后的空格会被去掉。建议最多显示 10 条，不保存建议词；网络不可用或没有墨水屏授权时提示用户，原有搜索和已保存搜索仍可使用。

建议读取绑定当前账号、授权和输入框：取消、关闭窗口、切换账号或更改搜索词后，旧结果不会打开。明确 HTTP 401 时复用一次已有墨水屏续期；再次失败不循环重试。搜索词或响应不合规范时不会显示未核对内容。接口格式参考 [weread-omni](https://github.com/teng-lin/weread-omni/blob/fe8609071af33b013c7d2e34a70976fec906dc0c/src/api/resources/search.ts)；不执行第三方代码。

两种模拟屏幕的完整 KOReader 插件和模拟服务验证输入、后台读取、建议选择后的书城搜索、取消与输入变化；自动化另覆盖账号变化、空结果、离线、缺授权、异常响应和一次续期编排。真实账号的一个公开查询由 Python 与实际原生 Lua HTTPS 各只读一次，8 条建议的次序与内容一致；无账号数据或授权修改，凭据与结果仅经内存管道。实体 Kindle KO2、自然过期和更多查询尚未验收。见[脱敏记录](validation-assets/2026-11-19/bookstore-search-suggestions.json)。

真实账号进一步在两种屏幕尺寸通过实际 FileManager 插件入口、搜索框、建议列表、选词和书城结果：独立 Python 先读取建议及选中词的搜索首批，原生界面各自再读取并对照书号、书名、作者、封面、分类与分页信息；每轮均为 4 次只读请求，子进程限制为指定的两次 GET。配置与书城缓存位于临时内存文件系统，授权只经匿名描述符和管道，核对未落盘后清除临时目录；没有截图或账号数据写入。KO2 尺寸初次尝试未通过所选搜索词／结果数量核对，原因未保留；独立重试通过。后续一次并行准备在界面启动前失败，原因未保留；顺序重试通过。不同次独立运行的首批数量也有变化，不能把一次对照推广为搜索结果固定。见[真实界面记录](validation-assets/2026-11-19/owner-suggestions-ui.json)。

两种模拟尺寸另注入建议接口 HTTP 401：实际原生后台先续期一次并重试成功；连续两次 401 时只续期一次并停止，搜索输入仍由原窗口管理。自然过期和实体设备仍待验收。
