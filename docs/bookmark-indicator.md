# 原生云书签角标

当前原生视口包含已核对的本人云书签时，在右上页边距绘制空心书签。点击角标打开对应本人书签，
其他边缘点击继续交给翻页。多个书签同页时显示一个角标，点击打开原文顺序中的第一条，仍可在列表浏览其他记录。
显示开关已统一为「显示划线、想法和书签」，阅读结束窗口与手势动作使用相同名称。

书签与个人划线共用已有的按账号 SQLite 快照和一次后台读取，不新增接口或网络刷新。
每批最多八条，在工作进程核对归档身份、原始正文／渲染正文／元数据摘要后，将单点转换为唯一原文锚点。
原生阅读进程合作式查找该锚点，核对完整引用及到目标点的前缀，成功才交给独立角标图层。
点书签不转换为文字划线，不加入 KOReader 笔记数组，不改下载文件、本机折角或云端进度。

翻页模式使用原生当前页成员检查；滚动模式按实际屏幕坐标判断，排除视口之外与底栏区域。
绘制和点击都再次检查当前状态，未重绘的旧位置也不能打开已离开视口的书签。
角标按屏幕密度缩放，在窄页边距中缩小；空白仍不足时不绘制。与本机三角折角同时出现时错开位置，避免覆盖正文。
切章、切账号、文档会话变化、译文、隐藏、休眠和关闭均受现有生命周期与异步取消约束，删除后的确认快照会清除角标。

## 验证范围

官方 KOReader v2026.07.1 Linux ARM64 的 600×800／167 DPI 与 1264×1680／300 DPI 均通过实际原生控件、
工作进程、SQLite 与封闭合成 HTTP 流程：保存后显示、翻页消失、显示开关、字号重排、滚动可见、点击对应书签、
与本机折角共存、删除后移除，以及全新离线进程显示并定位。新进程零 HTTP，下载字节与本机笔记保持一致。
同轮回归还覆盖原生划线三种样式、未知结果保留、只读恢复、想法草稿和离线重开。

两份候选包各含 250 个生产文件，源码、包内与实际安装内容逐字节一致。
完整检查为 90 份 Python／1,084 项零跳过、222 组 Lua、621 个静态文件零警告／错误、623 个 Lua 语法、
275 个 Python 编译、四时区、命名空间及 TLS。额外边界测试覆盖默认窄页边距、无可用页边距、滚动底栏、
绘制原点、旧页面点击、失效原文、账号切换和取消后异步结果。
本轮没有真实账号修改或授权维护。书签保存／删除此前的真实两次验证独立见[原生书签往返](native-bookmark-trial.md)，
不能据此把新增角标认定为实体 KO2 或更多真实正文的验收。
