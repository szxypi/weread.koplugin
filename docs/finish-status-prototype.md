# 读完标记的协议准备

目标入口为书籍详情 → 书架状态中的读完标记。现有展示已按 `finishReading` 判断，
不以 `finished`、100% 进度或最近阅读时间代替。新的写入协议尚未实测通过，暂未加入 Lua 写入或菜单入口。

请求参考 MiuRead `c1893562aa25a870b8dd076d7be062a3348f823e` 的
`miuread/eink_client.lua:mark_book_finished`（AGPL-3.0-only）。
Python 原型只允许墨水屏 `/shelf/sync`、所选单书 `/book/getProgress` 的 GET，
以及明确执行模式下单书 `/book/markstatus` 的两次 POST。
标记体为 `bookId`、`auto=0`、`finishInfo=0`、`status=4`，标记／取消分别使用 `isCancel=0/1`。
没有登录续期、Web 通道、书架加入／移除、阅读时长或阅读位置写入路径。

## 限定往返

默认完全离线；`--saved-session` 只预览，不创建实验意图、不修改账号。
预览选择第一本编号有效且明确未读完的在架普通书籍，读取其原生章节、偏移及百分比。
完整成员及全体读完标记、所选位置、账号和当前授权共同绑定到计划摘要。
不会把 `finished` 当作读完标记的替代字段。

实际执行需要另一次针对该书及两步修改的明确授权，同时提供与预览一致的 `--expected-plan`。
计划变化、已有待确认读完实验或待确认书架实验时，发送前停止。
首次发送前将最大两次的实验意图保存到单独项目钥匙串条目，并回读一致后才开始。
意图只含账号、单书编号、原标记和摘要；没有凭据、书名、整份书架或原始位置。
登录凭据条目继续保留至整体目标完成。

1. 再读完整书架和所选位置；与预览一致后，尝试一次标记读完。
2. 独立 GET 核对目标标记、其余全部标记及成员、阅读位置。回读最多三次。
3. 明确成功回执及正确状态都满足后，发送前再次检查，然后尝试一次恢复未读完。
4. 再次独立回读，并额外进行最终全体标记／成员及位置核对，全部恢复才清除本次意图。

回执缺失、HTTP 拒绝、位置变化、其他成员或标记变化时停止。
不会为了恢复标记而在未知回执后继续第二次修改，也不尝试写回阅读位置或其他元数据。
可能已经发送的尝试保留意图，新进程不得重放；仅已证明零派发或独立验证恢复时才能清理。
因此异常可能留下读完标记，且无法保证恢复排序、完成日期、最近阅读记录或其他服务端信息。
这不是服务端原子事务，也不保证阻止其他设备同时操作。
