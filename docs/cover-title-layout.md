# 封面下的两行书名

首页、书架、书城及公众号封面共用的书名区域改用 KOReader 原生 `TextBoxWidget`，最多显示两行。
长书名自动换行，超出两行才在第二行省略；换行、制表符先归一为空格，原始书名数据不改写。
短书名与长书名的首行对齐，已下载标记放在首行旁，点击文字区域继续选中对应书籍。

标题保留原有字体和与封面左边缘的对齐方式。书格为第二行预留高度，相应缩短封面，
封面仍保持原比例；列数、行数及分页容量沿用现有布局。
没有新增偏好设置或接口，列表模式仍使用原来的单行列表。
