# 墨水屏首页、书架、书城：第一阶段

## 范围

本阶段以 `finlater/weread.koplugin` 为运行基底，迁移 MiuRead 的界面组织方式、
自适应标题布局和书城响应整理逻辑。保持主仓库原有的登录、下载和阅读服务，
没有整体替换为 MiuRead 的账号、数据库或同步系统。

- 主仓库基线：`cf9eeeb3b3bd206fc47c3429d50d8e4acba7be3b`。
- MiuRead 参考基线：`c1893562aa25a870b8dd076d7be062a3348f823e`。
- 引用代码的来源和 AGPL 声明保留在 `NOTICE` 和对应文件头。

## 入口与行为

- 工具 → 微信读书 → 微信读书首页：显示最近阅读，最多 12 本。
  本地开书记录与云端书架的阅读时间共同排序，不改变云端书架顺序。
  本地记录按账号隔离；离线时展示已缓存书架，点击已下载书籍使用原有的整本／章节缓存选择逻辑。
  首次安装没有书架缓存时，可以点击刷新获取书架。
- 统一底部导航：首页、书架、书城；后续阶段增加“我的”（见下文）。保留明确的返回入口。
- 新配置默认封面书架；已保存的列表／封面偏好保持不变。
  书架仍提供分组、筛选、排序、公众号、刷新和翻页。
- 书城提供“为你推荐”和全库搜索。点击推荐后加载数据；进入页面本身不发起网络请求。
  同一批的封面用原有网格翻页；“上一批／下一批”使用服务端游标。
  同批重复书籍会去重；不推进的游标不会生成下一批入口。
  当前批保留在内存，超过 15 分钟标记为缓存；刷新失败保持原内容。
  重启后不会保留书城结果，但书架仍可离线使用。
- 通用 `launch()` 入口进入首页；外部集成的 `openBookshelf()` 仍直接打开书架。

书城只使用主仓库已有接口文档中的 gateway `/book/recommend` 和 `/store/search`。
后续已增加相似书籍、排行榜和分类浏览，见下文。尚未接入双通道 E-Ink 授权、
离线时长补传或批注写入。
此版本是第一阶段开发版，并非微信读书墨水屏 App 的完整功能复刻。

## 文件组织

- `weread/ui/discovery.lua`：首页、书城及导航协调。
- `weread/lib/discovery_data.lua`：响应整理、去重、游标和最近阅读排序。
- `weread/lib/home_header_layout.lua`：由 MiuRead 移植的标题栏布局。
- `weread/ui/library_view.lua`：复用原有封面控件，增加导航和书城操作栏。
- `weread/ui/library.lua`：封面后台加载重绘保持当前页面，关闭或切换账号后忽略迟到请求。

## 相似书籍推荐

- 入口：书籍详情 → 更多操作 → 相似书籍，需配置 API Key。
- 仍通过主仓库已记录的官方 gateway `/book/similar`，不使用未验证的 Web 接口。
- 保留来源书籍、推荐会话和游标；上一批、下一批和刷新传递同一会话。
  更换来源书籍重新建立会话，清空旧的游标历史。
- 服务端会话变化或缺失时保留当前列表并提示重新打开；首批没有会话可展示，
  但不提供不可靠的换批操作。请求失败保留详情／当前列表。
- 关闭详情、退出界面或切换账号会忽略未完成请求的迟到结果。
- 已执行 77 组 Lua 回归、6 组 Python 合成 HTTP 测试；真实 KOReader 中通过
  原生按钮与事件循环完成首批 20 本、末批 5 本、上一批以及关闭详情取消的验证。
  600×800、800×600 和 1072×1448 三种灰度显示配置通过。
- 真实账号返回和 KO2 真机仍待验收；未发布正式版本。

## 排行榜与分类

- 入口：书城 → 分类·榜单 → 排行榜／分类浏览。
- 按服务端返回的树展示分类；有子分类时可选择“全部 · 分类名”或具体子分类。
  过滤非图书类别与无效标识，不硬编码排行榜名称或分类编号。
- 公开 Web 接口请求不附带 Cookie 或 API Key；无需登录即可浏览。
  选书后的详情、下载与阅读继续使用原有授权规则。
- 排行榜与分类的标识、rank 参数及游标保存在当前列表，切换分类清空翻页历史；
  刷新失败保留已有列表。菜单纳入关闭与账号清理，避免留在阅读窗口上层。
- 分类树保留在内存，超过 15 分钟标记为缓存，离线可打开已有分类菜单。
  “刷新排行榜与分类”重新拉取数据；分类书单仍需要联网，不承诺重启后的离线书城。
- `scripts/verify_bookstore.py` 已在 2026-11-08 无登录验证实际公开响应：
  分类树、飙升榜前两批、一个图书分类前两批，共 5 个 HTTP 200。
  报告仅保存接口、字段名和数量，见验证记录；Lua 接入在此验证后完成。
- 本地合成数据与实际 KOReader 覆盖榜单首批／末批／上一批、分类菜单与子分类选书。
  KO2 真机触摸、按键及刷新表现仍待验收。

## 当前页阅读进度

- 首页与书架显示已缓存的阅读百分比；可见书籍后台读取官方 gateway `/book/getprogress`，
  无需先下载书籍。翻页或滚动补齐新区域，手动刷新书架会重新读取当前可见书籍。
- 封面右下角与列表状态显示百分比。云端“已读完”标记继续从书架快照读取；
  尚未实现手动标记／取消读完。
- 进度快照存入当前账号 SQLite 的独立 `shelf_progress` 表，不写入阅读位置或待上传队列。
  当前账号绑定的本机待上传进度优先展示；不会用云端百分比覆盖它。
- 缓存有效期两分钟；离线保留缓存。单个请求失败停止本批剩余请求，并冷却 30 秒。
  切换页面取消旧任务，封面重绘合并同一批请求；关闭或切换账号后不再写入迟到结果。
- 后台进程不可用或内存不足时保留已有数据。长列表滚动停止后合并触发请求，
  更新重绘保留滚动位置，不自动遍历整架请求进度。
- 真实 KOReader 中验证后台 HTTP、进程通信、SQLite、分页、离线显示与账号隔离。
  测试云端 37%／本机待上传 83% 时显示 83%，原阅读位置不变；真实账号仍待验收。

## 我的、阅读目标与月历

- 底部新增“我的”，工具菜单也可直接进入。显示账号名称、今日／本月阅读时长、
  本月阅读天数、连续阅读天数与月度灰度热力图；可打开原有“详细统计”。
- 使用现有官方 gateway `/readdata/detail` 的月度每日桶，统一按北京时间计算。
  不将年度按月或总计按年的聚合桶当作日记录。
- 连续阅读从今天开始；今天尚无阅读时保留昨天结束的连续天数。需要跨月时继续读取前月，
  最多读取 24 个月；仍未遇到断点时显示“至少 N 天”。缺失月份不冒充已确认的零阅读。
- 每日目标为插件本地目标，默认 30 分钟，可设为 1–1440 分钟整数。
  目标与统计快照存储在当前账号 SQLite 的 `profile_state`，不修改微信读书的云端目标。
- 离线可看缓存；首次无数据时标记未知，不将未知日当作零阅读。缓存超过 15 分钟标记为缓存，
  联网且已配置账号时后台刷新；手动刷新失败保留原数据。
- 关闭页面、账号切换取消后台任务；修改目标时后台结果只更新缓存，不盖住输入框。
  目标输入框也纳入账号切换清理。没有后台读取能力的设备可使用原有“详细统计”。
- 同时修正详细统计的离线加载提示残留、关闭后迟到结果重开、快速切换周期和账号隔离问题。
  日期换算不再依赖设备当前时区偏移，覆盖历史时区变更、夏令时边界和跨年场景。
- 后台工作文件按进程与实例隔离，避免多个 worker 在同一秒重置随机种子时混用结果文件。
- 单元测试覆盖闰年、跨月／跨年连续阅读、缺失与无效日桶、秒／毫秒去重、目标校验、
  缓存写入失败、任务取消和对话框并发。真实账号数据与 KO2 硬件验收仍待执行。

## 首页定制与快捷设置

- 入口：首页右上角齿轮 → 首页布局；工具菜单的设置也可直接打开。
  首页独立选择封面／列表、舒适／紧凑封面密度和最近阅读 6／12／24 本，不改变书架排序。
- 时钟与设备状态、阅读概览、快捷入口均可隐藏；这些模块与最近阅读可上下排序。
  最近阅读保留，四项底部导航固定显示。快捷入口从书架、书城、搜索、我的、设置、刷新中
  选择并排序，最多四项；可全部隐藏。小规模配置保存在设备设置中，不包含账号阅读数据。
- 状态栏显示设备本地时间、有效电量及已有 Wi-Fi 连接状态，不通过联网探测刷新状态。
  阅读概览复用当前账号缓存的统计和本地目标，日期仍按北京时间；点击进入“我的”。
  没有统计时提示打开“我的”加载，超过 15 分钟标记为缓存。
- 每分钟仅在文字变化时局部刷新状态／概览；关闭或离开首页取消定时任务，休眠回调取消，
  唤醒回调立即更新后恢复。两个模块均隐藏时不启动定时任务。
  设置菜单打开期间，封面／进度更新延后重绘，关闭菜单后应用，避免盖住菜单。
- 快捷设置支持书中图片与下一章预下载，复用原有预下载确认及服务。
  前光使用 KOReader 自带控制，Wi-Fi 使用 KOReader 原生入口，具体能力由设备决定。
  不提供设备不支持的前光选项；模拟器中的色温控件不表示 KO2 支持色温调节。
- 已验证原生菜单修改后配置回读、保存失败回退、模块排序、恢复默认、原生翻页事件、
  前光控件打开，以及休眠／唤醒回调中的任务清理。
  Wi-Fi 委托有组件测试，未在运行环境切换真实网络；前光强度、实体键、实际休眠与耗电仍待 KO2 验证。

## 阅读进度的会话与休眠恢复

- 排队的云端读取、目录刷新、冲突选择和跳转后的位置采集，均检查账号、当前书籍、
  文件路径及阅读会话。关闭／重开书籍后释放旧读取任务，迟到结果不能清掉新任务的忙碌状态。
  两个进度来源之间再次检查，避免中途更换账号后继续读取另一个来源。
- 换账号或重新登录时停止时长上报，撤销旧同步任务、冲突选择及跨章跳转，重新关闭进度确认门槛。
  仅更新同一账号的 Cookie 不触发这一账号切换流程。
- 待上传位置单独保存所属账号的匿名标识，书架显示优先读取这个绑定，
  不随“最近阅读”的账号变更而转移。历史记录仍沿用已有最近阅读账号绑定。
- 忙碌重试使用固定快照；即使又保存了更新位置，旧上传回执也只确认自己的快照，
  不覆盖新本机位置或删除更新的待上传记录。原书籍关书上传仍可完成，但不改变后来打开书籍的状态。
  同一本书重开时由新会话重新比较；选择云端位置会取消被替代的本机待上传意图。
- 同步比较使用返回时的实际阅读页；点击“保留 KOReader 进度”时重新捕获当前位置，
  避免读者等待联网或对话框期间翻页后仍上传旧页。每个冲突选择只能执行一次。
- 休眠时取消排队请求，启用关书上传时把尚未同步的位置先保存在本机，不启动休眠网络任务。
  唤醒后若有未完成上传，先重新比较云端位置再恢复时长上报；关闭自动拉取时需手动同步。
  不把旧排队上传直接延续到唤醒后，也不把这一位置记录当作离线阅读时长补传。
- 已在真实 ReaderUI、原生事件调度、实际 Client、本地 HTTP 和磁盘记录中验证账号切换、
  正常上传回读和休眠回调；进度组件共 154 项检查通过。
  当前映射仍使用原有目录字数比例，尚未完成章节原文精确坐标迁移、真实账号多设备同步或离线时长补传。
