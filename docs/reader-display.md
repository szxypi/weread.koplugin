# 页面显示

阅读时打开微信读书快捷菜单，选择“页面显示”，可控制 KOReader 状态栏及进度条，选择当前页码、阅读百分比、本章剩余时间、当前时间和电量。可选择同时显示多个项目，或依次轮换已选项目。设备或 KOReader 版本不支持的项目显示为暂不可用。

这些是 **KOReader 全局设置**，会影响其他书籍。进度条、页码和百分比按当前打开的文件计算；一本书按章节分别缓存时，它们反映当前章节，而非全书进度。状态栏若在 KOReader 中被禁用，需先在 KOReader 设置中启用并重新打开书籍。

设置使用 KOReader 原生状态栏的菜单操作，离线可用。切换状态栏可能引起页面重新排版；实现会保持当前阅读位置。关闭书籍或设备休眠会关闭面板，避免旧会话继续修改设置。

验证：600×800 和 Kindle Oasis 2（1264×1680）尺寸的 KOReader 模拟运行中，合成书完成面板操作、阅读位置核对和全新离线进程重开，见[小屏截图](validation-assets/2026-11-20/reader-display-600.png)和 [KO2 尺寸截图](validation-assets/2026-11-20/reader-display-ko2.png)。状态栏与排版、页边距及进度面板的组合流程也在 KO2 尺寸通过。实体设备尚待验收。
