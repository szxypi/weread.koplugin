# 单章跨文件链接与返回

单章导航已接入原生阅读器：从实际源 EPUB 恢复原链接，按目录识别同书目标章节，
独立核对缓存和唯一锚点后打开。缓存缺失时沿用现有单章下载器，完成后重新核对，
不凭目录计划直接跳转。跨文件后退／前进和原文中的返回链接均已接入。滚动阅读在排版一致时额外恢复准确的像素偏移。

## 准备结果

| 结果 | 已核对的内容 | 后续含义 |
| --- | --- | --- |
| `ready` | 源文件身份、源链接确实存在、目标包的书籍／章节标识，以及唯一目标锚点；已知版本不能冲突 | 新阅读器实例再次核对账号、书籍／章节、文件身份和真实 DOM 后打开 |
| `needs_download` | 原链接对应同书目录中的候选章节，缓存缺失或不可用 | 尚未证明目标锚点存在；界面可调用现有下载器，再重新准备 |
| `unavailable` | 来源变化、未知链接、歧义目录／目标、已知版本冲突或缺失锚点等 | 保留当前阅读位置，不能任意选择其他章节 |

目录计划与现存包内链接解析是两个接口。未知目标只能产生计划，不能通过现存链接的校验。
旧缓存的未知版本仅用于本机核对，不增加任何云端进度或时长上报权限。

## 来源与原生链接

原生单章 URI 已相对生成包内的 `OEBPS/text/chapter.xhtml` 重定位，
与原目录中的源文件路径不同。准备任务从原生实际选中的 URI 出发，
读取源包真实 XHTML 中的链接，恢复原相对路径后核对目录归属。
如果同一个原生投影对应不同的原始目标，会返回歧义，不能只凭文件名猜测。

实际发现原生“外部／缺失文件”链接已经做过 URI 解码；例如源链接中的 `%252A`
会在原生对象里成为字面 `%2A`。后台按该投影匹配，不再解码一次。
这与整书内部 `#_doc_fragment_…` 编码锚点的情况不同，两个分支分别处理。
中文、百分号文件名和 XML 数字实体锚点均经实际原生链接对象验证。

任务只读取独立 libarchive 描述符，不使用继承的阅读器／ZIP 句柄，不写缓存，
不接收 Cookie 或授权对象，不访问网络，不返回正文。链接专用扫描也不清理脚注正文或
输出其诊断内容。返回中只包含来源／目标身份、成员摘要和目标锚点等交接所需信息。

## 原生交接与历史

- 准备结果须绑定当前账号、授权代次、书籍、源文档实例、视口和目录快照；翻页、切书、
  休眠或取消后不打开旧结果。
- 缺失章节沿用现有单章下载流程，完成后重新核对实际包；切换到新 ReaderUI 后再次核对
  书籍／章节、文件身份和真实 DOM，再使用目标锚点。
- 切书前保留本机检查点与精确返回位置，保持正常的同步权限门槛；原生本文件历史和跨文件
  Back／Forward 必须一起验证，文件变化时不能把旧 XPath 套到新正文。

这些门槛已接入：`chapter_links` 在本实例的链接处理器上安装可撤销包装，只接管未解析的
单章本书链接；外部网址、本文件已存在目标和整书链接沿用既有处理。后续第三方处理器不会被拆掉。
后台错误、目标版本冲突和返回文件变化均保留当前文件；失败的返回不会消费历史，可在文件恢复后重试。
历史仅保存在内存，最多保留 64 个跨文件帧和每方向最近 256 项本地位置，不写入设置。
账号／授权代次变化后的旧历史不能跨文件打开。关闭阅读器后不持久恢复这份历史。

新增 71 项界面／历史检查覆盖过期回调不取消新任务、账号／授权／目录／文件变化、
下载完成不冒充目标证明、取消自有任务、返回失败保留历史、第三方包装和有界历史。
两种尺寸的完整原生流程验证缓存点击、中文文件／实体锚点、字面百分号、实际按需下载、
后退／前进精确位置、本文件历史优先、原文返回、翻页取消，以及已知版本／返回文件冲突。
不授予云端同步权限。见[导航验证报告](validation-assets/2026-11-12/chapter-links-navigation.json)。

## 滚动视口与会话恢复

初始实现仅保存原生文字 XPath。600×800 实测中，返回 XPath 相同，但视口由原先的
587 像素回到 561 像素，丢失行内的 26 像素滚动偏移。
现在在内存历史帧中同时保留原生位置和排版快照；书籍／章节及归档摘要先按原流程核对，
新阅读器再比较排版摘要、正文高度、页数、屏幕尺寸、显示模式和页脚布局。
只有这些值一致时才恢复旧像素位置，原生文字定位后的排版也会再核对一次。
未知排版、字号／屏幕／页脚变化或原生滚动边界改变时，回到已经验证的文字位置。
不向设置文件写入这份历史，也不因此增加云端同步权限。

精确滚动恢复时省略可选的原生链接位置标记，避免它显示在像素修正前的屏幕坐标。
普通翻页模式和排版变化后的文字定位保留既有标记行为。
新增 41 项独立检查覆盖精确恢复、各排版条件变化、未知摘要、原生边界／异常及旧格式历史。

两尺寸实际流程还覆盖：在后台归档任务运行时休眠、切换显示模式、关闭阅读器；
任务立即失效，唤醒和关闭后的迟到结果不自动打开文件；新的阅读器仍能正常使用链接。
另在目标章节打开期间实际修改源章节的字号，再返回，确认采用文字位置而未套用旧像素值。
这些属于原生运行时的生命周期验收，尚不代表实体设备的休眠／断电验收。
