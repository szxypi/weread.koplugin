# 我的笔记本

“工具 → 微信读书 → 我的笔记本”集中显示账号下有笔记的书籍。选择书籍后可以分别进入已有的云端划线、想法和书签页面；也可在首页设置里添加“我的笔记本”快捷入口。笔记正文的显示、搜索、原文定位及编辑仍由原有单书页面处理。

列表支持按书名、作者或书籍编号搜索；搜索忽略首尾空白，并复用书架的大小写及 Unicode 匹配规则。可切换原有顺序或按笔记总数从多到少排列，总数为划线、想法／点评和书签数量之和；数量缺失的书排在数量已知的书之后，同数保留原顺序。搜索和排序仅作用于已保存的列表，不联网、不改写云端或缓存；退出列表后恢复默认视图。

列表只保存书籍标识、标题、作者、数量、排序和读取时间，按账号保存在本机数据库。第一次需要联网和墨水屏授权；成功保存后可离线打开。再次联网时可手动刷新；授权过期时可使用现有续期流程。读取失败、数量不完整或保存失败时保留上一次缓存。列表中不支持云端笔记的书籍会显示提示。

## 验证与限制

真实账号只读探测中，服务端对 `count=2` 和 `count=100` 返回了相同的 15 本书，返回总数与列表长度一致。以第一本书的排序值传入 `lastSort` 后，墨水屏接口仍返回完整列表，不能据此假定它与 Skill 接口的游标分页行为相同。暂未证明其他账号的分页行为：如果服务端报告还有更多记录，或总数与返回数量不一致，插件会拒绝覆盖原缓存，而不会显示不完整结果作为完整列表。

模型和界面测试覆盖了空列表、格式错误、重复书籍、数量不完整、网络错误、取消、缓存写入失败和账号切换；模拟 KOReader 的 600×800 与 1080×1440 两种尺寸中，45 本合成书籍经完整插件加载、真实菜单、三个笔记入口及 SQLite 验证，另以真实账号的 15 本书验证原生 HTTPS 读取结果、逐页展示、三个单书入口、账号隔离和全新进程离线重开。单书入口在离线状态下核对导航，并未在本次测试中重新读取单书笔记内容；单书内容另有独立验证。测试只读，未修改笔记或书架，临时配置及缓存位于内存文件系统并已清理。尚未在 Kindle Oasis 2 实机上验证本入口。

搜索与排序另在 600×800、1264×1680 两种模拟尺寸通过 45 本合成书及真实账号 15 本书的原生界面和离线重开；包含搜索结果、清空、按数量排序及恢复原序，操作期间没有额外网络请求。测试覆盖筛选与排序组合、缺失数量、相同数量、输入过长、关闭后的旧回调以及后台刷新期间输入。真实样本未覆盖所有语言、异常数据及实体设备。

只读探测：`python3 scripts/verify_notebook_catalog.py --saved-session`；不带参数时不会联网或读取本机凭据。探测报告只包含字段、数量和校验结果，不保存书籍名称、内容或凭据。
