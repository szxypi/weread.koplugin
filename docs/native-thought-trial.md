## 逐步结果

1. 从实际 FileManager 中的书籍详情进入本人云端划线，打开原生多行编辑器，复用已核对的划线引用新建私密测试想法。
   生产后台服务发送一次创建请求；插件回读后，由独立 Python 再读完整想法、划线、书架标记和精确阅读位置。
   唯一新增记录的本人、同书、私密字段、文字和引用均一致后，才允许下一步。
2. 通过原生想法列表和编辑器，只编辑独立核对得到的新记录编号。生产服务发送一次编辑请求，插件与宿主分别回读，
   确认新文字、原引用和私密属性，原有记录及其他状态不变。
3. 在原生界面确认删除该新记录。生产服务发送一次删除请求；插件回读、宿主独立回读及额外最终回读通过。
   完整原有想法、划线、书架成员／标记、章 UID／序号／偏移／百分比均与原始快照一致，测试记录已不存在。

本次生产 Lua 客户端共 16 次真实请求：13 GET、3 数据 POST；宿主仅执行 31 GET，没有代发修改。
总计 **44 GET、3 数据 POST、0 授权 POST**，无重发、自动续期、额外创建或补充清理请求。
这不能证明笔记排序、服务端历史或操作时间完全恢复；这些不在可回读的原状态保证内。
