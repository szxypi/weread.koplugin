## 有界执行与恢复

执行器启动前重新核对原文、版本、完整本人划线与想法、书架标记及两通道精确位置。
真实执行会在独立钥匙串项目中先一次占用两个可能的修改额度，再启动原生进程；
创建后由宿主完整回读，确认唯一新增记录及原有集合未变，并再次读取后，才允许原生界面删除该记录。
删除后再次完整回读，核对原有记录和精确位置，最后清除本次意图。

Python 宿主没有账号数据 POST；所有修改都来自生产原生选区／列表控件、SQLite 发送记录、后台服务和实际传输。
测试专用门槛限制完整创建载荷，删除只能使用宿主确认的新编号，且不能命中原编号。
原生端与宿主端分别保存一次性状态；取消、丢失回执、进程中断或读回不一致均不释放下一次写入，也不重发。
即使尚未确认任何 POST，pending 也不能重启。其他笔记实验检测到任一种划线实验待确认时同样停止。

测试进程采用私有 tmpfs，登录通过匿名认证输入和捕获管道传递。
实际截图禁用，凭据、正文、引用、编号与位置不写入公开结果；退出后回收工作进程并删除临时配置。
原登录继续保留到整体目标完成。
