# 批量正文读取的请求间隔

批量下载在后台任务中读取正文时，Reader 和章节分片响应后等待一秒，再继续下一次读取。
间隔位于可取消的子进程内，界面仍可刷新或取消下载；单章阅读不增加等待。
此改动处理实际整书下载中断，不属于后续的整机性能或耗电专项。

## 已有失败与对照

同一排序首本 CB_ 书籍的独立 Python 预检曾完整读通 57 章，原始来源共 1,153,077 字节。
旧生产候选两次原生下载分别在第 56／46 章收到缺少书籍身份的阅读页，随后位置回读返回 -10102。
这些失败仍保留在[原交接记录](cb-file-handoff.md)，没有跳过章节或更换书籍。

限定诊断只给原生 Reader／正文请求增加一秒间隔，既有账号、传输范围和来源校验保留。
诊断下载完成 57 章并进入 725 页原生整书，三张已打包图片能由原生组件解码，云端位置独立回读未变。
后续页首位置核对未通过，因而整例仍为 UNVERIFIED；诊断结果不能替代正常生产流程验收。
不能仅凭这一对照确定 -10102 对所有接口的含义或其服务端原因。

## 后台实现

`weread/lib/download_read_client.lua` 提供任务私有的客户端代理，保留原响应与原设置，
只对严格 HTTPS Reader GET 和既有正文／样式分片 POST 增加等待，不增加、改写或重发请求。
原界面客户端、进度查询、账号写入、授权续期、目录和外部图片请求不受该代理的等待影响。
`Downloader:_runInterruptible` 仅在后台批量任务中构造代理，初始化、正文及需要后台处理的资源步骤使用同一规则。
取消仍沿用原生 Trapper 的终止和回收流程，已完成章节保留，已有完整 EPUB 不被半成品覆盖。

单章任务保留原客户端。缺少后台进程能力时，既有前台兼容分支不插入阻塞等待；
不能据 Linux 原生验收推断该兼容分支、其他平台或实体 KO2 已通过。
代理不改变读取失败后的既有有限重试、严格同书核对或授权恢复策略，更不授权任何新的账号数据写入。

## 遇到请求限制时暂停

整书下载若在阅读页、正文或样式请求中明确收到 HTTP 429，立即停止当前批次，不再重试该章或继续请求后续章节。已经完成的章节保存在原有续传目录，旧完整书不会被不完整文件替换；稍后再次选择「下载全书」可继续。单章或选章下载会停止并提示稍后重试，后台预下载也不循环重试。读取目录前遇到相同状态时会显示可读提示。其他临时读取错误仍遵循原有有限重试；此改动不推断 HTTP 200 中的业务状态，也不新增授权请求。

两种屏幕尺寸的原生模拟中，EPUB 与 TXT 均在第二章返回 429：首章完成后暂停、该失败章节只请求一次、后续章节未请求；恢复服务后复用首章并完成余下章节，新进程断网续读通过。单章／预下载停止、阅读页和样式响应、中文提示、工作进程及续传保护另经组件测试。[脱敏测试记录](validation-assets/2026-11-20/download-rate-limit.json)仅使用模拟服务；自然限流与实体设备仍待验证。

## 登录过期时保留下载

手动下载整书、选章或单章时，如果所选书的阅读页或当前章节请求明确返回 HTTP 401，立即暂停当前任务，不把过期当作普通临时故障重复请求。整书保留已经完成的章节；续期无法完成时提示重新登录后再次选择下载全书。已完成的完整书不会被半成品覆盖。选章或单章的未发布临时内容会清理，已有缓存保留。失败响应不能更新登录凭据，403、429 和不明确的错误仍按各自既有规则处理。

此前两种屏幕尺寸的 EPUB／TXT 模拟服务分别在第二章返回 401，核对第一章保留、失败请求只发送一次、后续章节未读取；服务恢复后再次选择下载全书，复用第一章并完成整书与新进程离线重开。这是当时的手动续传验证，并未模拟用户重新登录；记录保留在[原模拟记录](validation-assets/2026-11-20/download-auth-expiry.json)。

整书下载现会在上述暂停之后尝试一次同账号 Web 续期，核对持久回执和登录文件，重新读取该书阅读页与目录后才继续。目录内容变化、已知版本冲突、账号／页面／阅读会话变化或取消都会停止；第二次 401 不再续期。已完成章节通过原有检查点校验后复用，旧完整书保留到新书全部成功。若新目录没有返回版本号，重新生成的文件标记为版本未知；与既有手动续传一样，这不能证明已完成章节与后续章节来自同一内容版本。若新目录提供了正版本而旧检查点的版本不符，则重新获取对应章节。

两种屏幕尺寸的 EPUB／TXT 模拟服务在第二章返回一次 401，均完成一次续期、重新核对、复用首章及新进程离线重开；另验证阅读页过期、连续 401 后停止和手动重试。首次尝试因新目录未返回版本号而停止，调整未知版本处理后重测通过；原失败保留在[验证记录](validation-assets/2026-11-20/full-download-auth-recovery.json)。目录变化、错误回执、账号变化及取消另经组件测试。这些测试使用模拟服务，不能代替自然过期的真实账号验收。

手动选章和单章下载现也会尝试一次同账号续期，重新读取目录并核对所选章节及顺序后继续；由于未发布的临时内容已经清理，选章会重新读取本次所选章节。目录变化、账号或页面变化、关闭选章窗口、取消或第二次 401 都会停止。确认下载时保存账号、书籍和页面状态，迟到结果不会重新打开已关闭的窗口。云端位置缺章下载接入相同恢复流程，并保留原来的跳转意图检查。普通选书阅读仍沿用[原有流程](source-authentication-recovery.md#选书后的原生阅读)，后台预下载不自动续期。

两种屏幕尺寸的原生模拟验证了 EPUB 单章／选章续期，以及 TXT 单章和选章、阅读页过期、连续过期停止、缓存保护与新进程离线重开；整书续期、429 和正常阅读另经回归。旧位置映射的跨章节导航在两尺寸回归通过，该夹具只覆盖旧入口且未注入过期；首次运行因夹具误用当前原文位置入口而失败，区分入口后重测通过。当前原文阅读流程另行回归，但尚未验证真实云端位置缺章下载与过期同时发生。[脱敏记录](validation-assets/2026-11-20/manual-download-auth-recovery.json)仅使用模拟服务；自然过期及实体 KO2 尚未验收。

## 首次加载与刷新目录

书籍详情、目录页面和下载全书共用的在线目录加载已移入可取消的后台进程。阅读页或目录接口明确返回 HTTP 401 时，最多续期一次，核对同账号回执后重新读取；第二次 401 停止。403、429 和其他失败不触发续期；刷新失败时保留原目录。关闭目录、离开页面、切换账号或更换书籍后，旧工作结果不会更新缓存或打开界面。目录可读章节中的原始资料，包括已有图片资源地址，仍会保留；后台结果大小有上限。

两种尺寸的原生模拟覆盖未缓存目录、目录刷新、阅读页和目录各自过期、连续过期、限流、整书下载及新进程离线重开。首次模拟准备未清除详情页中已有的目录，未实际进入目标路径，已记录为未通过；修正准备后重跑通过。真实账号另只读获取三本书的目录，分别有 40、30、41 个可读章节；实际 Lua 目录投影与校验均通过，未发送账号数据或授权修改请求。这只验证真实目录结构，不代表真实账号自然失效或实体设备已验收。见[目录恢复记录](validation-assets/2026-11-20/catalog-auth-recovery.json)。

## 位置核对工具

独立 DOM 核对需要文字 XPointer，而原生页首可落在图片或结构节点。
验收工具现只在同一当前视口内解析可见文字，保留边界前的可见字符，不跨章节借用前一字符，
纯图片页或下页才有正文时拒绝。随后仍以完整 DOM／原文模型独立核对实际偏移，未删除坐标相等断言。
九项工具检查覆盖结构节点、相邻章节、纯图片页、已有文字点及滚动视口。

跳转后也不把逻辑书签假定为文字点。改为独立采集实际应用且仍位于当前页的文字锚点，
再次要求原文偏移相等；跨文件交接使用同样的独立检查。首次正常候选因此未通过的记录保留，
并非删除断言后将旧失败改为成功。
