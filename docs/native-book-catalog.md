# 墨水屏阅读目录准备

为后续直接使用墨水屏章节阅读，新增独立目录模型：按服务端顺序提供正章节编号、标题、章节索引、层级、字数和明确的免费／已购状态。仍复用已有的书籍身份、版本和权限核验；没有明确免费或已购证据的章节不会标为可下载。零编号资源章不作为可阅读章节。

目录附带独立摘要，覆盖原有身份与权限数据、顺序、章节索引和层级；缺失索引与零索引分开。若附加的展示字段无效或互相矛盾，不生成阅读目录，但保留原有权限模型，使现有章节下载不因新增展示字段检查而失败。现有墨水屏章节来源已复用同一目录读取方法，请求数量和授权行为不变。

本项只是直接阅读的数据基础，**尚未接入选书、阅读器或纯墨水屏下载入口**。目前正常下载仍需要原有网页正文与位置依据；墨水屏正文不能直接充当网页同步坐标。后续还需完成独立阅读入口、文件归属、本机续读、章节切换与云端进度／批注隔离和验证，不能将本项当作已支持脱离网页阅读。

三本真实账号书籍的目录（41、31、42 个正章节）已由独立 Python 投影与 KOReader Lua 模型逐字段对照，分别有 6、7、11 章明确免费或已购；前后书架投影一致，无账号数据修改或授权请求。修改后的原生章节来源另在真实账号读取一章，KOReader 与独立解包结果一致，零账号写入；该章节有一个未识别资源，不能由此宣称资源渲染完整。所有正文、目录、账号标识和凭据只经内存处理，见[脱敏记录](validation-assets/2026-11-23/native-book-catalog.json)。
