# 墨水屏公众号目录只读原型

本机已保存的墨水屏授权可以读取书架，但新目录接口尚未取得成功响应。
2026-11-09 最后一次请求的 Web 账号核对与墨水屏书架均为 HTTP 200；
`i.weread.qq.com/mp/chapters` 返回 HTTP 499，受限读取的 53 字节 JSON 错误体含 `errCode=-2041`。
这与既有 `weread.qq.com/web/mp/articles` 的 HTTP 200／`-2041` 是不同的请求路径，
均不能作为目录成功、分页或订阅的通过证据。

## 来源与请求范围

MiuRead 的 `mp.lua` 继续使用 Web 目录，没有对应的墨水屏目录实现。
新原型参考 MIT 协议、Copyright 2026 Teng Lin 的
[weread-omni 固定版本 public-accounts.ts](https://github.com/teng-lin/weread-omni/blob/88bd2e095d7d7ee423eaadf8f40653e72c5be6d4/src/api/resources/public-accounts.ts)，
独立实现 Python 请求与去敏观察，不复制该项目的传输层。

- 首次目录 GET 使用已有书架中的首个公众号编号、`count=20`、`synckey=0`，不带 `offset`。
- 显式选择两页时，满页之后按返回行数累计 `offset`，不带 `synckey`。
  `synckey` 在参考实现中是增量同步标记，不用于翻页；这些成功分支目前只通过离线测试。
- 每次调用至多读取一次书架和两页目录。每个生成的精确地址只可消费一次，拒绝请求体、额外参数及其他路径。
  不跟随重定向、不续期、不重试；没有订阅、已读、书架或其他账号数据写入。
- 使用既有墨水屏请求头和设备标识，不以更换身份、反复扫码或重放请求尝试消除验证要求。

## 真实过程与未完成项

首次书架返回 HTTP 401 后，单独通过已有受保护工具进行一次授权维护 POST：
续期成功、同账号的 139 本书架回读和钥匙串保存回读通过。
随后首次目录返回 HTTP 499；补齐有界错误体观察后，第二次明确得到 `-2041`。
本阶段合计 9 个 GET、1 个授权维护 POST，账号数据写入为零。
两次目录请求均只到首批，没有读取第二页。

[固定版本传输层](https://github.com/teng-lin/weread-omni/blob/88bd2e095d7d7ee423eaadf8f40653e72c5be6d4/src/api/mobile.ts)
将 `-2041` 解释为需要人工验证的挑战，区别于 `-2014` 限流和 `-2012` 授权失败。
本次实测只确认服务器错误码，未取得官方客户端的验证票据，也未证明其账号／设备作用范围。
如果官方客户端出现验证提示，应由账号本人完成；完成后仍需单独核对本机请求，不能承诺会自动恢复。
在外部验证状态变化前，不继续重试目录或为 `-2041` 再次续期。

按照仓库先做真实原型验证的要求，暂不把 `/mp/chapters` 接入产品 Lua。
已有原生目录入口、缓存阅读与导出保持原行为；真实成功目录、全量分页、订阅和文章链接导入继续待办。
开发授权保留在原有两个本机钥匙串条目中，直到整体目标完成或用户撤销。

## 诊断与离线验证

原型默认完全离线，不构造网络工具或访问钥匙串。
显式使用保存授权时，先验证 Web 账号，再从独立墨水屏条目加载绑定同账号的授权；
合法的 Web Cookie 轮换按已有归属保护保存，不因后续目录失败而丢弃。

成功响应最多读取 4 MiB，HTTP 错误体最多读取 64 KiB 加一个溢出检测字节。
报告只保留固定阶段、HTTP 状态、有界整数错误码、数量及静态字段的类型；
错误原文、未知键名、公众号／账号编号、标题、正文、URL、Cookie 和授权头不进入报告。
HTTP 200 的业务失败同样立即停止；授权失败、人工验证与限流输出不同的固定原因。
退出时清理内存中的授权副本，不删除钥匙串条目，不创建私有内容文件。

```sh
python3 scripts/verify_native_mp.py
python3 -W error::ResourceWarning scripts/test_native_mp.py
```

18 个离线测试覆盖精确地址与一次消费限制、GET 范围、页数预算、首批与后续参数隔离、
空／短页、非法书架与目录、HTTP／业务验证错误、授权失败与限流、矛盾／超界错误码、
响应上限及关闭、隐私投影、同账号前置核对、Cookie 轮换保留和失败清理。
合成成功响应不代表真实接口已通过。测试已加入 CI。

以下为显式真实只读命令；不要在验证状态未变化时重复执行：

```sh
python3 scripts/verify_native_mp.py --saved-session
# 仅在首批成功后需要检查后续参数时：
python3 scripts/verify_native_mp.py --saved-session --pages 2
```
