## 一次修改的边界

- 预览绑定账号、授权代次、界面／文档／阅读代次及 120 秒有效期。提交前重新取得完整书架和所选书位置；有变化即停止。
- 指纹包括所有书籍的在架身份、私密／置顶／读完标记，分组身份／名称／成员／显式置顶，以及所选书的精确章节、偏移和百分比。
  请求体及目标也绑定到同一计划；明确的全零未开始位置可用，混合零位置拒绝。
- 按账号的 SQLite 单行意图在请求前以 FULL 提交并原子领取。只发送一次 POST；不因未知回执、401、取消或重启自动重发／恢复。
  最多三次独立读取确认结果；修改其他字段或位置时停止，保留待核对记录。
- 回读确认后先保存书架快照，再结束意图。保存失败仍留待核对记录。检查待确认修改仅重新读取，双重确认保留当前状态，不撤回请求。
- 私密阅读、读完标记和书架加入／移除在原生界面互斥；关闭页面、换账号、换文档或休眠会取消所属任务，旧回调不能重开窗口。
  已领取的意图跨进程保留；未发送的准备可安全结束。

实际账号的 Python 与原生测试意图均保留已消耗的钥匙串记录，不允许旧测试再次启动。Web 和墨水屏凭证继续保留到整体目标完成。
实际凭证、书籍身份、书名及完整响应只经内存／私有管道或 `/dev/shm`；临时安装环境退出后删除，报告只包含数量、状态和布尔值。
