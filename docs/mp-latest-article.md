# 公众号最新文章

打开没有已保存目录的公众号时，插件在后台读取最新一篇；已有文章列表可通过「刷新最新文章」更新。最新文章按公众号和文章编号核对归属，合并进本机已有列表，不覆盖历史缓存或阅读记录。列表明确提示较早文章可能无法获取；它不是完整历史目录。已保存列表可在离线时重新打开，首次阅读仍使用现有公众号文章下载和原生阅读流程。

接口行为参考 [we-mp-rss 的微信读书公众号说明](https://github.com/rachelos/we-mp-rss/blob/main/docs/weread-mp.md)，独立实现读取和归属检查。旧目录接口仍有验证限制，插件打开公众号和刷新时不主动重复请求旧目录。新接口是只读的 Web GET，账号、会话、页面或缓存位置发生变化以及取消、关闭和休眠时丢弃旧结果；错误或不可识别响应不会替换已保存的文章列表。

一个真实已订阅公众号的最新文章已由 Python 与 KOReader Lua HTTPS 分别读取，编号和标题一致，且标题与实际正文对应，正文非空；独立回读确认书架及已有测试范围未变，无账号数据或授权 POST。见[脱敏记录](validation-assets/2026-11-17/mp-latest-article.json)。两个屏幕尺寸的打包插件已使用合成账号验证后台读取、保留旧文章及新进程离线重开。完整真实历史目录、更多公众号、真实账号完整界面和实体 Kindle 仍待验收。
