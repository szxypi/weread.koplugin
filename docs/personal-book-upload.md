# 上传本地书籍

在微信读书插件菜单中选择「上传本地书籍」，长按文件并确认，即可把文件导入微信读书云端书架。当前接受 EPUB、PDF、MOBI、TXT 和 AZW3，单个文件须大于 0 且不超过 200 MiB；原文件不会被修改。文件在后台分块读取并通过单个请求上传，云端书架独立回读确认后才提示成功。

上传期间若取消、账号变化、文件变化或结果无法确认，插件保留本机待核对记录，不会自动重复上传。下次进入上传入口时可先打开云端书架检查，再自行清除本机记录；清除记录不会撤销云端上传。记录按账号隔离，不含文件路径、正文或临时存储凭据。临时凭据只在上传任务内使用。

签名规则参考[腾讯云对象存储请求签名文档](https://cloud.tencent.com/document/api/436/7778)，导入流程参考 [weread-omni](https://github.com/teng-lin/weread-omni)。腾讯云[简单上传文档](https://cloud.tencent.com/document/product/436/14113)允许单次上传不超过 5 GB；200 MiB 是插件上限，并不代表微信读书服务端对每种格式和设备均保证接受该大小。单次请求不支持断点续传；网络中断时按待核对流程处理。插件使用 KOReader 原生界面与分块读取，不依赖网页阅读器。

三次真实账号合成 TXT 导入、独立回读和移除已通过：分别使用 Python、KOReader 原生上传执行器，以及 1264×1680 模拟屏幕上的打包插件原生菜单、文件选择与确认界面；移除由独立的验证程序执行。自造 EPUB 已在两种尺寸的 KOReader 阅读器中打开，Python 和原生上传界面分别完成真实导入、相同正文回读和移除。约 9 MiB 和约 199 MiB 的自造 EPUB 也已分别通过真实原生界面上传、正文回读和移除；约 199 MiB 样本同时在两种模拟屏幕下通过分块上传与取消测试。 恰好 200 MiB 的首份样本云端接收后未得到插件确认，独立核对正文后已移除；在延长大文件后台确认等待后，另一份同大小的自造样本通过真实原生上传、正文回读和移除。首次未确认的具体原因尚未确定；超过等待上限时仍保留待核对状态。原生界面在实际上传前，均使用同一测试计划完成了零写入预演。EPUB 首次预检遇到授权过期时未发送上传；独立确认 401、续期一次后以新计划完成验证。

自造两页 PDF 使用独立的 Python 测试流程完成一次真实上传。书架首次回读超时后，未重发上传；随后在两个书架来源中核对唯一新增测试书，确认转换正文与原文匹配，进入了原生阅读器，并移除测试书。首次测试章节只有一页，未满足原有翻页验收条件。随后使用另一份自造 PDF 完成真实上传，从插件书架进入原生阅读器并定位正文，在新进程中离线重开；云端位置和原书架经独立核对保持一致。单页验收不声称已测试翻页。另一份两页、文字较多的自造 PDF 经真实上传，转换后章节完成原生正文定位、翻页和离线重开；另一次使用独立测试书核对原始两页各自的开头和末尾标记，转换后的标记顺序正确；随后以另一份独立测试书核对该样本全部 92 行文字，各行在转换结果中各出现一次且顺序一致。该结果不代表复杂 PDF 的排版和图文混排均已验收。基于首次延迟，插件已延长后台只读确认等待时间；超过上限或取消时仍保留待核对记录，不重发上传。

自造 MOBI 与 AZW3 由自写 EPUB 经 Calibre 7.6 转换，固定文件及摘要用于重复验证；两种格式均已在两种模拟屏幕中被 KOReader 读取。两种格式各经一次真实账号 Python 上传，从插件书架进入原生阅读器、定位正文、翻页和在新进程离线重开，并独立移除测试书；云端位置与原书架经核对保持一致。随后三种格式各经 1264×1680 打包插件的原生菜单、文件选择和上传确认界面完成真实导入，再由独立阅读进程验证正文和离线重开，并移除测试书；MOBI 与 AZW3 另验证翻页。上传与后续阅读分别使用隔离环境，尚未验收同一配置内连续操作。

每次测试后均核对原有书架成员、可见标记和分组一致；该验证不能证明云端存储对象或服务端历史已被删除。两种尺寸的打包原生插件另通过合成服务的上传、异常回执与待核对恢复测试，见[脱敏验证记录](validation-assets/2026-11-17/personal-book-upload.json)。复杂 PDF 的排版与图文混排、上传后在同一配置中连续阅读、实体 Kindle 和云端处理历史仍待验证。

另使用一份可翻页的自造 EPUB 验证上传后的阅读链路：真实账号导入后，在 1264×1680 模拟屏幕从插件书架选书、下载正文、进入 KOReader 原生阅读器、翻页并在全新进程离线重开；读取前后独立核对同书的云端位置，随后移除测试书并确认原书架一致。目标书籍与合成正文在进入阅读器前再次核对；阅读过程没有派发账号数据写入或授权请求。读取期间服务端轮换的 Web 登录信息经账号核对后保存至钥匙串。
