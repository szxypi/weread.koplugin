# 上传本地书籍

在微信读书插件菜单中选择「上传本地书籍」，长按文件并确认，即可把文件导入微信读书云端书架。当前接受 EPUB、PDF、MOBI、TXT 和 AZW3，单个文件须大于 0 且不超过 8 MiB；原文件不会被修改。上传在后台进行，云端书架独立回读确认后才提示成功。

上传期间若取消、账号变化、文件变化或结果无法确认，插件保留本机待核对记录，不会自动重复上传。下次进入上传入口时可先打开云端书架检查，再自行清除本机记录；清除记录不会撤销云端上传。记录按账号隔离，不含文件路径、正文或临时存储凭据。临时凭据只在上传任务内使用。

签名规则参考[腾讯云对象存储请求签名文档](https://cloud.tencent.com/document/api/436/7778)，导入流程参考 [weread-omni](https://github.com/teng-lin/weread-omni)。插件使用 KOReader 原生界面与分块读取，不依赖网页阅读器。

三次真实账号合成 TXT 导入、独立回读和移除已通过：分别使用 Python、KOReader 原生上传执行器，以及 1264×1680 模拟屏幕上的打包插件原生菜单、文件选择与确认界面；移除由独立的验证程序执行。原生界面在实际上传前，使用同一测试计划完成了零写入预演。每次测试后均核对原有书架成员、可见标记和分组一致；该验证不能证明云端存储对象或服务端历史已被删除。两种尺寸的打包原生插件另通过合成服务的上传、异常回执与待核对恢复测试，见[脱敏验证记录](validation-assets/2026-11-17/personal-book-upload.json)。真实账号下的其他格式、大文件分片、实体 Kindle 和云端处理历史仍待验证；大于 8 MiB 的文件暂不支持。
