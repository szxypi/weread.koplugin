# 原生章节选区想法往返验证

使用真实账号的一本书、一个明确可读取的 EPUB 原生章节，在隔离的 KOReader 阅读器中，从正文选区进入「微信读书划线或想法」。选区由独立解析器选择，避开既有云端划线；墨水屏和网页原文字节一致，书籍版本与章节权限均重新核对。测试内容是新建的私密测试想法，不使用原有想法作为修改对象。

2026-11-23 验证过程：

1. KO2 模拟尺寸先运行禁止发送预演：实际生成的创建请求与独立计划一致，请求在发送前拦截，账号数据修改为零。
2. 正式执行前重新读取并比较原有划线、想法、书架和阅读位置。新建、编辑、删除各发送一次，每一步均由宿主独立回读，确认原有记录未被修改后才继续。
3. 删除后独立检查没有该测试想法，也没有需要清理的新增关联划线，因此未发送清理请求。最后核对原有记录、章节索引、书架和阅读位置与基线一致；临时环境及测试意图已清除。

测试使用隔离的原生阅读器宿主和生产插件代码，并非实体 Kindle 或完整插件实例的真机验收。两种模拟尺寸下，封闭合成服务另覆盖禁止发送、三步往返、回执丢失和请求未产生预期结果后的防重发；请求载荷不匹配、目标指向原有想法及最终凭据保存失败也有独立测试。结果不明时保留待核对意图，不能直接重放。

首次正式执行在任何数据修改之前遇到授权过期，停止后只执行一次已保存授权的续期，并独立验证同一账号和书架；随后重新读取原基线才启动真实往返。凭据保留在本机钥匙串，正文和测试内容未写入验证记录，详情见[脱敏结果](validation-assets/2026-11-23/native-direct-selection-thought-roundtrip.json)。
