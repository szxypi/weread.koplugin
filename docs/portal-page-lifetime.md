# 首页、书城操作与详情返回

首页和书城的原生按钮会延后一轮事件处理再执行。此前，退出或替换页面后，已排队的导航、
快捷入口、搜索和翻页仍可能重新打开旧页面；搜索框也不随原页面关闭。首页设置的旧回调和预下载确认同样缺少所属页面核对。
已用未修改的上一提交复现退出首页后旧导航重新打开书城的行为。

现在这些操作核对原页面、账号、登录代次、阅读文档／会话、书架和查询快照、读取方式及持久授权身份。
搜索框、分类选择、首页布局／快捷设置和预下载确认由所属页面管理；关闭、替换或上下文变化后，旧回调不能读取输入、保存设置或发起查询。
从主菜单单独打开首页布局设置仍可正常使用。没有新增接口或扩大云端写入权限。

封面与进度继续后台保存，弹窗打开期间延后页面重建；取消后显示新数据，切换页面后丢弃旧重绘。
首页的分钟状态更新也核对所属页面，避免在阅读会话变化后继续更新旧页面。

正常返回详情页需要保留原来的页面，同时使详情相关请求失效。本次在取消详情请求后先核对父页面，
再更新代次并重建父页面：首页、书架、书城保留当前页及原查询，生成新的可用按钮；旧按钮继续失效。
完整回归曾发现关闭详情后分类入口失效，修复后已重新运行受影响场景。

## 验证范围

- 193 组 Lua 通过，新增两页面的账号／授权／快照／来源／会话等边界，搜索替换、取消、提交和分类选择；首页设置及确认的正常与迟到操作；详情取消与父页面重建顺序。
- 63 份离线 Python、796 项检查、零跳过；520 个静态文件零警告／错误；522 个 Lua 语法、173 个 Python 编译、命名空间与四时区通过。
- 官方 KOReader v2026.07.1 Linux ARM64／Xvfb 的两种尺寸，实际 PluginLoader／FileManager 各运行两个独立进程，每进程 29 个首页／书城／书架操作场景。原生按钮排队、输入框、菜单、预下载确认、设置文件及详情返回均通过；查询派发边界在此场景拦截，正常 HTTP 查询另由完整组合及真实只读页面核对。
- 同一生产代码的两尺寸完整组合使用实际缩略图子进程与进度 HTTP，确认首页搜索框和快捷设置保持打开、取消后刷新；搜索／分类／相似分页、非空合成推荐、统计、授权与取消继续回归。另各运行普通阅读／同步／重连及缓存续读／原文交接／清理，共 8 个合成原生配置。
- 同一候选的真实账号书城，两尺寸各启动联网与全新离线进程。搜索两批 20＋2 本、相似两批 20＋6 本及空推荐，共 26 个视图，与各自同一次响应的独立 Python 投影和文件 SQLite 缓存一致；离线零请求。非空真实推荐仍未取得，未据此声明通过。

真实验证仅有 24 次应用层 GET，账号数据及授权 POST 均为零。真实缓存只存在于 Linux tmpfs，
授权使用匿名描述符及捕获管道，临时配置审计后删除；实际安装的 214 个生产文件与候选逐字节一致。
