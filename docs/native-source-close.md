# TXT 关书后的原生位置同步

开发分支已将 TXT 关书同步接到独立原生通道，尚未发布。关闭阅读器前只保存原文位置、文件身份、目录、
显示百分比和账号范围等普通数据；关闭后由后台重新打开归档并核对来源，再读取原生云端状态并发送零时长位置。
后台不访问已关闭的阅读器文档，也不调用 Web 位置发送器。

## 生命周期与异常处理

关书准备保留用户此前确认的云端位置，发送前重新比对；其他设备改动、文件或目录变化、换账号、取消、
超时和重新打开同一本书都会使旧计划失效。不同插件实例共享取消范围，旧计划的释放不能取消新任务。
来源准备单次最长 30 秒，包括一次来源授权恢复在内总计最长 35 秒；只有新收到的实际 HTTP 401 才能触发一次恢复。
原生授权过期仍停止，不进行写后续期或重发。

关闭前不能冻结有效来源时，保留本机检查点，不再退回已经停止的阅读器来源接口。
原生 SQLite 记录在请求前领取，明确成功后先保存本机结果再接受完成回执；本机保存失败保留可恢复记录。
缺少明确回执时保留待核对记录与本机意图，离线重开不重发。未知记录的用户恢复界面仍待补齐。

## 验收范围

[固定字段记录](validation-assets/2026-11-12/native-source-close.json)包含两个尺寸各五种实际 ReaderUI 场景：

- 正常关书发送，以及模拟云端生效但没有明确成功回执。
- 后台归档准备时取消、重开同书和切换账号；旧任务均不产生迟到的关书请求。
- 所有场景均先关闭原生文档，核对关闭后文档调用为零、后台子进程回收、计数保持、临时配置删除。
- 未知回执再由全新进程离线重开，HTTP 为零，原生待核对记录和本机意图仍在。

独立本机服务按原始 TXT 校验完整片段、坐标、签名、原生版本及零时长字段；Web 请求没有承担关书写入。
279 个安装文件与候选包和源码一致。249 组 Lua、117 个 Python 文件共 1481 项测试通过，Python 无跳过；
原有 XHTML 实际阅读流程和关书同步通过回归。

本页全部发送均使用合成账号和本机服务，真实账号修改及授权 POST 为零。600×800 与 KO2 尺寸仿真通过，
真实账号的关书写入、实体 KO2 和断电仍待验收。此前[真实手动写入与恢复](native-reader-trial.md)的范围已消费，
不能拿来重跑关书验证。
