# 原生章节云端上传预检

原生章节的进度上传仍未开放。当前新增的内部只读预检用于准备后续实现，不能派发上传请求，也没有用户界面入口。

预检将当前页面映射到已核对的 XHTML 原文位置，并从同一原文提取最多 20 个字符的摘要。它分别读取原生和网页云端进度，在章节原文读取前后各核对一次网页位置，再次读取原生进度和书架状态；书籍版本、账号、原生与网页的章节位置、阅读计数或书架变化时停止。摘要只在进程内传递，不打印正文或登录信息。

已有云端位置必须包含原生接口明确返回的非空摘要；无云端章节时，阅读计数必须全部为零。缺少字段或无法唯一定位原文时不生成预检结果。新预检保留云端原有的全书百分比，不根据单章位置猜测全书百分比；这不能说明上传后百分比会自动准确更新。

该结果显式标记不能派发，现有上传记录也不接受其 XHTML 坐标。单元测试覆盖来源或云端变化、字段缺失、账号失效及摘要长度；600×800 和 KO2 尺寸的完整原生阅读器模拟覆盖正常预检、云端位置变化和缺少摘要，既有来源核对与云端续读也通过回归。

另在两种尺寸的隔离原生阅读器中，对同一本真实账号书籍完成只读预检：原生与网页原文字节一致，独立程序核对当前页的来源坐标，最终书架和云端进度不变；没有账号数据写入或授权请求，临时环境已清除。另一本缺少摘要的真实书籍按预期停止，且临时环境已清除；该次在预检阶段结束，未进行最终云端状态回读。脱敏结果见[验证记录](validation-assets/2026-11-23/native-direct-upload-preview.json)。原生上传与回读、结果不明时的恢复，以及实体 Kindle 测试均尚未完成。
