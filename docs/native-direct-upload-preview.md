# 原生章节手动同步与验证

在原生章节的「微信读书·快捷菜单」选择「同步本页到云端」，插件会核对账号、文件、原生及网页来源、章节目录、两端云端位置、摘要、阅读计数和书架。确认后再次检查全部来源与基线，再使用零阅读时长的原生请求上传；仅收到明确成功回执且独立回读完整目标和计数一致，才显示同步成功。翻页、文件或账号变化会取消当前流程。

原生和网页两端都未返回摘要时，预检会将其作为明确的缺失状态，不能当成空字符串或先前摘要。如果上传后仍未返回完整目标摘要，结果保持待核对，不声称成功。已有云端位置与原文一致时不发送；云端尚无章节时只在三个阅读时长计数均为零时允许准备。全书百分比保留云端原值，并非从单章推算，可能暂时与实际位置不一致。

发送前由账号隔离的 SQLite 记录绑定来源、位置和基线，领取发送权后不重发。回执丢失、回读异常或中途取消时保留记录；再次选择同步可只读检查云端状态，经明确选择后归档，不自动发送或撤销先前请求。同步过程中必要的原始摘要与待上传摘要会暂存于账号本机的同步记录，记录完成或归档后不再保留在活动记录中。自动同步、离线待上传和原生章节的批注同步尚未接入。

两种尺寸的完整 KOReader 原生模拟验证成功、取消、云端变化、回执丢失，以及缺少摘要的上传准备和写后只读核对；模拟失败情况下未重发。真实账号只读预检分别覆盖摘要存在和缺失的书籍，原文与独立位置核对通过。两种尺寸的隔离原生阅读器还分别对两类书籍走到实际发送边界，核对发送载荷并在出网前阻断；待核对记录正确保留，云端和书架未变，临时环境已清除。

真实服务器另由独立 Python 原生协议完成一次 XHTML 位置变更与原位恢复：恰好两次写入、两次明确成功回执，两端独立回读均确认位置和摘要；阅读计数及可见书架未变，没有网页写入或授权请求。该测试使用同一章的原生和网页一致原文以及独立唯一坐标；不证明最近阅读时间或服务端全部历史恢复。真实账号的完整原生界面写入、缺少摘要时的真实写入、更多书籍及实体 Kindle 仍待验收。见[只读预检记录](validation-assets/2026-11-23/native-direct-upload-preview.json)及[真实协议记录](validation-assets/2026-11-23/native-direct-upload-roundtrip.json)。
