# 单章缓存身份

单章 EPUB 的路径按书籍编号和章节编号共同生成，不依赖章节标题。两个章节即使同名、标题含有会被替换的字符，或者标题很长，也不会因为文件名相同而覆盖彼此。下载前及发布前会核对目标；已有不属于该章节或无法识别的文件会保留，并选择其他路径。

重新下载已有单章时，插件仅在旧文件能核对为同一本书的同一章节、且路径没有被其他章节共用时继续使用原路径，以保留 KOReader 按路径存储的阅读位置和笔记。旧文件无法核对或路径被多个章节共用时，插件保留旧文件及其本机记录，下载结果使用新路径；旧文件的本机记录不会自动复制到新路径。

对于已有多个章节指向同一文件的旧记录，插件会读取 EPUB 内的来源和目录信息：能确认的单章只供对应章节打开，能识别的合并文件继续保留；单章文件无法核对或与所选章节不符时，不再把它当作目标章节。选章时会提示重新下载，续读时若只能打开其他已核实章节会先提示；合并文件未包含续读章节时也不会静默替代。已识别的合并文件沿用原有打开方式，仍需另行验证能否跳至选中的章。没有可核实缓存时保留旧文件并提示下载。此前已被覆盖的正文无法凭缓存自动恢复，原有共享映射不会自动修改。

验证使用两种屏幕尺寸的真实 KOReader 模拟环境：合成普通书同名章节经单章及批量下载分别打开、核对原文身份并离线重开；KO2 尺寸的导入书也完成同样验证。可核对的旧文件重新下载保留路径及模拟笔记，旧路径共用时不覆盖；后台预下载发布前会话变化时保留已有文件。真实账号各在两尺寸完成普通书单章下载、原文核对及新进程离线重开，云端位置不变，未修改账号数据，见[小屏记录](validation-assets/2026-11-20/owner-chapter-path-600.json)和 [KO2 尺寸记录](validation-assets/2026-11-20/owner-chapter-path-ko2.json)。真实账号同名章节、旧缓存和实体 Kindle 仍待验收。

旧共享记录另以合成 EPUB 在两种尺寸检查了单章误映射、不可识别文件、含封面目录项的合并文件及确认后重新下载；KO2 尺寸另检查导入书。云端位置入口也有不可核对缓存的提示测试。真实账号在 KO2 模拟尺寸完成普通阅读与离线重开回归，见[记录](validation-assets/2026-11-20/owner-shared-cache-ko2.json)；该记录不包含真实共享缓存，真实旧缓存与实体设备仍待验收。
