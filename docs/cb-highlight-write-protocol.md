# 导入书划线写入协议验证

2026-11-19 使用单独上传的自造 XHTML EPUB 验证导入书的划线接口：
在源章节及其目录、账号和书架分别核对后，仅对新书创建一条测试划线；完整回读两次后仅删除这条划线，
再独立核对原始标记、想法、原生阅读位置、源章节及目录。测试书随后从书架移除，书架投影回到基线。
实际发送一次新增和一次删除，均未重发；另外发送一次文件上传、一次导入通知和一次测试书移除。
没有修改已有书籍，也没有在报告中保存账号、书籍编号、原文或凭据。
结果见[脱敏记录](validation-assets/2026-11-19/cb-fixture-highlight-trial.json)。

上传、两次标记修改分别使用独立持久记录。写入前核对自造书的上传回执、同一账号、正文哈希和预期请求；
如果结果不明确、原记录发生变化或权限发生变化，就停止并保留测试书和待核对状态，不自动重发。
测试模型覆盖这些中断、目标替换和外部变化。最初只读预检两次遇到 HTTP 401；使用原开发钥匙串中的
同一设备授权续期一次并核对同账号书架后，重新完成零写入预检，再进行试验。

这证明一份自造 XHTML 导入书的普通划线新增／删除协议及所观察的回读，不代表导入书的原生编辑器、
已有标记、多种正文格式或 Kindle 真机已验收。后续已接通原生保存与删除，两尺寸合成服务和一份
自造书的真实原生保存／删除通过，范围见[导入书个人笔记](cb-personal-notes.md)。书签和私密想法写入也已接通，详见该页。

工具默认完全离线；`--saved-session` 只进行书架预检，`--apply` 才会执行一次新试验。
试验使用的一次性上传记录在完成后保留，禁止重跑同一实验。

## 导入书划线样式

另一份新上传的自造 XHTML EPUB 完成四次独立核对的标记请求：默认划线新增、改为直线、改为波浪线、删除。两次修改均保留默认颜色和原文；最终核对来源、目录、阅读位置和原有标记，移除测试书并核对书架恢复。没有修改已有书籍或输出私人数据。见[脱敏记录](validation-assets/2026-11-19/cb-fixture-style-owner.json)。这次由独立客户端调用真实服务，覆盖一个自造样本；当时其他导入格式、彩色划线和实体设备尚需验证。

原生界面可调整默认颜色导入书划线的样式，保存后独立回读。彩色标记的后续支持见下文。

600×800 和 KO2 分辨率的 KOReader 原生界面已使用隔离模拟服务完整执行新增、直线、波浪线、删除及离线重开，每次写入后由外部独立读取；禁止发送预演也通过。KO2 尺寸另模拟两次样式修改各自未生效，确认本机保留待核记录，再次操作不重发。测试数据均为合成内容，不涉及真实账号；见[记录](validation-assets/2026-11-19/cb-style-native-mock.json)。

另一份自造 EPUB 在 KO2 分辨率的实际 KOReader 原生界面连接真实账号完成同样四步，并在每步由宿主独立回读，断网新进程重开后核对缓存和待核记录；测试书移除后书架恢复。原生操作前先进行禁止发送预演。该次未修改已有书籍，未保存私人数据；结果见[脱敏记录](validation-assets/2026-11-19/cb-native-style-owner.json)。这次未涵盖其他格式、彩色划线或实体 Kindle。

## 导入书标记颜色

独立上传一份自造 XHTML EPUB，使用独立客户端对标记样式的六种颜色逐个验证新增和修改：共 18 次有序标记请求，每次发送后独立回读，仅操作新建划线。最终删除所有测试划线并移除测试书，核对书架、原有记录、来源和目录；未修改已有书籍。异常时一次性领取记录会保留，禁止重发。详见[真实服务记录](validation-assets/2026-11-19/cb-palette-owner.json)。

阅读器现可为导入书的标记式划线选择默认颜色，并修改已有标记式划线颜色。默认颜色的划线可改变样式；非默认颜色划线的样式修改和非标记样式的颜色修改仍待验证。600×800 与 KO2 分辨率的原生模拟已覆盖彩色新建、改回默认、再次变色、删除和离线重开；KO2 模拟两处未确认情况均保留待核且禁止重发，见[模拟记录](validation-assets/2026-11-19/cb-palette-native-mock.json)。真实账号原生界面、其他格式和实体 Kindle 仍待验收。
