# 阅读排版设置

阅读时在「微信读书·快捷菜单」中选择「阅读设置」，可以选择设备上已有的字体，并调整字号、行距和字重。操作交给 KOReader 原生排版引擎，阅读位置由阅读器在重排后保留；固定页面文档等不提供相应排版控制的文件会提示无法调整。

在阅读设置中选择「页边距」，可同时调整左右边距或上下边距，也可使用紧凑、标准和宽松预设。调整会保留当前左右及上下的差异，触及边界时分别限制在允许范围内；当 KOReader 已开启上下边距同步时，两者保持一致。预设使用 KOReader 的当前预设值；同步开启而预设上下值不同时，采用两者的平均值。

设置通常保存在当前文件的 KOReader 阅读记录中。单章下载的每一章是独立文件；如果希望新打开的章节也采用这些设置，可选择「字体设置设为全局默认」并确认。此操作更新 KOReader 的全局默认字体、字号、行距和字重，其他没有单独设置的书籍也会使用；已有单独设置的文件仍以自己的设置为准。取消确认不会修改默认值。

页边距面板提供独立的「边距设为全局默认」：确认后保存左右、上下边距及上下同步状态，同样会影响其他未单独设置的书籍，不会更改字体默认值；字体设置的默认按钮也不会更改默认边距。

连续点击会合并为一次排版应用；正常关闭面板时先应用尚未执行的更改。阅读器、文件或账号变化，以及设备休眠会取消仍在等待的旧操作；等待期间如有其他地方更新同一设置，不会覆盖新值。字体选择和默认设置确认同样受当前阅读会话约束。

600×800 和 1264×1680／300 DPI 均使用打包插件和真实 KOReader 阅读器完成合成书验收：连续调整、字体切换、取消／确认默认设置、正文重排及阅读位置、休眠取消、单章间切换、整书和全新离线进程中的设置恢复。合成界面：[600×800](validation-assets/2026-11-20/reader-typography-600.png)、[KO2 尺寸](validation-assets/2026-11-20/reader-typography-ko2.png)。

真实账号的普通 EPUB 章节在两尺寸分别经过插件书架进入原生阅读、设置调整、选择字体、隔离配置中保存默认值和全新离线重开；云端位置前后相同，账号数据写入、授权续期请求和私密截图均为零，见[600×800 报告](validation-assets/2026-11-20/owner-typography-600.json)与 [KO2 尺寸报告](validation-assets/2026-11-20/owner-typography-ko2.json)。真实测试配置仅存在临时内存文件系统，不会改动日常使用的 KOReader 默认值。更多书籍格式和 Kindle 实机仍需验收。

页边距另在两尺寸完成实际 KOReader 合成阅读、三种预设、上下同步、取消／确认默认值、章节切换和离线重开验证；真实账号普通 EPUB 也在隔离配置中完成两尺寸原生调整、默认值保存与离线重开，云端位置不变且没有账号数据写入。见[600×800 报告](validation-assets/2026-11-20/owner-margins-600.json)、[KO2 尺寸报告](validation-assets/2026-11-20/owner-margins-ko2.json)和合成界面：[600×800](validation-assets/2026-11-20/reader-margins-600.png)、[KO2 尺寸](validation-assets/2026-11-20/reader-margins-ko2.png)。
