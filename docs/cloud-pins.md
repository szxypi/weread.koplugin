# 云端置顶

书籍详情 →「书架状态」→「修改云端置顶」。插件先读取墨水屏书架及所选书的阅读位置，再提供确认：明确已置顶时可取消；明确未置顶或云端未提供状态时可发起置顶。未提供状态会在确认窗口中标明，不假定原状态为未置顶。需要墨水屏登录及网络；目前仅支持普通数字编号书籍，个人导入书和公众号尚未接入。

置顶后必须收到明确成功回执，并独立读到该书 `isTop=true`；取消后必须收到明确成功回执，再读到 `isTop=false` 或原先存在的置顶标记消失。若标记消失，界面只报告成功请求和标记不再返回，书架状态仍显示「未提供」，不将缺失推断成明确 false。更新的书架快照会保存并刷新显示。用户还可以单独使用[本机置顶](local-shelf-pins.md)，该功能不与云端同步。

请求使用 `/shelf/top`，目标书籍与空的专辑／分组数组都写入请求；参数依据[开源客户端实现](https://github.com/teng-lin/weread-omni/blob/fe8609071af33b013c7d2e34a70976fec906dc0c/src/api/resources/shelf.ts)及[真实四步协议核对](pin-observability.md#真实置顶与取消2026-11-22-后续)。已真实验证 Python 客户端的置顶和取消、三通道回读及清理；另以真实账号的书架与所选书位置做只读核对，Python 和 KOReader Lua 的置顶／取消计划逐字段一致；[去敏报告](validation-assets/2026-11-22/cloud-pin-real-model.json)不含书籍或账号内容。真实账号原生确认界面已在 600×800 与 KO2 尺寸完成[只读验收](#真实账号原生只读预览)，生产写入界面另经合成服务与 SQLite 验证；真实账号原生界面写入往返和实体 KO2 仍待验收。

## 保护与验证

- 确认前后绑定当前账号、授权、界面和完整书架状态，并比较其他书籍的可见标记、分组与所选书章节、偏移及百分比；变化时不发送请求。
- 与私密阅读共用按账号持久化的操作记录，并与读完标记、书架成员操作在界面互斥。发送前原子领取记录；每次只发送一个请求，未知回执、中断和重启均不自动重发。回读成功后先保存书架，再结束记录。待核对入口只读取并允许用户确认保留当前状态，不自动恢复云端状态。
- 空数组必须编码成 JSON 数组；不支持的身份、异常标记、组或无法核对的位置阻止发送。取消置顶仅从明确的 `isTop=true` 出发；返回缺失与返回 false 分别保留。
- 合成服务使用实际打包插件、KOReader 界面、后台进程和 SQLite：两种尺寸验证置顶／取消、位置及其他状态保护、确认取消、回执丢失后跨进程只读核对和不重发，后台进程均回收；真实私密阅读模拟流程另作回归。报告：[600×800](validation-assets/2026-11-22/cloud-pin-ui-600.json)、[KO2 尺寸](validation-assets/2026-11-22/cloud-pin-ui-ko2.json)。

更多书籍、真实原生界面往返、实体设备，以及服务端未公开的操作历史和排序时间仍待验收。

## 真实账号原生只读预览

使用实际打包插件、临时内存文件系统、匿名授权描述符和原生详情／书架状态／置顶确认界面，两种尺寸各独立读取真实账号书架及所选书位置，界面生成的置顶计划与宿主独立计划逐字段一致。取消确认后再次触发旧按钮没有写入；传输层只允许该账号的受限 GET，所有 POST 在网络前拦截，未产生账号数据修改、授权续期或真实截图。前后独立回读的书架标记、分组及精确位置一致；模拟器安装字节核对、后台进程回收、凭据泄漏检查和临时环境移除通过。

[600×800 去敏报告](validation-assets/2026-11-22/cloud-pin-owner-preview-600.json)与 [KO2 尺寸去敏报告](validation-assets/2026-11-22/cloud-pin-owner-preview-ko2.json)仅包含状态和计数；书名、书号、原始回包与凭据不进入报告。此前一次预演因测试工具仍使用旧版本本地状态路径而在发送任何写入之前停止，修正后上述两尺寸通过。真实账号的原生置顶／取消写入、实体设备及服务端历史仍需后续验证。
