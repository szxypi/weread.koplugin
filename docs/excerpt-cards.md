# 书摘卡片迁移中

正在迁移 MiuRead 的书摘卡片：将选中的文字排成图片，提供模板与配色选择。本阶段仅接入离屏渲染与本地 PNG 写入底层，**阅读器菜单尚未提供入口**，尚不能作为完整功能使用。预览编辑器、选区和已保存笔记入口、手机局域网取图及真机验收仍需完成。

六套模板和十种配色来自 [MiuRead](https://github.com/miumiupy98-art/miuread-koreader)；来源和协议见 [NOTICE](../NOTICE)。图片在本机生成，不读取或修改云端笔记。输出使用独占文件创建，不覆盖已有文件；卡片文本为空、编码无效或超过当前 4096 字节限制时拒绝生成。卡片颜色渲染仅在同步绘制期间启用，结束或失败后恢复 KOReader 文本绘制。

使用打包插件及实际 KOReader 渲染器，在 600×800 和 1264×1680 模拟屏幕分别生成六套模板的两种配色，并检查 PNG 写入、重复保存不覆盖、无效路径和全局绘制恢复。图片使用合成文字；尚未覆盖界面、局域网传输、真实选区或实体 Kindle。
