# 书摘卡片迁移中

正在迁移 MiuRead 的书摘卡片：在微信读书插件的阅读器中选中文字，选择「书摘卡片」即可预览、切换六套模板及配色，并保存 PNG。静影模板可选择背景图；支持剪贴板的设备还可复制选中文字。图片保存在插件数据目录的 `exports/cards`，保存后会显示完整路径；样式选择保存在本机。

从「我的云端划线」或「我的云端想法」打开一条已保存记录，也可选择「书摘卡片」；有引用的想法使用引用原文，没有引用时使用想法文字。此入口可离线使用，书签的定位摘要不会当作书摘。手机局域网取图及实体 Kindle 验收仍需完成。

六套模板和十种配色来自 [MiuRead](https://github.com/miumiupy98-art/miuread-koreader)；来源和协议见 [NOTICE](../NOTICE)。图片在本机生成，不读取或修改云端笔记。输出使用独占文件创建，不覆盖已有文件；卡片文本为空、编码无效或超过当前 4096 字节限制时拒绝生成。卡片颜色渲染仅在同步绘制期间启用，结束或失败后恢复 KOReader 文本绘制。

使用打包插件及实际 KOReader 渲染器，在 600×800 和 1264×1680 模拟屏幕分别生成六套模板的十种配色或背景，并检查 PNG 写入、重复保存不覆盖、无效路径、长文字截断和全局绘制恢复。两种尺寸还从合成正文的原生选区菜单打开编辑器，检查模板切换、背景选择、保存、模拟剪贴板、屏幕重建、失败恢复、休眠取消与全新离线进程重开。图片使用合成文字；实际硬件剪贴板、局域网传输、真实账号内容及实体 Kindle 尚未验收。

合成界面：[600 像素预览](validation-assets/2026-11-20/excerpt-editor-600.png)、[KO2 分辨率预览](validation-assets/2026-11-20/excerpt-editor-ko2.png)、[笔记操作入口](validation-assets/2026-11-20/excerpt-note-actions-600.png)。前两张截图中使用模拟剪贴板，实际设备只有提供剪贴板接口时才显示复制按钮。

笔记入口在两种模拟尺寸分别用普通书和导入书的合成划线、引用想法与无引用想法验证，覆盖离线重开、账号变化和弹窗替换，不修改笔记。真实账号的 52 条划线与 3 条想法分别读取后，各选一条在两种尺寸的原生界面预览，并在独立离线进程重开；没有保存真实图片、截图或正文到普通磁盘，界面操作没有账号数据写入。真实验收从已选书籍详情进入，详情标题为测试值；跨书搜索中的书名和作者由合成数据验证。准备时先独立确认两次授权过期，续期一次并核对同账号及钥匙串回读；实体 Kindle 和其他真实笔记仍待验收，见[脱敏记录](validation-assets/2026-11-20/owner-excerpt-notes.json)。
