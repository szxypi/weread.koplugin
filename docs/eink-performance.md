# 墨水屏性能

## 连续书架列表

连续滚动的书架和公众号列表在重绘时跳过屏幕以外的书目和分隔线，同时更新所有书目的触摸区域和焦点位置。文字控件按需创建，滚出屏幕后释放；列表仍为每本书保留轻量行记录，不是完整的虚拟列表。翻页模式与封面布局沿用原来的绘制方式。

在打包插件的 KOReader 桌面模拟器中，使用 1,500 本合成书、八次滚动重绘，600×800 的书目绘制次数从 12,000 降至 124，1264×1680 从 12,000 降至 122；分别比较了开头、中间及末尾四个位置的截图，前后逐像素相同。点击、长按、焦点跳转以及镜像布局也已检查。三次运行的中位数及限制见[记录](validation-assets/2026-11-24/eink-long-shelf-performance.json)。

本次模拟器的整屏重绘时间没有出现可靠下降；记录中的 Lua 堆大小不是进程总内存。这些结果不能说明 Kindle 实际的刷新速度、残影、电量或内存峰值，仍需实体设备测量。

连续列表的点击、长按和抬手会直接定位到对应书目；滑动及拖动交还 KOReader 滚动组件，其他事件继续使用原有分发方式。1,500 本合成书、列表末尾的 200 次抬手测试中，两种模拟尺寸的书目检查次数均从 297,600 降至 200；四次滑动相关手势的行检查从 6,000 降至零。边缘、空隙、未知手势、点击、长按、滑动、拖动和焦点跳转均已验证；真实账号隔离书架的两尺寸在线／离线交互也通过，零账号数据修改。耗时仅为桌面模拟器的事件分发测量，不能代表实体设备的整体响应，见[记录](validation-assets/2026-11-24/eink-long-shelf-gestures.json)。

1,500 本合成书的三轮模拟测试中，连续滚动过程中保留的文字行控件最多为 16 个，修改前为 1,500 个。书目尺寸、140 条长短不一的公众号作者、焦点离屏后恢复及前后画面均已核对。最初发现关闭文字整形时极长作者导致尺寸不一致，现已改为精确测量，并在两种模拟尺寸下重新通过；真实账号的隔离书架另在两种模拟尺寸完成在线和离线交互。记录中的 Lua 堆占用不代表进程总内存，具体范围见[按需创建测试](validation-assets/2026-11-24/eink-lazy-shelf-rows.json)。

另以真实账号的隔离书架快照，在两种模拟尺寸验证连续列表滚动到底部、可见书目点击和长按，以及新进程离线重开；没有账号数据修改或真实截图，临时配置已清理。最初授权过期经两次读取确认后续期一次，并核对同账号与钥匙串回读。该验证没有测试实体设备，详见[脱敏记录](validation-assets/2026-11-24/eink-long-shelf-owner.json)。

在 Linux、图形环境或 `xvfb-run` 下，可对已构建的 KOReader 运行合成测试：

```sh
xvfb-run -a python3 scripts/benchmark_eink_long_list.py \
  --koreader /path/to/koreader --width 1264 --height 1680 --dpi 300 \
  --max-row-paints 500 --max-event-visits 500 --max-materialized-rows 50
```

测试不连接微信读书，临时配置位于内存文件系统；`--rtl` 可检查镜像布局，`--no-xtext` 可检查关闭文字整形的布局，`--screenshots` 可保存合成画面用于比较。

## 封面私密阅读标记

封面上的私密标记保留原来的圆角裁剪和图案，将相邻黑色像素预先合并成横向线段，重复绘制时无需逐像素调用。两种模拟尺寸的完整书架截图与优化前逐像素相同；另对 1,080 组大小、圆角和越界位置逐像素核对。

对单个合成标记连续绘制 20 次时，600×800 的绘制调用从 6,040 降至 720，1264×1680 从 26,320 降至 1,440。数字包含黑底和白色图案，不代表实体设备的整体速度或耗电，见[验证记录](validation-assets/2026-11-24/eink-private-badge.json)。可用 `scripts/benchmark_eink_shelf.py` 的 `--max-private-badge-paint-calls 1500` 参数在 KO2 模拟尺寸复验。

两种尺寸的完整插件模拟流程还覆盖私密标记与置顶、读完和进度标记并存，以及书架列表和筛选；470 组 Lua 测试通过。

## 长章节目录

章节目录保留各章节的轻量行与焦点坐标，只为可见行创建文字控件并绘制；离开屏幕后释放控件。点击按所在行分发，滑动仍由 KOReader 的滚动组件处理，实体按键导航可以将屏幕外章节滚回可见位置。

在 KOReader 桌面模拟器中使用 1,500 章合成目录，八次重绘的章节绘制次数从 12,000 降至 124（600×800）和 122（1264×1680），同时保留的行控件从 1,500 降至最多 16。列表末尾 200 次抬手事件的行检查从 300,000 降至 200。两种尺寸及镜像布局、关闭文字整形的前后各四张截图逐像素相同；每一行的尺寸、点击、滑动、焦点跳转与离屏后恢复均已核对。记录及测量限制见[合成结果](validation-assets/2026-11-24/eink-chapter-list.json)。

另在两种尺寸运行普通书的同名章节与进度面板，以及导入书目录和离线续读合成流程，均通过。
