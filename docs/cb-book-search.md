# CB_ 书籍的原生整书搜索

阅读器快捷菜单的「搜索整本书」现支持符合既有格式的 `CB_` 书号。接口按账号和当前阅读会话约束，查询与分页在后台执行。结果只作为候选：点击时核对书号、章节、引用、原始正文和本机文件身份，再由 KOReader 定位；未缓存目标章节时先确认下载。这里的 `CB_` 是编号范围，不单独证明书籍的来源。

本机跳转不验证云端阅读进度的坐标语义，不授予位置上传资格；原有 `CB_` 同步限制和个人划线／想法的编号限制保持不变。已缓存章节中的原生本机搜索也仍可使用。

## 真实数据范围

以同一账号的六本 `CB_` 书籍各一个 XHTML 章节进行只读检查，从可见正文序列构造 11 次有限查询。三本书的四次查询返回目标文字，范围与对应原文一致，也通过实际 KOReader Lua 的原文投影；该纯模型步骤使用合成书号。另七次查询未返回从正文提取的文字，原因尚未确定，可能涉及文本边界、分词或服务端内容覆盖。因此 `CB_` 结果列表和空结果都会提示本书的搜索结果可能不完整。这些样本不覆盖全部书籍、章节、查询词或 TXT 格式。

从一个返回匹配的样本，从目录首章发起搜索，在 600×800 和 1264×1680 隔离 KOReader 进程中分别验证了已缓存章节定位，以及取消后确认下载缺章再定位。下载由插件通过真实只读接口执行，下载正文与独立读取的原文一致；验证前后云端章节、偏移及百分比、目录、正文和书架顺序一致。没有账号数据或授权修改，也没有真实截图。凭据和正文只经内存、匿名管道及临时内存文件系统，临时配置已清理。普通数字书号也通过两尺寸真实账号的已缓存／缺章定位回归，登录恢复另经模拟回归。

云端返回导入书结果或空结果后，列表提供「搜索已下载章节」入口并带入相同搜索词，可选择本机搜索方式；已下载章节之外的内容不会被当作已检索。若有完整目录而部分章节未下载，结果页可选择下载全书并用原词重新搜索；下载前可取消，下载或索引失败的章节仍明确标记为未覆盖。当前打开的文件以及指向它的链接不能作为下载目标。两种屏幕尺寸的实际 KOReader 进程使用合成书籍验证了切换、本机跨章节搜索、取消下载和下载后重新搜索；仅下载阶段使用模拟网络。此功能不改变云端搜索索引的覆盖范围。

随后以真实账号的一本 57 章导入书，在 1264×1680 隔离 KOReader 进程中验证了取消下载、下载全书、重新搜索及离线跳转；目标章节正文与独立读取一致，当前阅读文件在下载时未被替换。前后独立核对确认书架、目录和阅读位置不变，临时环境及凭据检查通过。一次早期跳转验证未确认，原因未查明，独立回读未发现账号状态变化；补充两章诊断及整书复验后通过。每次整书验证使用 58 次只读 GET 和 172 次正文只读 POST，没有账号数据或授权写入；范围见[脱敏记录](validation-assets/2026-11-18/owner-full-search-download.json)。实体 Kindle 尚未验证。

后续将查询词限定在单个正文片段内，并分别从目录首章和当前章发起只读搜索。六本书共 22 次查询，其中十组可直接比较两种起点：三组均找到目标，一组只有当前章起点找到，六组均未找到；其余两次查询的当前章与首章相同。返回的七次目标范围均与原文一致。这说明先前的空结果不能仅归因于查询词跨正文片段，也不能将当前章补查视为完整搜索。

[墨水屏客户端接口目录](https://github.com/teng-lin/weread-omni/blob/main/docs/endpoints.md)另列出了 `/book/search`，但没有验证其返回格式及导入书覆盖。使用一本导入书的原文章节生成搜索词，以保存的同账号墨水屏授权发送一次只读 GET，服务端返回 HTTP 401；因此目前无法区分授权状态与接口限制，也无法判断该接口是否能补全搜索。随后独立回读书架、目录和阅读位置均未变化，没有修改账号数据或续期授权。结果和查询范围见[脱敏记录](validation-assets/2026-11-18/native-import-search.json)。此接口尚未接入插件；现有本机搜索与整书下载入口继续可用。

之后使用原生书架读取和实际 KOReader 的独立统计读取，分别确认保存的墨水屏授权已过期；同设备续期一次后核对同账号书架并保存授权。续期后对四本导入书各发送一次只读搜索，每次关键词均来自该书实际章节中可唯一定位的原文；四次响应均接受，但结果数组均为空。每本书的搜索前后分别核对书架、目录和阅读位置不变。这个结果不覆盖其他词语、参数、书籍或服务端索引状态，不能说明该接口永远无效；当前也无法凭空结果验证命中格式与跳转位置，因此仍不接入。结果见[续期后记录](validation-assets/2026-11-18/native-import-search-renewed.json)。

首章起点查询结束后，无论是否已有匹配，如果能从当前文件映射或有效原文位置确认另一当前章，插件会自动从该章再查一次。首轮仍有后续页时，也可选择「从当前章节补查」，不必先加载全部结果；补查结束后可继续加载原搜索，补查进行中取消或失败时可先返回原搜索。两条查询共用总页数及结果上限，达到上限或无法确认当前章时不再补查；结果按章节和原文位置合并去重。目录需要重新读取时，插件先保存有效目录再进行搜索，避免已有章节无法定位。两种尺寸的实际 KOReader 配合模拟服务验证了补查、定位和首轮搜索取消，补查中的取消另经单元测试；其中一个真实账号样本原先从首章返回空、从当前章返回匹配，最终候选在两尺寸、目录已缓存和需要重新读取两种情况下均通过原生补查和原文定位，前后云端章节、偏移、百分比、目录、正文和书架顺序保持一致。未执行账号数据或授权修改。详细范围见[补查记录](validation-assets/2026-11-18/cb-search-fallback.json)。

首轮已有结果后的补查、两次结果去重排序和原文跳转已在两种模拟尺寸使用打包插件及合成服务验证；多页补查、失败保留和重试另经组件测试。真实账号的一本导入书在两种尺寸、目录已缓存和需要恢复目录的情况下，从首章与当前章各读取一次，对同一原文匹配去重后成功定位；独立读取的书架、目录、原文和位置保持，没有账号数据或授权修改。首次真实回归因验收工具未计入新增的本机搜索入口而停止，修正列表定位后上述四组重验通过。另对五本书进行 20 次只读查询，有限样本仍存在空结果，见[脱敏记录](validation-assets/2026-11-19/cb-search-merge.json)。这个改进不能保证搜索覆盖所有章节或全部匹配；真实服务中首轮非空而当前章补查获得新结果的情况及实体 Kindle 仍待验收。

主动补查、合并重复结果、原搜索续页和原文跳转已在两种模拟尺寸用打包插件与合成服务验证；组件测试另覆盖切换两条未完成的查询、取消、失败重试和共同页数上限。真实账号只读抽查找到多页候选，但随后的查询遇到服务端限制，程序停止，未进入真实界面验收；没有账号数据或授权修改。后续验证工具已改为找到候选后停止继续搜索，见[脱敏记录](validation-assets/2026-11-19/cb-search-early.json)。

两种尺寸另以合成书籍验证跨章节分页与已缓存定位；KO2 尺寸覆盖缺目录、下载确认、取消和下载后定位。原有云端位置同步禁用及普通书路径通过回归。结果范围见[脱敏记录](validation-assets/2026-11-18/cb-book-search.json)；真实 TXT、更多查询与异常网络以及实体 KO2 仍待验证。
