# 书城公开搜书

首页和书城的搜索框提供「公开搜书」。它只读取公开书目数据，在 KOReader 原生界面显示，不加载网页；普通搜索在没有墨水屏授权或官方 API Key 时也可使用该通道。搜索建议仍需要墨水屏授权，公开搜索不代表可以免登录阅读所有书籍。

公开查询不携带账号 Cookie 或授权，不保存服务响应中的 Cookie，网络请求及解析在后台进行。翻页、返回和刷新保持同一来源；账号、登录状态或页面发生变化后，旧结果不会覆盖当前界面。已登录用户的结果按当前账号保存以便离线查看；未登录时搜索词不写入公共分类缓存。账号缓存中同一个搜索词保存最后一次查询结果，不混合不同来源的分页。

请求和分页格式参考 [douban-ebook-plus](https://github.com/iBitBetter/douban-ebook-plus)，仅参考接口，不执行第三方代码。原生 Lua 在实际 KOReader 运行环境中以公开词连接真实服务，两页分别返回 20 本、游标推进且无重复；请求未携带凭据。这是有限的公开样本，结果可能变化，并不能证明完整覆盖所有书目或小说分类。

模拟服务与原生界面测试覆盖输入、首批、前后翻页、账号切换、过期结果丢弃、离线来源隔离及错误处理。实体 Kindle Oasis 2 和更广泛的真实查询尚未验收。
