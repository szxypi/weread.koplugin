# 书城公开搜书

首页和书城的搜索框提供「公开搜书」。它只读取公开书目数据，在 KOReader 原生界面显示，不加载网页；普通搜索在没有墨水屏授权或官方 API Key 时也可使用该通道。搜索建议仍需要墨水屏授权，公开搜索不代表可以免登录阅读所有书籍。

公开查询不携带账号 Cookie 或授权，不保存服务响应中的 Cookie，网络请求及解析在后台进行。翻页、返回和刷新保持同一来源；账号、登录状态或页面发生变化后，旧结果不会覆盖当前界面。已登录用户的结果按当前账号保存以便离线查看；未登录时搜索词不写入公共分类缓存。同一搜索词的普通和公开结果分别保存。离线提交普通搜索时优先使用普通结果，没有时可打开已有公开结果。公开搜索只打开公开结果，已浏览批次沿用原来源。旧版保存的公开结果仍可读取，重新查询同一关键词时会保留可用的旧公开快照。

没有 Skill 密钥时，普通搜索的首批遇到墨水屏授权失效、403、服务端 50x 或连接错误，可转到公开搜索；401 会先尝试至多一次授权续期。结果标题标为「公开搜索」，后续批次绑定公开来源；已经在浏览的原生或其他来源分页不会被拼接。原生搜索直接返回 429、业务拒绝或无效响应时不会触发回退；续期失败后可使用公开搜索，待确认的续期记录继续保留，不会因公开搜索重发。两种屏幕尺寸的原生界面已用模拟服务核对连续 401、一次续期、公开两批和直接返回的 429；续期回执不明确与登录变化另经组件测试。自然失效的真实组合及实体设备仍待验收，见[记录](validation-assets/2026-11-19/keyless-search-fallback.json)。

配置了 Skill 密钥但首批请求返回 HTTP 401／403／5xx，或者连接失败时，普通搜索也可切换到公开来源；无论直接使用密钥还是先尝试墨水屏通道都适用。网关 429、其他业务拒绝、响应过大或格式无效不会触发回退；推荐与相似书籍不会被替换为公开搜索。分页继续绑定原来源，账号变化使旧请求失效。两种屏幕尺寸的原生界面经模拟网关 403、公开两批和网关 429 验证；自然过期的真实密钥与实体设备仍待验收，见[记录](validation-assets/2026-11-19/gateway-search-fallback.json)。

请求和分页格式参考 [douban-ebook-plus](https://github.com/iBitBetter/douban-ebook-plus)，仅参考接口，不执行第三方代码。原生 Lua 在实际 KOReader 运行环境中以公开词连接真实服务，两页分别返回 20 本、游标推进且无重复；请求未携带凭据。这是有限的公开样本，结果可能变化，并不能证明完整覆盖所有书目或小说分类。

模拟服务与原生界面测试覆盖输入、首批、前后翻页、账号切换、过期结果丢弃、离线来源隔离及错误处理。实体 Kindle Oasis 2 和更广泛的真实查询尚未验收。

未登录时，从搜索或分类结果打开普通数字书号的书籍，会在后台读取公开资料并显示详情；「获取最新信息」也可无需登录刷新。阅读及其他需要账号的操作仍要求登录。较早版本只显示书单已有字段、主动刷新会提示登录，当时的[脱敏记录](validation-assets/2026-11-19/public-guest-detail.json)保留原状。

只用墨水屏授权登录时，原生详情接口暂时不可用且本机没有通过账号通道核对的详情，也可读取普通书籍的公开资料并离线打开。书号、账号或页面变化会使旧结果失效。允许回退的错误及缓存优先级见[书籍详情说明](book-metadata-prototype.md)。

公开搜索和分类书单若返回简介、出版社、译者或评分，详情页可直接显示这些字段；评分和评价数必须同时有效才显示。简介最多保留 2048 字节，过长时标明省略；缺失或格式不合规范的字段不显示。这些信息只作为当前详情的补充，不覆盖已有资料、阅读状态，也不把简介摘要写成已验证的完整资料。已保存的书单可离线带出对应补充信息；未登录搜索词仍不写入公共分类缓存。

合成服务的两尺寸原生测试覆盖简介、出版社、评分及分类书单的新进程离线详情；单元测试另核对既有完整资料和阅读状态不被覆盖。两尺寸的真实公开搜索各验证了一本书的简介传递与展示，全程未使用账号凭据，见[记录](validation-assets/2026-11-19/public-book-details.json)。字段是否可用取决于书目响应，实体 KO2 仍待验收。

完整公开资料读取使用固定的只读 POST，单次只查询选中的一本书；请求不携带或保存登录凭据。接口格式参考 [wereadapi 的公开资料记录](https://github.com/ylw1997/wereadapi/blob/master/docs/apis/book-publicinfos.md)，没有运行第三方代码。插件核对返回书号，过滤阅读状态、版本和其他非展示字段，再保存允许展示的资料供离线查看。请求失败时保留现有详情；账号或登录状态变化后，旧结果不能提交。两尺寸的真实 KOReader 进程分别验证了公开查询、自动读取、手动刷新及全新断网进程重开；每轮三次搜索 GET、两次资料只读 POST，均无凭据或账号数据修改，隔离配置已删除。两尺寸合成测试还核对阅读入口仍要求登录。此验证仅覆盖公开搜索选中的样本，不代表所有书籍可用或实体设备已验收。见[脱敏记录](validation-assets/2026-11-19/public-full-book-details.json)。

以访客身份（未保存账号）在详情页点击「阅读」，扫码登录成功后会继续打开刚才选中的书；取消扫码、离开该详情、切换账号或阅读器后不会继续旧操作。两种尺寸的实际 KOReader 原生界面配合模拟登录服务，验证了取消扫码、重新登录、下载并进入所选书的原生 EPUB 阅读器；使用合成账号和书籍，不代表真实扫码或实体设备已验收。见[记录](validation-assets/2026-11-19/guest-login-read.json)。

补充的完整模拟流程从首页进入首次打开的公开榜单，选书、取消扫码、重新扫码并翻页，再在全新离线进程从首页恢复原生阅读页；两种屏幕尺寸均通过，离线阶段零请求。搜索入口也完成 600×800 相同回归；本次使用合成账号与书籍，不代表真实扫码或实体设备已验收。见[记录](validation-assets/2026-11-19/guest-chart-login-offline.json)。

访客在公开搜索结果长按书籍并选择「立即阅读」时，也可扫码后直接继续阅读所选书。取消扫码后可重试；页面或账号变化使旧操作失效，扫码前只保留书号和公开标题、作者，不携带原账号的本地位置。两种尺寸的 KOReader 原生界面使用模拟服务验证了扫码取消、重试、翻页和全新离线进程续读；真实扫码及实体设备仍待验收。
